# fp-project

FP育成プロジェクトリポジトリ

法人・資産家マーケットを担当するFP（ファイナンシャル・プランナー）を実務レベルへ育成するための学習・育成教材を管理します。

## カリキュラム

本番用の学習教材は [`curriculum/`](./curriculum/README.md) にあります。

| モジュール | テーマ |
|-----------|--------|
| [01 法人保険営業](./curriculum/01-法人保険営業/README.md) | 保険種類・経理処理・損金ルール・提案実務 |
| [02 企業分析・経営相談](./curriculum/02-企業分析経営相談/README.md) | 決算書読解・財務分析・資金繰り・課題抽出 |
| [03 相続](./curriculum/03-相続/README.md) | 民法基礎・相続税計算・財産評価・生前対策 |
| [04 事業承継](./curriculum/04-事業承継/README.md) | 承継スキーム・自社株評価・事業承継税制 |
| [共通](./curriculum/共通/README.md) | 面談設計・コンプライアンス・用語集 |

詳細・学習の進め方・免責事項は [`curriculum/README.md`](./curriculum/README.md) を参照してください。

> **注意：** 本教材は教育目的です。税率・控除額・特例等は税制改正で変わります。本文中の `〔要確認〕` は提案時に最新の法令・通達・約款で確認してください。
