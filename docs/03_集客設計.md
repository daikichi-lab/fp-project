> **セミナー名（仮）：「保険営業から、社長の"相談役"へ ― 会計を武器に法人を開く3日間チャレンジ」**（サブコピー：数字が分かれば、経営者の隣に座れる。"相談役"になれば、保険の話は向こうからやってくる。タイトル詳細は `04_セミナータイトル・特典カタログ案.md`。**サブ公式LINE名は短縮版「"相談役"になる3日間チャレンジ」で作る**）

## ゴール

- 認知 → **公式LINE登録** → **チャレンジセミナー申込** までの動線を作る
- KPI（仮）：公式LINE 100名 → セミナー申込 30名（→ `00_全体設計.md` のKPI参照）

## チャネル（どこで見つけてもらうか）

| チャネル | 役割 | 内容の方向性 |
|---|---|---|
| note | 信頼・深い読者獲得 | 「法人開拓に悩むFP」向けの実践記事・体験談 |
| X / Instagram | 拡散・認知 | 決算書の豆知識／法人営業のあるある／実績の声 |
| 既存FPリスト・人脈（フジヤマ氏／塩尻／カズ紹介） | 質の高い母数 | 同業FP・保険営業仲間を**FP専用オープンチャット**へ |
| フジヤマ氏 個人Facebook | 認知・告知 | 3日間セミナーを個人キャラで告知 |
| メイン公式LINE（大吉公式） | **ブランド母艦／入口の号外** | 普段の配信を守りつつ「FP向け情報配信を始めた→こちら」と号外でOCへ誘導（ゴリ押し告知はしない） |
| **FP専用オープンチャット** | **ティザーの主戦場** | ソフトティザーで期待値を上げ、サブ公式LINEへ送客 |
| セミナー用サブ公式LINE（使い捨て） | 申込・リマインドのハブ | 申込・リマインド・**質疑応答**を集約。登録→Facebookグループ招待 |
| Facebookグループ（非公開） | セミナー運営の母艦 | 申込者を集約・ルール/課題・コミュニティ（配信はZOOM／※04参照） |

> 集客導線の中心は**FP専用オープンチャット → サブ公式LINE**。メイン公式LINEは"育てたブランド"を守るため号外案内に留める。SNS/note/個人FBは母数を集める入口。

## リードマグネット → 登録動線（OC経由）

- SNS/note/個人FBの導線：「**決算書"3分速読"シート**ほか特典をプレゼント」で**FP専用オープンチャット**へ誘導（既存FPリストへは個別転送でOCへ）
- メイン公式LINE在籍者へは「FP向け情報配信を始めました → こちら」と**号外でOCへ誘導**（メインのブランドは守る）
- OC内でソフトティザー → **セミナー用サブ公式LINE**へ登録 → 登録直後にあいさつ＋特典配布＋「3日間セミナー」予告 → Facebookグループへ招待

## 募集文（テンプレートの骨子）

⑤詳細・募集開始で使う構成：

1. **ヘッドライン**：セミナー名「保険営業から、社長の"相談役"へ ― 会計を武器に法人を開く3日間チャレンジ」＋ベネフィット一文（例：数字が分かれば、経営者の隣に座れる。"相談役"になれば、保険の話は向こうからやってくる）
2. **共感**：こんな悩みありませんか?（01の痛みを箇条書き）
3. **得られる未来**：3日後のあなた（01のAfter）
4. **カリキュラム**：Day1〜3の見出し（7/14・16・18／`04`）
5. **参加条件**：FP/保険営業実務者／**無料**（席数は絞らない）
6. **申込方法**：このメッセージに「参加」と返信 等
7. **締切と緊急性**：**7/13(月)まで**（Day1前日）
