# 00. 全体設計｜FP法人マーケット攻略プロジェクト

> このプロジェクトの「地図」。各ドキュメントの起点。迷ったらここに戻る。

## コンセプト（一言で）

**個人保険マーケットで頭打ちを感じているFP・保険営業の実務者を、「決算書を武器に経営者と対等に話し、法人契約・相続・事業承継を獲得できるプロ」へ育成する。**

- 入口（無料）：3日間チャレンジセミナー「保険営業から、社長の"相談役"へ ― 会計を武器に法人を開く3日間チャレンジ」（仮）（2026/7/14火・16木・18土 各20:00〜21:00）
- 出口（有料）：**大吉塾 ｜ FP法人会計マスターコース**（30万円・3ヶ月集中／**会計の基礎を固め、3ヶ月で"初商談〜初契約"まで。中小企業の身近な案件中心（相続・事業承継も込み）**）
- 運営母体：**大吉会計株式会社**（daikichi-accg.co.jp）。教育ブランド「大吉塾」を展開

## なぜこのテーマが成立するのか（前提となる市場認識）

| 個人マーケット（現状） | 法人マーケット（目指す先） |
|---|---|
| 単価が低い／飽和／値下げ競争 | 1件あたりの保険料・手数料が桁違い |
| 紹介が枯れると止まる | 経営者人脈が連鎖して広がる |
| 「保険屋さん」扱い | 「先生」「相談相手」になれる |
| 誰でも参入できる | 決算書・財務・承継の知識が参入障壁＝差別化 |

→ **「法人に行きたいが、決算書が読めない・経営者と何を話せばいいか分からない」**という"できない理由"こそが、本プログラムが解決する核心。

## ファネル全体像（人の流れ）

> **【2026/6/17 MTGで動線更新】** メイン公式LINEのブランドを守るため、**メイン公式LINE →（号外）→ FP専用オープンチャット → セミナー用サブ公式LINE → Facebookグループ** の順で挟む（→ `03`/`06`）。

1. **認知**：note・SNS・フジヤマ氏個人FB・既存FPリスト/紹介で「法人開拓に悩むFP」にリーチ
2. **集約**：母数をまず**FP専用オープンチャット**へ（メイン公式LINEからは号外で誘導）
3. **温め**：オープンチャット内で**ソフトティザー**で期待値を上げ、**セミナー用サブ公式LINE**へ登録 →**3日間チャレンジセミナー**募集（無料・席数は絞らない／緊急性は締切・特典で）
4. **参加**：**ZOOM**で各回60分×3日（7/14・16・18 20時）。**初日(Day1)100名を目標**にDay3へ向け逓減（脱落制度）。Facebookグループで課題提出・コミュニティ（未提出は退出）
5. **転換**：最終日に**クロージング＋価格提示**。即決済OK／迷い・分割相談者のみ**個別相談**へ（→ `05`）
6. **成約**：その場決済 or 個別相談でヒアリング→提案→クロージング→**バックエンド成約**
7. **再活用**：参加者の感想・実績を次回集客の素材に（ループ化）

## KPI設計（最初の1サイクルの目安）

> 数字は仮置き。1回回して実測→更新する。本プロジェクトの「計器盤」。

| 段階 | 指標 | 目標（仮） |
|---|---|---|
| 集客 | OC／公式LINE登録 | **Day1 100名を満たす母数**（要逆算・仮） |
| 参加 | **Day1出席（初日に最大化）** | **100名を目標**（6/17・カズ目標） |
| 完走 | Day3まで完走（脱落制度で逓減） | Day1の 40〜50%（仮。Day2→Day3と減る前提） |
| 相談 | 個別相談（即決済しない検討層） | 完走者の一部（仮） |
| 成約 | バックエンド成約 | 仮（実測して更新） |
| 売上 | 1サイクル売上 | 単価**30万（プランA）／300万（プランB・仮）** × 成約数 |

**逆算の考え方**：必要な売上 → 必要な成約数 → 必要な相談数 → 必要な完走者数 → 必要な集客数。ボトルネックの段階のCVRを一つずつ改善する。
