## 2. コンセプト（LPのメッセージ）

- **ヒーローコピー**：「**決算書が読めれば、法人保険の提案は、もっと簡単になる。**」— 経営者との信頼関係を構築しながら、決算書分析・事業承継・相続対策まで提案できるFPへ。
- **クロージングコピー**：「法人保険は商品知識だけでは売れません。経営者を理解し、会社を理解し、未来を提案できるFPが選ばれます。」
- **問題提起**：多くのFPは商品知識を学ぶが、経営者が求めているのは保険の説明ではない。**決算書から会社の状態を読み取り、経営課題や将来リスクを可視化できるFPだけが「相談される存在」になる。**

### 想定する悩み（LP冒頭の5つ）
1. 法人保険を提案したいが経営者との会話に自信がない
2. 決算書を見ても何を分析すればよいかわからない
3. 保険商品の説明しかできず価格競争になってしまう
4. 事業承継や相続の相談を受けても踏み込めない
5. 経営者から信頼されるFPになりたい

### 受講後に身につく5つの成果
1. 経営者から「相談したい」と思われるFPへ（信頼関係の構築）
2. 見込客の会社の経営状況を分析して適切な法人保険を提案し、契約を獲得する
3. 決算書の見方と分析方法をマスターする
4. 相続・事業承継について提案に必要な知識・技術をマスターする
5. ブランディングで差別化し、経営者から選ばれるFPになる（→提案の切り口が増え契約獲得につながる）

### 受講後の未来
決算書を見るだけで企業の課題が見える／経営者との会話に困らない／保険営業ではなく**経営パートナーとして相談される**。

### 伴走コンサルティングの中身（FAQより）
- 個別セッション：**月1〜2回程度・1回60分**（Zoomまたは対面）。商談前後のフィードバック・提案書レビュー・LINE/Chatworkでの随時相談。受講者の状況に合わせカスタマイズ。
- 商談同行：基本は**首都圏（東京・神奈川・埼玉・千葉）**。それ以外は**オンライン同行**（Zoom等でリアルタイム参加）。
- アップグレード：**受講開始後1か月以内**なら差額支払いで①→②へ変更可（限定5名の定員次第）。

### 成果保証（②のみ）
- **定義**：受講開始から契約期間（1年）終了後も含め、**法人保険の新規契約による受取手数料・報酬の累計が180万円以上**に達した時点で成果達成。詳細計算・対象商品は申込後の個別面談で説明。
- **期限**：**無期限**。契約期間（1年）終了後も、180万円以上の売上が上がるまでサポート継続。ただし**指定する課題・行動指針に取り組むことが条件**。
- **対象外**：①指定の課題・商談活動を行わなかった場合 ②転職・廃業等で法人保険営業を継続していない場合 ③虚偽の情報での申込。詳細は契約書。
