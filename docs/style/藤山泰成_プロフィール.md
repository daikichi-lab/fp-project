# 藤山泰成 公式プロフィール

> **このファイルの使い方**
> 講師プロフィールを載せる全箇所（`04_台本_Day1`のS4／集客LP・note／`01_ターゲット設計`「語り手の信頼性」／登壇案内・バナー）で、肩書・経歴の**一次情報**として参照する。
