# 04（完全版）. 3日間チャレンジ ― スライド台割（完全版の設計図）

> 目的：**完全版の3日間チャレンジ**をスライド単位で組んだ"台割"。これを承認後、`04_台本_Day1〜3` と `docs/slides/` を本台割で作り込む（"まず構成だけ"→次に完全版を整える）。
> 方針：**スライド枚数は気にしない（〜100枚）。一概念＝一スライドで、丁寧に。** ゴール・特典・教え方は `04_3日間再設計骨子_未来会計版.md` 準拠。
> 規模：**1日あたり最大100枚まで可**（枚数より"伝わる粒度"優先＝一概念一枚で丁寧に）。目安 Day1≈34／Day2≈28／Day3≈40。
> 凡例（builder種別）：`T`title／`S`section／`St`statement(暗転キメ)／`C`content(箇条)／`Cd`cards／`#`stat(大数字)／`Tbl`table／`MM`お金の地図(moneymap)／`P`price。

## 全Day共通（厳守）
- **主**：終えたら「安心して・自信をもって経営者に会いに行ける」。3日間はそれ自体で完結、講座は加速・バックアップ。
- **形式＝こちらから伝える（delivery主体）／参加者に実技ロープレはさせない**（2026/6/23）。"体感"は藤山のデモを見せて作る。**理解と自信は〈丁寧な delivery ＋ 明日そのまま使える特典 ＋ 難所は藤山バックアップ〉で達成**。実技をしない分、**特典は"読めば/なぞれば再現できる"完成度**が生命線（実技の代替）。
- たとえ先行→用語後出し／「管理会計」不使用（未来会計・お金の地図）／自虐NG（藤山は痛みの当事者性）／**価格はDay3のみ・30万**／税務はさわり＋**【要・税理士確認】**・自社株見直しは断定しない（記号「※」）・特例承継の期限は前面に出さない／〔藤山ヒアリング待ち〕。
