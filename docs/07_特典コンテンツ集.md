## A1｜勘定科目"社長語"翻訳メモ（Day1 着席特典）

> 狙い：Day1開始時刻の着席促進／「たとえ→用語」の体現。A4・1〜2枚。

### （紙面）決算書の言葉を、社長に通じる言葉へ。

決算書が難しく感じるのは、能力の問題ではなく「言葉」の問題です。面談の前にこのメモを1分眺めて、**右側の言葉で**話してください。

**貸借対照表（BS）＝会社の「持ち物と借金のリスト」**

| 決算書の言葉 | 社長語（こう言い換える） | ひとことメモ |
|---|---|---|
| 現金及び預金 | 会社の財布と貯金 | まず最初に見る場所 |
| 売掛金 | まだ入金されていない売上 | 利益にはなっているのに現金はまだ無い |
| 受取手形 | 「あとで払います」の約束の紙 | 売掛金の親戚 |
| 棚卸資産（在庫） | 倉庫で眠っているお金 | 売れるまで現金に戻らない |
| 前払費用 | 来期の分まで先に払ったお金 | |
| 建物・機械装置 | 稼ぐための道具 | 買った値段から毎年すり減っていく扱い |
| 保険積立金 | すでに入っている貯蓄型保険のかたまり | 既契約が読める。ここは宝の山 |
| 役員貸付金 | 会社が社長に貸しているお金 | 銀行が一番嫌う科目 |
| 買掛金 | まだ払っていない仕入代 | |
| 短期借入金 | 1年以内に返す借金 | |
| 長期借入金 | 長く付き合う借金 | 「額」でなく「何年で返せるか」で見る |
| 役員借入金 | 社長が会社に貸しているお金 | 実は"社長の財産"＝相続と関係する |
| 未払金・未払費用 | もう使ったのに、まだ払っていないお金 | |
| 預り金 | 社員から一時的に預かっているお金 | 源泉徴収など |
| 資本金 | 創業のときの元手 | |
| 利益剰余金 | 創業からコツコツ貯めた利益の積み立て | ＝会社の「体力」。ここを労うと社長は喜ぶ |

**損益計算書（PL）＝会社の「1年間の家計簿」**

| 決算書の言葉 | 社長語 | ひとことメモ |
|---|---|---|
| 売上高 | 1年間の稼ぎの総額 | |
| 売上原価 | 売るために直接かかったお金 | |
| 売上総利益（粗利） | 商売の腕前 | |
| 販売費及び一般管理費 | 会社を回すための毎月の生活費 | |
| 役員報酬 | 社長の給料 | |
| 減価償却費 | 現金の出ていかない費用 | 昔買った道具の"すり減り分" |
| 支払保険料 | いま払っている保険の掛金 | ここでも既契約が読める |
| 営業利益 | 本業の稼ぐ力 | |
| 経常利益 | 会社の実力 | 銀行が一番見る利益 |
| 当期純利益 | 税金を払って最後に残った利益 | 翌年、BSの「体力」に積み上がる |

**使い方**：①面談前に1分眺める ②社長との会話では右の言葉で話す ③決算書を読むときは左→右に翻訳しながら読む。

## A2｜利益とお金は、別モノ ― 早わかり1枚（Day2 着席特典）

> 狙い：Day2開始時刻の着席促進／Day2の核心「利益は出ているのに、お金が残らない」を先に手渡し、その日の"謎解き"（架空モデル・大吉製作所の決算書）がスッと入る状態にする。A4・1枚。ネガティブ回避＝「現金が薄い＝悪い会社」ではなく「構造」として前向きに。B3（書き込み式チェックシート）とは別物＝こちらは"概念の地図"。

### （紙面）「儲かっているのに、お金がない」には、理由があります。

利益とお金（現金）は、別モノです。これは社長の経営が下手だからではなく、お金の"構造"の話。今日はこれを、実際の決算書で読み解きます。着席でこの1枚を眺めておくと、今日の謎解きが二倍わかります。

**まず、ひとことで。**
> **利益は意見、現金は事実。**
> 損益計算書（PL）の利益は、見積もりや会計処理で"解釈"の入る余地がある数字。通帳の残高は、嘘をつかない数字です。

**利益が出ても、お金が残らない5つの理由**（今日、実際の決算書でこの目で確かめます）

| # | お金が出ていく／入らない理由 | なぜPL（利益）からは見えないのか | 家計でいうと |
|---|---|---|---|
| 1 | 借入の元本返済 | 元本の返済はPLに1円も出ない（費用になるのは利息だけ） | 住宅ローンの元本返済 |
| 2 | 税金 | 利益に対して、現金で払う | 所得税・住民税 |
| 3 | 設備投資 | 現金は先に丸ごと出て、費用は後から少しずつ（減価償却） | 車を一括で買う |
| 4 | 売掛金・受取手形 | 売れて利益は立つのに、入金は2〜3ヶ月後 | 給料日前の立て替え |
| 5 | 在庫（棚卸資産） | 仕入で現金が先に出て、売れるまで現金に戻らない | まとめ買いした食材 |

**だから、こう読みます。**
- 現金が薄い＝「危ない会社」とは限りません。**成長している会社ほど、立て替え（売掛・在庫）や投資が大きくなる**からです。
- 大事なのは、「なぜ薄いのか」を**構造で説明できること**。社長がひとりで抱えている「儲かってるはずなのに、なんで金がないんだ」に言葉を与えられる人――それが"相談役"です。

**今日の見どころ**：この5つが、1社の決算書の中で実際にどう効いているか。数字を"見る"から、"読む"へ。

> 本資料は一般的な情報提供です。数値の目安は業種・規模により異なります。

## A3｜"相談役"の1ページ ― 保険屋さんと相談役は、ここが違う（Day3 着席特典）

### （紙面）同じ人が、立ち位置ひとつで「相談される側」に変わる。

今日は、初回面談から"相談役"になるまでを、通しでお見せします。その前に、両者の違いを1枚で。今日のデモは、この表の**右側の列を実演するもの**だと思って見てください。

| | 「保険屋さん」で終わる人 | 社長の"相談役"になる人 |

## B1｜財務三表 繋がり早見図（Day1 再現ツール）

> 狙い：Day1の土台（三表の構成と繋がり）を持ち帰って再現＝Day2以降の前提。A4・1枚。図版化はpptx制作時（下記レイアウト指示）。

### （紙面）会社の数字は、3枚でひと組。

**まず、家計にたとえると――**

| 表 | 家計でいうと | 答えてくれる質問 |
|---|---|---|
| 損益計算書（PL） | 1年間の家計簿 | 今年、いくら稼いでいくら使った？ |
| 貸借対照表（BS） | いまの持ち物と借金のリスト | いま、何をどれだけ持っている？ |
| キャッシュフロー計算書（CF） | 財布と通帳の出入りの記録 | 現金は、なぜ増えた？減った？ |

**3本の繋がり線（ここだけ覚える）**

1. **PLの「当期純利益」は、BSの「利益剰余金」に積み上がる。** 今年の稼ぎが、来年の体力になる。会社の歴史はBSの右下に貯まっていく。
2. **BSの「現金及び預金」が動いた理由を説明するのがCF。** 利益が出たのに現金が減った年は、CFに必ず理由が書いてある。
3. **利益と現金は、別物。** ズレの三大理由：①売掛金（利益になったのに現金はまだ）②借入の元本返済（現金は出るのにPLに出ない）③減価償却費（費用なのに現金は出ない）。

> 覚え方のひとこと：**「利益は意見、現金は事実」**。PLは解釈の入る余地がある数字、現金残高は嘘をつかない数字です。

**1枚図のレイアウト指示（制作用・紙面には載せない）**：左にPL（上から売上→利益）、右にBS(資産/負債/純資産の箱)、下にCF。矢印①PL最下段→BS純資産、矢印②BS現預金⇔CF、注釈③を余白に。Day1スライドの図と同一デザインにする。

**次の一歩**：この3枚のうち、初回面談で見るのは**BSの3ヶ所だけ**（→特典「3つの数字」シリーズへ）。

## B2｜決算書の状態 → 備えるべきお金 → 効く保険 変換マトリクス（Day2 再現ツール・★中核）

> 狙い：「会計で入口／保険で締める」をツール化した本チャレンジの核。Day2 §5の完全版。A4横・1枚。

### （紙面）決算書から、社長の"これから要るお金"へ。

使い方は3ステップ。**①決算書でサインを見つける → ②社長に見えている景色を想像する → ③"備えるべきお金"の話として切り出す。** 保険はその答えとして、最後に登場します（自分から商品名を出さない）。

| 決算書のサイン（どこを見る） | 社長の景色 | 備えるべきお金 | 効く保険の型 | 切り出しの一言例 |
|---|---|---|---|---|
| **借入が多い・現金が薄い**（借入金が月商数ヶ月分／現預金が月商1ヶ月未満／経営者保証） | 「自分に何かあったら、この借金はどうなる…」 | 万一のときの借入返済＋当面の運転資金（固定費6〜12ヶ月分が目安） | 事業保障（死亡保障・掛け捨て中心） | 「社長に万一のとき、この借入はどなたが返す設計になっていますか？」 |
| **利益が出続けている**（経常利益が黒字続き／役員報酬は控えめ） | 「自分の引退のこと、考える暇がなかった」 | 役員退職金の原資（返戻金のピークと退任時期を合わせる設計） | 退職金準備（長期平準定期など） | 「社長ご自身の退職金、いくら受け取るか決めていらっしゃいますか？」 |
| **内部留保が厚い**（純資産・利益剰余金が大きい／自己資本比率が高い） | 「会社は強くなったが、株の評価なんて見たこともない」 | 相続税の納税資金（自社株は売れない＝換金できない財産） | 納税資金準備（死亡保険金の非課税枠＝**500万円×法定相続人**を活用） | 「会社の"体力"が、相続では"重さ"にもなるってご存じでしたか？」 |
| **承継が視野**（社長60代以上／後継者未定または複数の子） | 「継ぐ子と継がない子に、どう分ければ…」 | 代償分割・納税の現金（公平は現金でしか作れない） | 事業承継の備え（代償分割資金・納税資金） | 「会社を継ぐ方と継がない方の"公平"って、最後は現金の問題になるんですよ」 |
| **役員借入金が多い**（社長→会社への貸付） | 「会社に貸しているだけ。財産だと思っていない」 | 貸付金は**額面のまま相続財産**になる→その納税資金 | 納税資金準備（出口の整理は専門家と） | 「社長が会社に貸しているお金、実は相続の対象になるってご存じでした？」 |
| **従業員が多い**（人件費比率が高い／採用に苦戦） | 「社員の退職金まで手が回らない。でも辞めてほしくない」 | 従業員の退職金・弔慰金・定着の仕組み | 養老保険ハーフタックス（※全員加入＝普遍的加入が要件） | 「社員さんの退職金の準備って、いまどうされていますか？」 |

**このマトリクスの使い所**：2回目面談（気づきを3つ返す場）の3つめ＝「これからの話」で1行だけ使う。全部は言わない。**一番サインが濃い1行だけ**。

> ⚠️ **必ず守ること**：①保険の「型」は一般的な情報です。特定の商品の推奨・比較はこの紙面ではしない。②法人保険の経理処理は2019年の税制通達（解約返戻率の区分）により契約ごとに異なります。加入・見直しの際は必ず最新の税務取り扱いを確認。③税額の計算・個別の税務判断は税理士の独占業務です。「専門家の先生と一緒に確認しましょう」まで。
> 本資料は一般的な情報提供です。個別の税務相談は税理士等の専門家に、保険商品の詳細は各保険会社の資料をご確認ください。

## B3｜3つの数字 チェックシート（Day2 再現ツール）

> 狙い：Day2の読み方を"なぞれば再現できる"書き込み式に。A4・1枚。実際の決算書を横に置いて埋める。

### （紙面）決算書は、3分でこの3つ。

会社名：＿＿＿＿＿＿＿＿＿＿　決算期：＿＿＿＿年＿＿月期　業種：＿＿＿＿＿＿

**① 体力 ― 自己資本比率**（見る場所：貸借対照表の右下「純資産の部」）

- 純資産 ＿＿＿＿＿＿円 ÷ 総資産 ＿＿＿＿＿＿円 ＝ **自己資本比率 ＿＿＿＿%**
- 目安：**40%以上＝優良／20%未満＝注意／10%未満＝危険信号**（一般的な目安・業種差あり）
- ここから言える労いの一言：「＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿」（例：御社、しっかり体力を貯めてこられたんですね）

**② 血の巡り ― 手元現金の月商倍率**（見る場所：貸借対照表の左上「現金及び預金」）

- 現金及び預金 ＿＿＿＿＿＿円 ÷ 月商（年商÷12） ＿＿＿＿＿＿円 ＝ **＿＿＿＿ヶ月分**
- 目安：**最低1〜1.5ヶ月分**（業種差が大きい・あくまで目安）
- 利益が出ているのに薄い場合、その理由の候補に○：　元本返済 ／ 税金 ／ 設備投資 ／ 売掛・在庫

## B5｜財務インパクトの読みどころ＆算出シート（Day2 再現ツール・★算式）

> 狙い：Day2の"もしも"（続ける／渡す／終える）の必要額を、決算書からなぞって出せる書き込み式。読みどころ（どこを見る）＋3つの算式。A4・2枚。※係数・月数・税率・功績倍率は**目安**（会社ごとに調整・税理士確認）。出典＝`research/財務インパクト算出方法_リサーチ.md`（しのざき総研＝負債×1.5 ほか）。

### （紙面1枚目）財務インパクトの"読みどころ" ― 決算書のどこから、何を拾うか

3つの数字（体力・血の巡り・借金）で"健康診断"。そこにこの読みどころを足して、"もしも"を金額にします。※科目の場所は特典A1「勘定科目"社長語"翻訳メモ」参照。

| 読みどころ | どこを見る | 何に使う（シナリオ） |
|---|---|---|
| 現金及び預金 | BS 左上 | 手元＝穴から引く（全シナリオ） |
| 短期・長期借入金 | BS 右 | 負債返済（続ける・終える） |
| **★連帯保証・団信の有無** | **決算書に無い＝社長に聞く** | 借入の穴を"外す/残す"（過剰保障を避ける） |
| 買掛金・支払手形 | BS 右 | 負債返済（式の中身） |
| 純資産・利益剰余金 | BS 右下 | 自社株評価のベース（渡す） |
| 役員借入金 | BS | 相続財産の見落とし第1位（渡す） |
| 保険積立金 | BS | 既契約＝"もう埋まっている穴" |
| 固定費（人件費・販管費） | PL | 運転資金＝固定費×月数（続ける） |
| 役員報酬 | PL | 死亡退職金の計算（続ける） |
| 支払保険料 | PL | 既契約の把握 |

### （紙面2枚目）3つの算式 ― "もしも"を金額にする（書き込み式）

**① 続ける（社長の死亡・就業不能）＝事業保障資金**
- 運転資金 ＝ 固定費（月）＿＿万 × 必要月数（6〜12）＿＿ ＝ **＿＿万**
- 負債返済 ＝（短期借入＋長期借入＋買掛＋支払手形）＿＿万 × **1.5**（※保険金は益金＝税割戻し。連帯保証・団信で調整）＝ **＿＿万**
- 死亡退職金 ＝ 報酬月額＿＿万 × 在任年数＿＿ × 功績倍率（社長**3.0**目安）＝ **＿＿万**／弔慰金（業務上＝月額×36・業務外×6）
- 小計 −（手元現金＿＿万 ＋ 既契約保険＿＿万）＝ **不足額 ＿＿万**
- ※非課税枠：死亡保険金 500万×法定相続人／死亡退職金 500万×法定相続人（**別枠**）／受取人指定で分割協議の外

**② 渡す（事業承継）＝納税・買取・公平の現金**
- 自社株の納税資金（評価は税理士）＿＿万 ＋ 代償分割の現金＿＿万 ＋ 役員借入金（額面で相続財産）＿＿万 ＝ **＿＿万**
- （従業員承継＝後継者の株買取資金／M&A＝"売れる会社"にする準備）

**③ 終える（清算）＝清算資金**
- ① 固定費（月）＿＿万 × 清算期間＿＿ ＋ ② 借入＿＿万（保証次第）＋ ③ 従業員退職金＿＿万 − ④ 換金資産＿＿万 ＝ **清算必要額 ＿＿万**

**記入例（架空・大吉製作所）**：続ける＝運転資金4,200〜8,400万 ＋ 負債8,000万×1.5（=1.2億）＋ 退職金 約1億 −（現金2,600万＋既契約900万）＝ **不足 約2億超**。→ 現金2,600万では全然足りない＝これが保険で埋める候補。

> ⚠️ 本シートは概算の整理のための一般的な情報提供です。係数（×1.5）・月数・税率・功績倍率は目安であり、会社ごとに異なります。**税額計算・自社株評価・非課税枠の個別適用は税理士の独占業務**です。保険は"考え方"であり、個別商品の推奨ではありません。**連帯保証・団信は必ず契約内容をご確認ください**。

## C1｜既加入 保険証券 読み解きシート（完走特典）

> 狙い：完走の報酬＋**保険へ直結**する現実的な入口（新規提案より「いまの棚卸し」が自然）。A4・2枚（チェック表＋見直しの糸口）。

### （紙面）社長の「いま入っている保険」から始める。

新しい保険の話は、警戒されます。でも「いま入っているものの棚卸し」は、社長にとって100%メリットの話です。決算書の**「保険積立金」「支払保険料」**が見えたら、こう切り出してください。
**「新しい保険の話ではなくて、いま入っていらっしゃるものの"棚卸し"を一度しませんか。証券を並べるだけです。15分で終わります」**

**証券チェック表（1契約につき1列）**

| チェック項目 | 見る場所・書き込み | なぜ見るか |
|---|---|---|
| ① 契約形態 | 契約者＿＿／被保険者＿＿／受取人＿＿ | 法人契約か個人か、受取人が会社か遺族かで**出口（お金の流れ）が全く違う** |
| ② 保険の種類 | 定期／長期平準／逓増／養老／終身／医療 ほか | 目的（保障・退職金・福利厚生）とズレていないか |
| ③ 保険金額 | ＿＿＿＿万円 | **借入残高＋当面の固定費（6〜12ヶ月分）**と比べて足りているか（＝必要保障額のざっくり目安） |
| ④ 保険期間・満期／更新 | ＿＿年まで／更新＿＿年 | 更新型は保険料が跳ね上がる時期を先に知っておく |
| ⑤ 解約返戻金 | いま＿＿万円／ピーク＿＿年頃 | **ピークと社長の退任時期が合っているか**（退職金原資設計の生命線） |
| ⑥ 経理処理 | 全額損金／一部資産計上／不明 | 2019年通達以降、**解約返戻率の区分**で扱いが変わる（下表参照）。不明なら顧問の先生に確認 |
| ⑦ 加入の目的（当時） | ＿＿＿＿＿＿＿＿ | その目的、**いまも有効か**。「節税のため」だった契約は、出口が設計されているかを要確認 |

**参考：法人保険の経理処理（2019年通達・契約日2019/7/8以後の定期保険等）**

| 最高解約返戻率 | 資産計上の目安 |
|---|---|
| 50%以下 | 資産計上なし（全額損金） |
| 50%超70%以下 | 保険料×40%を資産計上 |
| 70%超85%以下 | 保険料×60%を資産計上 |
| 85%超 | 当初10年：保険料×返戻率×90% ほか |

**見直しの糸口・5パターン（チェック表を埋めると見えてくるもの）**

1. **保障不足**：借入が増えたのに保険金額が昔のまま（③）
2. **ピーク超過・失念**：返戻金のピークを過ぎて目減り中／ピークが退任予定とズレている（⑤）
3. **受取人が古い**：先代のまま・退職した役員のまま（①）
4. **更新の崖**：更新型の保険料が数年内に急増する（④）
5. **目的の消滅**：借入完済・後継者決定などで当初の目的が終わっている（⑦）

| 生命保険（受取見込み） | ＿＿＿＿万円 | →STEP3の非課税枠と関係 |
| **自社株** | ＿＿＿＿万円 | **上場していない会社の株も社長の財産**。評価は専門家の領域（純資産が厚い会社ほど重くなる方向）。まずは会社の純資産額を目安に記入 |
| **社長が会社に貸しているお金（役員借入金）** | ＿＿＿＿万円 | 見落とし第1位。**額面のまま相続財産**になります |
| その他（不動産・車など） | ＿＿＿＿万円 | |
| **合計 A** | **＿＿＿＿万円** | |

**STEP2｜基礎控除を引く**

- 基礎控除 ＝ **3,000万円 ＋ 600万円 × 法定相続人の数**
- 法定相続人 ＿＿人 → 基礎控除 **B ＝ ＿＿＿＿万円**
- **A − B ＝ ＿＿＿＿万円**　→ プラスなら、**相続税がかかる可能性**があります（税率は超えた部分に10〜55%の累進。正確な税額計算は税理士の独占業務です）

**STEP3｜「現金で払えるか」を見る（ここが本題）**

相続税の納付は、**原則、現金で、10ヶ月以内**です。そこで――

- A のうち、**すぐ現金にできない財産**（自宅・自社株・不動産）：＿＿＿＿万円
- A のうち、**現金・すぐ現金化できるもの**：＿＿＿＿万円
- → 納税と分割（きょうだい間の公平）に、現金は足りそうですか？　**足りない／わからない → その差額が「保険で備える」検討額です**

**なぜ保険なのか（3行だけ）**
1. 死亡保険金には**「500万円 × 法定相続人」の非課税枠**があります（受取人が相続人の場合）。
2. **受取人を指定できる**ので、遺産分けの話し合いの外側で、必要な人に確実に現金が届きます。
3. 契約したその日から、**「必要な瞬間にまとまった現金がある」状態**を作れます。自社株や不動産にはできないことです。

**記入例（架空）**：財産合計A＝1億6,000万円（うち自社株1億円）／相続人3人→基礎控除B＝4,800万円／A−B＝1億1,200万円→かかる可能性大。現金化できる財産は2,000万円→**納税と公平の現金が大きく不足**→「まず専門家の先生と正確な評価を。並行して、現金の備え方を一緒に考えましょう」が次の一手。

> ⚠️ **本シートは概算の整理のための一般的な情報提供であり、税務相談・税額計算ではありません。** 相続税の計算・申告・個別の対策は税理士の独占業務です。自社株の評価方法は現在、国税庁で見直しが議論されています（2026年4月〜有識者会議）。実際の検討は必ず税理士等の専門家と行ってください。保険の活用も個別商品の推奨ではありません。
> 数値の出典：基礎控除・非課税枠・税率・申告期限＝国税庁タックスアンサー（No.4152／No.4114／No.4155／No.4205）。
