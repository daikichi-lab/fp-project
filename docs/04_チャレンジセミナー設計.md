## 0. 設計思想 ― OSエンジン × FP差別化

### OSから採用する"普遍原則"（崩さない）
- **初日から売り込まない**。Day1は信頼と共感を作る日。
- **情報量より変化量**。「少し前に進んだ」実感が最重要。**1日1テーマ・1ゴール**（詰め込みは離脱）。
- **聞かせるな、やらせる**（検索練習）＝毎日ワークとシェア。**1スライド1メッセージ**（認知負荷）。
- **自律性・有能感・関係性**（自己決定理論）＝選べる・できた・仲間がいる。
- **倫理的説得のみ**：恐怖訴求・嘘の希少性・誇大表現は使わない。高単価ほど**中心ルート**（内容・対象適合・価格・リスクを正直に）。

### FP固有レイヤー（OSに無い＝ここで差す）
| OSの汎用要素 | FPでどう差すか |
|---|---|
| 「気づき・共感」 | 藤山の歩み（前向き）＋**"数字がわかる保険屋だけが社長の隣に座れる"** という再定義 |
| 「実践・成功体験」 | **決算書の3つの数字**で社長を"当てる"／相続・事業承継を**数字で見せる** |
| 「未来・提案」 | **決算書分析の所有体験**→**独学の壁(GAP)**→講座 |
| 汎用オファー | **二段backend：30万=自走(DIY)／300万=伴走(done-with-you)** のギャップ提示 |
| 商品＝主役 | **保険は「相談役になった結果、後からついてくる」**（売り込まない） |
| 一般用語 | **たとえ→用語**（「管理会計」の語は出さない／コンプラ表記必須） |

### 顧客設計（Value Proposition Canvas・FP版）
| 顧客のJobs | Pains（痛み） | Gains（得たい成果） |
|---|---|---|
| 法人(経営者)に信頼され保険につなげたい／決算書を読めるようになりたい／相続・事業承継で役立ちたい | 決算書が読めない・どう声をかけるか分からない／"保険屋"として門前払い／何を学ぶべきか分からない／独学が続かない | 社長の**相談役**になれる／会いに行ける自信／**保険は後からついてくる**／高単価の法人顧客 |

→ **Pain Relievers**＝3つの数字の読み方／初回面談準備キット／相談役トーク。**Gain Creators**＝当事者性ある実例・藤山の実績／（伴走で）共同募集・本業連携。

### 全日共通の固定ルール（声・コンプラ）
標準語の丁寧語／**関西弁・自虐は生成テキストでは使わない**（失敗は学び・使命）／**たとえ→用語・「管理会計」の語は出さない**／**価格はDay1-2で出さずDay3で提示**／**割引なし（動機づけは期限付き特典）**／税務は知識ドメインと一致＋**コンプラ注意書き**。

### 3日間アーク（OSの表/裏テーマ × 高単価の型 × 相談役アーク）
| | Day1 | Day2 | Day3 |
|---|---|---|---|
| OS 表テーマ | 気づきと共感 | 実践と成功体験 | 未来提示と提案 |
| OS 裏テーマ | 問題の再定義 | 自己効力感の形成 | 次の行動の明確化 |
| 高単価の型(PLC) | 機会(What) | 変革(Why) | 所有体験(How)＋オファー |
| 相談役アーク | WHY | HOW | GAP |
| 参加者心理 | 半信半疑 → **共感・安心・期待** | 期待・不安 → **できた・可能性** | 迷い → **納得・決断** |
| メンタルループ | 開く | 閉じる | 所有体験→決断 |

**毎日かならず**：①今日のゴール（正解状態）②マイクロリザルト（5〜15分の小さな成功・出し過ぎない）③心理トリガー ④次回への引き。

| 項目 | 内容 |

| 心理トリガー | 権威(藤山実績)／好感(歩み)／互恵(特典)／期待(予告)／関係性(コメント) |
| 価格 | **出さない** |

**進行表（60分）**
| 時間 | 内容 |
|---|---|
| 0–5 | 歓迎・参加ルール（"コメント/ワークした人ほど得る"）・今日のゴール・**「今日は売り込みません」宣言** |
| 5–15 | **藤山の歩み**（前向き＝学び・使命）→「数字がわかる保険屋」が選ばれる理由 |
| 15–30 | **問題の再定義**：社長は"数字を一緒に見て相談できる相手"が驚くほど少ない／"保険屋"が門前払いされる本質は商品でなく**相談相手の不在**（`research/経営者の保険屋イメージ・断り文句`） |
| 30–42 | 会社の数字の全体像：家計の「**持ち物・稼ぎ・財布の中身**」（たとえ）→ 貸借・損益・キャッシュフロー（用語は後出し）＋決算書1枚デモ |

**ワーク（FP版・書き込み式）**：①今いちばん困っていること（例：決算書が読めない／声のかけ方）を一文 ②それが半年続くと何が困るか ③決算書1枚を見て気になる点を1つ。
**当日NG**：話しすぎてワーク削る／コメント拾わない／商品説明に寄せる／**関西弁・自虐**。
**終了後チェック**：録画保存／お礼+次回案内LINE／コメント返信／未提出者へ促し／KPI記録／**翌日冒頭で使う"声"を3つ選ぶ**。

## 5. 特典（ブライブ）設計

**原則**：価値を先に渡す＝**互恵**。**受け手に負の感情を生む切り口はNG**（旧「FPが仕事を取れない理由」は6/26ボツ）。ポジティブ＆実務直結。**OS原則＝特典は"参加のきっかけ"でなく"理想未来に近づく補助輪"**。

| 種別〔すべて仮〕 | 内容 | 狙い |
|---|---|---|
| **公式LINE登録特典（推奨）** | **「社長との初回面談 完全準備キット」**＝①質問リスト ②決算書を自然にもらうトーク ③初回で見る"3つの数字"早見表 | Day1/Day2に直結・"欲しい"を作る |
| 着席特典 | Day1冒頭の着席で配布 | 開始着席率 |
| 完走特典 | Day3まで参加で配布 | 完走率（儀式） |
| 期限付き特典 | 個別相談予約／申込期限内 | 希少性＝決断の後押し |

- 税務を含む特典は知識ドメインと一致＋**コンプラ注意書き**。**LINE特典は7/1までに確定**（7/3告知）。

## 6. KPI（OS09を採用）

**ファネル**：告知表示→申込ページ→**登録**→Day1→Day2→Day3→**個別相談**→申込。
**主要指標**：登録率／Day1参加率／**Day3残存率(Day3÷Day1)**／ワーク提出率／**相談率(相談÷Day3)**／成約率。
**ボトルネック診断**（OS09）：登録↓=テーマ/LP、参加↓=期待形成/リマインド、コメント↓=問いの難度/安全性、Day3↓=Day2の予告、申込↓=オファー適合/FAQ。目標値は〔仮〕。
