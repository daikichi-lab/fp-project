# 第3回 財務分析(9/2・リアル・13:00~17:00)内容検討資料

第3回「財務分析」の内容を確定させるための候補案。
**「何のために分析するのか(目的)」を軸に、分析手法と使用する財務指標を整理**した。
このうちどの目的に重心を置くかを決めれば、当日のプログラムが確定する。

---

## 1. 目的別の分析手法・指標マップ

### 目的A:金融機関からの評価を知る(資金調達力の把握)

融資の受けやすさ・金利条件は銀行の信用格付けで決まる。経営者が最も関心を持ちやすい切り口。

- **手法:銀行評点(金融機関の定量スコアリング)**
- 使用指標(一般的な定量評価モデルの構成):

| 評価軸 | 指標 |
|--------|------|
| 安全性 | 自己資本比率、ギアリング比率(借入金÷自己資本)、流動比率、固定長期適合率 |
| 収益性 | 売上高経常利益率、総資本経常利益率 |
| 成長性 | 経常利益増加率、売上高、自己資本額 |
| 返済能力 | 債務償還年数(借入金÷償却前利益)、インタレスト・カバレッジ・レシオ、償却前経常利益 |

- 演習イメージ:モデル決算書を評点表に当てはめてスコアリングし、「銀行からどう見えるか」を体感する
- 特に重要な指標:**債務償還年数(10年以内が目安)と自己資本比率** — 銀行実務で最重視される

### 目的B:自社の変化をつかむ(経営改善の起点)

他社と比べる前に、まず自社の時系列変化から課題を発見する。

- **手法:3期比較(趨勢分析)**
- 使用指標:
  - 売上高・売上総利益率・営業利益率の推移
  - 固定費(人件費・地代家賃等)の推移
  - 借入金残高と債務償還年数の推移
  - 売掛債権・棚卸資産の回転期間の推移(資金繰り悪化の予兆)
- 演習イメージ:3期分の決算書から「良くなった点・悪くなった点」を抽出し、経営者に質問すべきことを挙げる
- ポイント:数値の増減そのものより「**なぜ変化したのかを経営者に語れるか**」を訓練する

### 目的C:業界内での立ち位置を知る

自社だけ見ていては「この利益率は高いのか低いのか」が判断できない。

- **手法:類似業種(業界平均)との比較**
- 比較データソースの候補:

| データソース | 特徴 |
|--------------|------|
| ローカルベンチマーク(経済産業省) | 無料・6指標で簡易診断。入口として最適 |
| TKC経営指標(BAST) | 中小企業の実データベースで精度が高い(要約版は無料公開) |
| 中小企業実態基本調査(中小企業庁) | 業種別・規模別の公的統計。無料 |
| 日本政策金融公庫「小企業の経営指標調査」 | 小規模事業者との比較に有効。無料 |

- 使用指標:労働生産性(一人当たり付加価値)、労働分配率、一人当たり売上高、粗利率、営業利益率
- 演習イメージ:ローカルベンチマークシートに実際に入力して業界平均と比較する

### 目的D:総合的な健康診断(標準値・目安との比較)

個別の目的に入る前の基礎として、財務指標の体系を押さえる。

- **手法:財務指標比較(一般的な目安値との対比)**
- 指標体系(5分類)と代表指標の候補:

| 分類 | 指標 | 計算式 | 一般的な目安 |
|------|------|--------|--------------|
| 収益性 | 売上高総利益率 | 売上総利益÷売上高 | 業種による |
| 収益性 | 売上高営業利益率 | 営業利益÷売上高 | 3%以上 |
| 収益性 | 総資本経常利益率(ROA) | 経常利益÷総資本 | 5%以上で優良 |
| 安全性 | 自己資本比率 | 自己資本÷総資本 | 30%以上、10%未満は要注意 |
| 安全性 | 流動比率 | 流動資産÷流動負債 | 150%以上 |
| 安全性 | 固定長期適合率 | 固定資産÷(自己資本+固定負債) | 100%以下 |
| 効率性 | 総資本回転率 | 売上高÷総資本 | 1.0回以上 |
| 効率性 | 売掛債権回転期間 | 売掛債権÷月商 | 業種による(長期化は要注意) |
| 効率性 | 棚卸資産回転期間 | 棚卸資産÷月商 | 業種による(長期化は要注意) |
| 成長性 | 売上高増加率 | (当期売上-前期売上)÷前期売上 | プラス維持 |
| 返済能力 | 債務償還年数 | 有利子負債÷(経常利益+減価償却費) | 10年以内 |
| 生産性 | 労働生産性 | 付加価値÷従業員数 | 業界平均との比較 |
| 生産性 | 労働分配率 | 人件費÷付加価値 | 50%前後(業種による) |

### 目的E:事業承継・相続対策への橋渡し(第4回・第5回との連携)

本講座は第4回「相続対策」・第5回「事業承継」に続くため、その布石となる視点。

- 見るべきポイント:
  - **純資産の水準**(自社株評価の土台。純資産価額方式に直結)
  - 類似業種比準方式との関係(配当・利益・純資産の3要素)※「類似業種との比較」は株価評価でも登場することに触れる
  - 役員借入金・役員貸付金の有無(相続財産・株価評価に影響)
  - 含み損益のある資産(不動産・保険積立金等)
- 深掘りは第4回・第5回に譲り、ここでは「決算書のどこを見れば承継リスクに気づけるか」に絞る

## 2. 講座構成の候補案(3案)

4時間(13:00~17:00)の使い方として3案。

### 案A:銀行評点アプローチ(融資目線に重心)

「銀行からどう見られるか」という1つのストーリーで4時間を貫く構成。切り口が明確で経営者への提案に直結しやすい。

| 時間 | 内容 |
|------|------|
| 13:00~13:45 | 決算書の基礎(財務三表のつながり)※目的Dの指標体系を概観 |
| 13:45~15:00 | 銀行評点の仕組みと演習(目的A) |
| 15:10~16:15 | 3期比較演習:評点が悪化/改善した原因を趨勢分析で特定(目的B) |
| 16:15~17:00 | 評点を改善する打ち手の検討・発表 |

### 案B:目的別総合演習(健康診断型)

1社のモデル決算書を、複数の手法で多面的に分析する構成。手法の網羅性が高い。

| 時間 | 内容 |
|------|------|
| 13:00~13:45 | 財務指標の体系と目安値(目的D) |
| 13:45~14:45 | 3期比較演習(目的B) |
| 14:55~15:55 | 類似業種比較演習:ローカルベンチマーク活用(目的C) |
| 15:55~16:30 | 銀行評点の考え方(目的A・概説) |
| 16:30~17:00 | 総合診断レポート作成・発表 |

### 案C:事業承継接続型(講座全体の流れに重心)

第2回MG(会社経営の疑似体験)→ 第3回財務分析 → 第4・5回承継、という講座全体のストーリーを最重視した構成。

| 時間 | 内容 |
|------|------|
| 13:00~13:30 | MG体験の振り返り:ゲームの決算書と実際の決算書をつなぐ |
| 13:30~14:30 | 財務指標の体系と3期比較(目的D・B) |
| 14:40~15:40 | 銀行評点演習(目的A) |
| 15:40~16:30 | 承継目線の決算書チェック:純資産・役員借入金・自社株評価の入口(目的E) |
| 16:30~17:00 | まとめ:第4回・第5回への課題設定 |

## 3. 決めるべきこと

1. **重心をどの目的に置くか**(案A/B/Cの選択、または組み合わせ)
2. 演習に使う決算書:モデル企業の架空決算書か、参加者の関与先(守秘義務に注意)か
3. 類似業種比較のデータソース(ローカルベンチマークが無料で導入しやすい)
4. 配布物:評点表テンプレート、指標一覧カード、ローカルベンチマークシート等
5. 電卓・PCの要否
