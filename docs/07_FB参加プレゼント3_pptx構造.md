## 生成・QAメモ

- 生成：`/pptx-creation:deck-strategy` に本mdを渡して deck_plan.json 化 → `create-deck`（theme.json＝Day1と同一）→ 視覚QAループ必須 → `deck-review` 80点以上で配布可。
- 「"」入りタイトルの字形・messageLines の行長（〜25字）・table のセル折返しは QA で重点確認。
- 配布形態：PDF書き出し（Facebookグループに投稿）。動画収録時は同じpptxを画面共有し `07_FB参加プレゼント3_台本.md` を読む。

## このドキュメントの使い方

- **台本との対応**：各スライドの `notes` と `07_FB参加プレゼント3_台本.md` の【スライド◯】が対応。台本を直したら notes と本文もセットで直す。
- **数値の変更禁止**：目安の数値（40/20/10%・1〜1.5ヶ月・10年）は `docs/research/知識ドメイン_リサーチ.md` が出典。変えるときはリサーチ側と同時に更新。
- **特典設計**：位置づけ・狙いは `07_プレゼント（特典）設計.md`（S｜完全準備キット③）。呼称（FB参加特典）確定後に `06_意思決定ログ.md` へ記録。
- **見た目**：`theme.json`（大吉会計テーマ）で Day1 スライド・他特典と統一する。
