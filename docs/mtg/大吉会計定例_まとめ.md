## 2. 3日間チャレンジの構成 — 作り直し方針

### 2-1. 塩尻の初稿（たたき台）
- **Day1**：藤山の自己紹介＋**財務三表の読み方**（BS・PL・CF、全体像をつかむ）
- **Day2**：決算書の**具体的な読み方**
- **Day3**：**ロープレ形式**（初回面談〜契約までの流れを藤山が参考例で一通り）
- ねらい：「安心して会いに行ける」＋「法人保険の取り方で差別化できる」を体感 → 30万／300万へ。

### 2-2. 藤山の修正（重要）
- **各日の"ゴール（正解状態）"が未定義なのが根本問題**。それが無いまま話しても噛み合わない。**先にゴールを決める**。
- これは**ダイレクト出版的なマーケ手法**。「**チャレンジローンチ／プロダクトローンチ**」という確立した型がある（米DM企業のやり方）。**まず型を調べ、構成の土台にする**。
- **Day3はロープレではない気がする**。「この3日間"すら"来てよかった」と思える中身に。
- **相続・事業承継は絶対に入れる**（大川・藤山一致）。マーケットの大きさを**数字で見せて可能性を示す**。

### 2-3. 型の基本ライン（大川調べ）
| 回 | 役割 |
|---|---|
| 1回目 | **問題の認識** |
| 2回目 | **解決策の理解** |
| 3回目 | **実現可能性の確信** → オファーで行動を決断 |

### 2-4. 藤山の現時点イメージ（パッと版・参考）
- **Day1**：藤山の失敗談 → 「財務を勉強した方がいい」。決算書が読めると**法人保険が取れる構造**の話。
- **Day2**：**経営者が何に困っているか**（＝問題）。相続・事業承継の**マーケットを数字で**見せ、可能性を提示。
- **Day3**：塩尻作成の**決算書分析**を見せ「これを説明できたら経営者は喜ぶ」→ そこから**どう話を進めるか**。

> 現場の声（塩尻ヒアリング）：FPの悩みは圧倒的に「**決算書・財務が読めない／読めるようになりたい**」。→「**財務が読めたら、こんな話ができる**」を見せるのが刺さる。

## 3. 特典（プレゼント）— 作り直し方針

- 既存の「**保険が売れない／契約が取れない保険屋**」系PDF＝**ボツ**。理由：受け手に「**分かってる、分かってるから困ってる**」という**負の感情**が出る。
  - → 方向転換：「**イケてる保険屋が知っている知識**」など**ポジティブ側**へ。
- **公式LINE登録特典**を別途用意（"思わず欲しくなる"もの）。
- 候補（AI抽出リストから良いとされたもの）：**法人開拓 失敗チェックリスト／相続の必要保障額 ざっくり資産シート／決算書 入手トーク**、ほか勘定科目一覧・社長との初対面 質問リスト・補助金助成金カレンダー 等。
  - 藤山案「**TOTの共通言語**（経営者との会話＝資金調達・財務・事業承継・相続、深掘りで定款・株式）」→ **難しすぎる懸念**で保留。
  - 塩尻が欲しい「**初回打合せで話す内容／決算書のとり方**」＝あれば2日目に直結。
- 進め方：**理論は後付け、まずAIにフル任せで案出し**（藤山OK）。藤山も**知人FPに意見を聞く**。
