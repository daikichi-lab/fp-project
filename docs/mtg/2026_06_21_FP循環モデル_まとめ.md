## 0. 一言で（設計思想）

**FPを集めて育てる仕組みを"入口"にすると、高収益の本業（管理会計・外部CFO・相続・事業承継・M&A・上場支援・不動産）が自動的に流れ込む「循環エンジン」をつくる。** これが全体設計。
- **対象顧客**：売上 **2億〜20億円**の経営者。
- **起点**：FP集客（マネジメントゲーム＝MG／チャレンジセミナー）。
- **直近**：7/14・7/16・7/18 チャレンジ初回。

## 1. 全体像 ― 循環エンジン（5ステップのループ）

単発でなく「ひとつ回ると次が呼ばれる」ループが核心。

| | ステップ | 内容 |
|---|---|---|
| 集 | ① FPを集める（起点） | 母数が大きく熱量も高いのがFP。まずここを徹底集客。経営者向け会計勉強会は「将来やるが今ではない」 |
| 育 | ② MG・チャレンジで育成 | MGとチャレンジを入口に、財務・相続・事業承継を実務レベルで教える。**会費制コミュニティ化** |
| 繋 | ③ 顧客を紹介・共同募集 | 育ったFPが経営者を連れてくる。**共同募集**で一緒に提案し成果を分配。**FPが事実上の営業代理店**に |
| 本 | ④ 高収益の本業が流入 | 管理会計導入・外部CFO・相続・事業承継・M&A・上場支援・不動産。前段が回れば本業は勝手に入る |
| 評 | ⑤ 成果と評判が次のFPを呼ぶ | 「ここに繋ぐとお金が入る」という実績・評判が積み上がり、新たなFPが集まる → ①へ |

> ⑤の評判が①の集客力に変わりループが加速。中心は「循環エンジン」。**藤山＝設計と思想**、構築・進行はチーム分担。**回り始めたら藤山が前に出なくても回る形**を目指す。

## 2. なぜ「FP起点」か（遠回りに見えて最短）

- **刺さる顧客**：初期の経営者ではなく**売上2〜20億円**の層。類型は「**上場志向／将来売却（M&A）／実務で成長させたい**」の3つ。
- **保険が動く**：この層は相続・事業承継ニーズが大きく保険が大きく動く。**COT/TOT・MDRT級のFPはここに集中**。
- **会計が要**：正しい税務・資産設計には会計事務所が不可欠。**FP×会計で顧客を取り切れる**（価値を上げたい人も、相続で一旦下げたい人も会計側でキャッチ）。
- **循環収益**：FPが育つと**会費収入＋営業代理店化＋共同募集**が生まれる。例＝契約成立で**FP7割・当社2〜3割**など成果分配。

## 3. 事業を3層で捉える

「入口（集客）→ 育成・コミュニティ → 高収益本業」。下層は上層が回れば自動流入。

| 層 | 内容 |
|---|---|
| **集客層（入口）** | FP（主）＋経営者（副）。入口はMGとチャレンジ。**ポイント＝「研修」でなく「交流会」と表現**（FPは営業を嫌うが交流会なら集まる） |
| **教育・コミュニティ層（育成）** | 財務・相続・事業承継を実務で教え**会費制コミュニティ化**。「いつでも相談できる安心して任せられる箱」。**失敗した経営者だからこその"仲間・優しさ"がブランドの核** |
| **高収益本業層（収益）** | 管理会計導入支援・外部CFO・上場支援・M&A・事業承継・相続・不動産。**取りに行かなくても流入**＝利益の源泉 |

---

## 4. 競合との決定的な差は「伴走」

| 既存の協会・資格ビジネス | 当社（伴走できるチーム） |
|---|---|
| 知識提供だけ／教科書レベルで終わる | **税理士・司法書士・弁護士＋事業承継4000件規模のコンサルを保有** |
| 応用・実務・フィードバックの場がない | 「**言葉が分かるところまで**」教え、あとは安心して任せられる |
| 士業が分業で横断する人がいない | 最初のフロントで顧客を受け止め、**正しい順番で導ける** |
| 「何にお金を払ったか分からない」になりやすい | **紹介すれば成果（＝お金）が返る**設計 |

## 6. 今後の展開 ― フェーズ別

完璧を7月に求めず、テストしながら半年で完成度を上げるのが前提。

| フェーズ | 時期 | 内容 |
|---|---|---|
| PHASE 0 | 直近・7月 | チャレンジ初回を7/14・16・18で実施。以後**毎月・半年継続**（毎月やり続けること自体が「本気」の評判に）。完璧主義で止めない |
| PHASE 1 | 〜半年 | 藤山の失敗談（特殊詐欺の1本 等）をコンテンツ化。MG交流会でFP・経営者を集め会費・コミュニティ起動。**AIでFP悩み記事を量産し地方→中央のSEO**で流入。FP相談サイト＋MGサイト構築 |
| PHASE 2 | 1〜2年 | 名簿が貯まり本格的な集客構造を構築。SNS（Threads等）連動、**栗山さんのYouTubeを大型集客の入口**に。藤山は前に出ず仕組みで回す体制へ |
| PHASE 3 | 将来 | FPを**千人〜万人規模**に。経営者向け会計勉強会の本格展開、共同募集・人材獲得まで。補助金活用のAIゲートシステムで流入拡大 |

## 7. 直近アクション（チャレンジ初回）

- **やること**：3日間で「**何を伝えるか／何がいるか**」を決める。**プレゼント（特典）構成も含めて**ある程度決めて走りながら改善。
- **武器**：**藤山の失敗談が共感の核**（人は失敗話に共感する）＝コンテンツの源泉。
- **集客導線**：既存の公式LINE／メルマガ、紹介者（送客パートナー）から流入。チャレンジ後に当社の流れへつなぐ**一貫設計**。

## 9. チームの共通認識（重要）

- まず「**この箱**」を完結させる。新要素の追加は**箱が回り始めてから**。あれもこれも足さない。
- **完璧を7月に求めない**。半年でテストしながら仕上げる。完璧主義で止めるのが最大のリスク。
- **一貫性が命**。集客 → チャレンジ → 紹介 → 成果還元 → 本業まで、お金とイメージを**一本の線**でつなぐ。
