# 01. ターゲット設計（データ裏付け版 / 2026-06-26）

> 「誰の、どんな痛みを、どう解決するか」を一枚に。全ての告知文・セミナー・商品はここから逆算する。
> **数値の出典は `docs/research/保険営業の市場規模・法人保険課題_リサーチ.md`**（一次ソース確認済み）。断定数字は確度〔高〕のみ使用。

---

## 0. 一言で（誰を狙うか）

**「個人保険で頑張ってきたが頭打ちを感じ、法人マーケット（経営者）を開きたい保険営業・FP」。** ただし完全初心者ではなく、**実務の土台がある現役**。

なぜこの層か（データ）：
- **母数が厚い**：生保営業職員 約24万人＋生保募集人 約91万人。うち向上意欲層の指標＝**MDRT 約9,600人（上位約2%）**、その下に**AFP約15万・CFP約2.8万**の現役。〔出典§1〕
- **痛みが構造的**：個人は**世帯加入率89.2%で飽和**、**死亡保障額は2009年以降一貫減**、**5年目在籍率25%＝5年で約75%が脱落**。「行くところがない」は努力でなく市場の問題。〔§2-3〕
- **逃げ場＝法人**：法人契約は**少件数で高収益**。だが**2019年の税制改正で"節税で売る時代"が終わり**、財務・承継で語れる人だけが勝つ＝**学んだFADの参入障壁＝チャンス**。〔§4〕

---

## 1. メインターゲットの条件

- 年齢：30〜50代
- 経験：保険・FP実務で**3年以上**（5年目の壁＝在籍率25%を越えた中堅以上）。個人向けはこなせる
- 状況：成績は悪くないが**ここ数年で頭打ち**。単価を上げたい／安定させたい
- 環境：保険会社の営業職員、個人・乗合代理店、独立系FP（AFP/CFP保有だと尚良い）
- 心理：**「保険屋」から抜け出して経営者に一目置かれたい**／上昇志向

---

## 2. ペルソナ 3類型（フロントは全員、バックエンドで出し分け）

> 無料3日間チャレンジは3類型すべてに届ける。メッセージの**主軸はA（最大ボリューム・最も共感されるPain）**。バックエンドは A→30万、B/C→300万伴走へ。

### A型「頭打ち中堅」― 本命・ボリューム（→ 30万講座の主力）
> **佐藤さん（42歳・男性／生保営業職員 or 専業募集人）**
> 経験8年・年収580万。個人保険で一定の成績はあるが、紹介が枯れると止まり、ここ2〜3年頭打ち。「法人は単価が大きい」と聞き挑戦したいが、社長に会っても何を話すか分からず、決算書を見せられると固まる。社内研修は商品知識止まりで、法人開拓を教えてくれる人がいない。「経営者に一目置かれる存在になりたい」。
- データ的背景：平均年収約500万の壁／MDRTは2%だけ／件数勝負・単一商品・士業連携なしの典型。
- **刺さる軸**：「個人の消耗から抜けたい」「決算書が読めない不安」。Day1で"自分のことだ"。

### B型「転換志向の独立系・乗合」（→ 30万 → 300万伴走の候補）
> **鈴木さん（48歳・男性／乗合代理店・独立系FP、AFP保有）**
> 年収780万。自走できるが個人単価に限界を感じ、法人も時々やる。ただし決算書の深い読みや**提案の型**がなく、相続・事業承継の話になると士業に持っていかれる。税理士と組みたいが信頼を得る入口がない。「体系立てて学び、伴走してほしい」。
- データ的背景：頭打ち3要因のうち②単一商品依存・③士業連携欠如が主。
- **刺さる軸**：「型」と「伴走」「士業連携の作り方」。

### C型「天井破りトップ層」（→ 300万伴走・共同募集の中核＝循環エンジン）
> **高橋さん（39歳・男性／MDRT手前〜級）**
> 年収1,100万。個人ではトップ近いが「件数地獄」に疲れ、法人大型・継続収益と経営者ネットワークを作りたい。上昇志向が強く、投資判断も速い。
- データ的背景：平均500万 vs MDRT1,400万の上、さらに上の収益構造を狙う層。
- **刺さる軸**：「件数地獄からの脱出」「経営者人脈の連鎖」。**循環モデルで"経営者を連れてくるFP"の中核**。

## 3. 悩み・痛み（Pain）― データ裏付き

| Pain | 裏付け（確度） |
|---|---|
| 経営者に会っても**話の糸口がない**／保険の顔では門前払い | 定性・業界共通認識〔中〕。社長は「税理士に任せている」で弾く |
| **決算書が読めない**。数字を見ても課題が分からない | 法人参入の最大の壁（複数ソース一致）〔中〕＝講座コンセプト直結 |
| 個人マーケットは**単価が低く飽和**。紹介が枯れると止まる | 世帯加入率89.2%・死亡保障額は一貫減・紹介は半年〜2年で枯渇〔高/中〕 |
| このまま続ける不安 | **5年目在籍率25%**＝5年で約75%脱落〔高〕 |
| 法人保険・相続・事業承継の**提案の型がない** | 「教えてくれる人がいない・良い本もない」〔中〕 |
| **教わる場がない**（社内研修は商品知識止まり） | 複数ソース一致〔中〕 |
| 節税トークが封じられ、**何を価値に売るか分からない** | 2019通達で全損消滅・販売が高度化〔高〕 |

## 4. 欲求・なりたい姿（Desire / After）

- 経営者から「**先生**」「相談に乗ってほしい」と言われる存在になる
- 決算書を3分で読み、**経営者と対等に経営課題を語れる**
- 相続・事業承継を入口に、**大型の法人契約**を獲得（**少件数で高収益＝件数地獄を抜ける**）
- 個人マーケットの消耗から抜け、**高単価・安定・継続**の収入構造（平均500万→MDRT級1,400万の世界）
- 紹介が**経営者ネットワークで連鎖する**（循環モデル）

## 5. Before → After（変化の物語）

| | Before（現在） | After（プログラム後） |
|---|---|---|
| 面談 | 何を話すか毎回手探り・門前払い | 決算書を起点に経営課題から入れる |
| 知識 | 商品知識のみ | 財務・相続・事業承継を提案に使える |
| 立場 | 「保険屋さん」（会ってもらえない） | 「経営の相談相手＝先生」（向こうから相談が来る） |
| 単価 | 個人契約中心・件数地獄 | 法人契約で単価が桁違い・少件数で高収益 |
| 集客 | アポ取り・紹介依存で疲弊 | 経営者人脈が連鎖する |
| 収入 | 平均500万前後で頭打ち | 次のステージ（MDRT級＝約3倍）が射程 |

## 6. 刺さるメッセージ（コピーの素材）

数字は確度〔高〕のみ断定使用。コンプラ：保険は「結果として後からついてくる」扱い。

- 「**決算書が読めれば、保険は"売り込まなくても"売れる。**」
- 「個人マーケットで消耗するのは、もう終わりにしよう。**未加入世帯は、もうほとんど残っていない。**」（加入率89.2%）
- 「経営者は"保険屋"には会わない。でも"財務が分かる人"には会う。」
- 「**節税で売る時代は2019年に終わった。** これからは"数字で語れる人"が選ばれる。」
- 「**127万社が後継者未定。** 相続・事業承継は、法人マーケットへの最短の入口。」
- 「商品知識を増やしても、法人は獲れない。獲れるのは"経営者の言葉"を話せる人。」

## 7. ターゲット外（あえて狙わない）

メッセージをぼかさないために明記する。

- 保険・FP未経験の完全初心者（実務の土台がなく、伴走コストが高い）
- 副業・お小遣い稼ぎ目的の層（高単価バックエンドと不整合）
- 個人マーケットに満足しており現状維持で良い人
