# 01. ターゲット設計

> 「誰の、どんな痛みを、どう解決するか」を一枚に。全ての告知文・セミナー・商品はここから逆算する。

## メインターゲット

**FP・保険営業の実務者**で、個人マーケットに限界を感じ、法人マーケットを開拓したい人。

- 年齢：30〜50代
- 経験：保険・FP実務で3年以上。個人向けはある程度こなせる
- 状況：成績は悪くないが、ここ数年で頭打ち。単価を上げたい／安定させたい
- 環境：個人代理店、乗合代理店、保険会社の営業職員、独立系FP など

## ペルソナ（代表例）

> **佐藤さん（42歳・男性／乗合代理店の営業）**
> 個人向け保険販売で年収600万。紹介とアポ取りに疲れてきた。「法人保険は単価が大きい」と聞き挑戦したいが、社長に会っても何を話せばいいか分からず、決算書を見せられても固まってしまう。財務や事業承継の知識がなく、結局いつもの医療保険の話に逃げてしまう。「経営者に一目置かれる存在になりたい」。

## 悩み・痛み（Pain）

- 経営者に会っても**話の糸口がない**（保険の話を切り出せない）
- **決算書が読めない**。数字を見ても何が課題か分からない
- 個人マーケットは**単価が低く・飽和**。紹介が枯れると止まる
- 法人保険・相続・事業承継の**提案の型を持っていない**
- 周りに**教えてくれる人がいない**（社内研修は商品知識止まり）
- 高額セミナーや士業連携の話は聞くが、**何から手をつければいいか分からない**

## 欲求・なりたい姿（Desire / After）

- 経営者から「**先生**」「相談に乗ってほしい」と言われる存在になる
- 決算書を3分で読み、**経営者と対等に経営課題を語れる**
- 相続・事業承継を入口に、**大型の法人契約**を獲得する
- 個人マーケットの消耗から抜け、**高単価・安定・継続**の収入構造を作る
- 紹介が**経営者ネットワークで連鎖する**状態をつくる

## Before → After（変化の物語）

| | Before（現在） | After（プログラム後） |
|---|---|---|
| 面談 | 何を話すか毎回手探り | 決算書を起点に経営課題から入れる |
| 知識 | 商品知識のみ | 財務・相続・事業承継を提案に使える |
| 立場 | 「保険屋さん」 | 「経営の相談相手＝先生」 |
| 単価 | 個人契約中心で低単価 | 法人契約で単価が桁違い |
| 集客 | アポ取り・紹介依存で疲弊 | 経営者人脈が連鎖する |

## 刺さるメッセージ（コピーの素材）

セミナー名・LP・告知文に使う核フレーズ。

- 「**決算書が読めれば、保険は"売り込まなくても"売れる。**」
- 「個人マーケットで消耗するのは、もう終わりにしよう。」
- 「経営者は"保険屋"には会わない。でも"財務が分かる人"には会う。」
- 「相続・事業承継は、法人マーケットへの"最短の入口"。」
- 「商品知識を増やしても、法人は獲れない。獲れるのは"経営者の言葉"を話せる人。」

## ターゲット外（あえて狙わない）

メッセージをぼかさないために明記する。

- 保険・FP未経験の完全初心者（実務の土台がなく、伴走コストが高い）
- 副業・お小遣い稼ぎ目的の層（高単価バックエンドと不整合）
- 個人マーケットに満足しており現状維持で良い人

## このドキュメントの使い方

- **03 集客設計**の告知文は、ここの「痛み」と「メッセージ」から書く
- **04 セミナー設計**は、ここの「Before→After」を3日間で疑似体験させる構成にする
- **05 個別相談**のヒアリングは、ここの「痛み」を本人の口から言語化させる
