# 05. 個別相談・クロージング設計

> ファネルの最終転換点。「売り込む」のではなく「相手の現在地とゴールを整理し、最短ルートとして本商品を提案する」場。

## クロージング方針（2026/6/17 MTG決定）

- **最終日（Day3）にクロージング＋価格提示**。**個別相談は"必須"にしない**。
- **その場で即決済OK**：お金の不安がなく、やる気のある人は最終日にそのまま決済。
- **個別相談へ回すのは「迷っている／支払い分割の回数を相談したい」人**。→ 売れやすい層を逃さず、検討層だけ丁寧に拾う。
- **嘘の審査制（おさるマーケ流）**：「思いが揃う人だけ」という建付けで、熱量の低い人はお断り。3日間完走＝Facebookグループで振り落とした後なので、残った人はやる気が一定担保される。
- **割引はしない**（情報商材っぽくなる／30万でも安いという前提）。代わりに**期限付き特典**で背中を押す（「今日中に決めたらこれをプレゼント」）。特典は量産可（→ `07`）。
- **予約導線**：個別相談は**TimeRex（カレンダー予約）リンク**で「アポを取ってください」（2026/6/22 確定）。
- **質疑応答はセミナー用サブ公式LINE**で受ける（後夜祭用の別オープンチャットは作らない → `06`）。
- ※ 価格は **30万で確定維持**（MTGで49.5万案も出たが採用せず → `02`/`06`）。
- **二つの支援モデル（2026/6/21）**：Day3クロージング・即決済は**プランA（30万・3ヶ月／学ぶ）**を基本提示。**プランB（300万・1年＋成果保証／伴走・Aを内包）**は高単価で対話が要るため、**個別相談を主戦場**に案内する（→ 下記「プランA/B の提示導線」）。

## 位置づけ

- セミナー完走者を中心に案内する**無料個別相談**（45〜60分想定）。**全員必須ではなく、即決済しない検討層が対象**。
- 目的：相手の課題を深掘りし、解決策＝バックエンド（**プランA 30万／プランB 300万伴走**）を**必要なものとして**提示する。特に**プランB（300万・伴走）は対話が要るため個別相談が主戦場**。分割・支払い相談にも応える
- 成約率はここで決まる。`00` のKPIでは相談→成約 30〜50% を目標

## 相談の流れ（型）

1. **アイスブレイク／前提合わせ（5分）**
   - 「今日は売り込みの場ではなく、◯◯さんの法人開拓の現在地とゴールを整理する時間です」と最初に宣言（警戒を解く）
2. **ヒアリング＝現在地の言語化（20分）**
   - 現状：今の営業スタイル・成績・法人での挫折経験
   - 痛み：何に一番困っているか（`01`の痛みを本人の口から）
   - 試したこと：これまでやってきた／うまくいかなかったこと
   - ゴール：1年後どうなっていたいか・なぜ
3. **ギャップの可視化（10分）**
   - 現在地とゴールの「差」と、独学で埋める場合の時間・リスクを一緒に整理
4. **解決策の提示（10分）**
   - そのギャップを最短で埋める道として**プランA/B（`02`の二つの支援モデル）**を提示。ゴール（相談役として成果を出す）を先に握り、そこへの2つの道として見せる
   - **本気度・予算・目的から主推奨を1つに絞る**（選択肢を出しすぎない原則は維持。判断軸は下記「プランA/B の提示導線」）
5. **クロージング（10分）**
   - 価格提示 → 沈黙して待つ → 質問・不安に対応 → 意思決定の後押し

## ヒアリングの質問例

- 「法人を獲りたいと思った"きっかけ"は何ですか?」
- 「社長との面談で、一番困るのはどの瞬間ですか?」
- 「これが解決したら、収入や働き方はどう変わりそうですか?」
- 「逆に、このまま個人マーケットを続けると1年後どうなっていそうですか?」（現状維持のリスク自覚）

## 価格の伝え方（高単価を正当化する）

- **投資対効果で語る**：「法人契約1件で受講料は回収できる」（`02`の論理）
- **時間で語る**：独学で数年 → 数ヶ月。機会損失の方が大きい
- 価格は**自信を持って一度だけ提示し、沈黙して相手に渡す**（埋めようとしない）
- **割引はしない**：値引きは情報商材的に見え価値を毀損する。代わりに**期限付き特典**で動機づけ（→ `07`）
- **分割は"回数相談"で対応**：金額を下げるのではなく支払い方法で柔軟に（個別相談の主目的の一つ）
- **二段の価格（A/B）**：まず**A（30万）**を基本に、本気で成果まで出したい層へ**B（300万・伴走）**を提示（詳細は下記「プランA/B の提示導線」）

## プランA/B の提示導線（二つの支援モデル｜2026/6/21）

> `02_商品設計.md` の**プランA（30万・3ヶ月／学ぶ）**と**プランB（300万・1年＋成果保証／伴走・Aを内包）**を、個別相談でどう提示するか。原則は変えない＝**ゴールを先に握り、そこへの道として見せ、主推奨は1つに絞る**。

### 2プランの要約（相談で見せる）

| | プランA：マスターコース（学ぶ） | プランB：伴走支援（成果まで伴走） |
|---|---|---|
| 価格 | **30万・3ヶ月** | **300万・1年＋成果保証**（仮） |
| ゴール | 基礎を固め、初商談〜初契約まで**自走**できる | 共同募集・本業連携まで含め、**成果が出るまで伴走** |
| 向いている人 | まず自分で動ける状態が欲しい／予算は抑えたい／法人は"試す"段階 | 法人を**本気の柱**にしたい／成果まで伴走してほしい／一緒に売りたい（共同募集）／時間を金で買いたい |
| 決め方 | Day3即決済もOK | 高単価・対話が要る＝**個別相談が主戦場** |

### 提示の順番（アンカリング）

1. **ゴールを先に握る**：「相談役として、実際に法人で成果を出す」状態を合意する。
2. **全体像＝Bから見せる**：1年伴走・成果保証・**共同募集（成果分配。例：FP7割）**までの到達点を見せる（価値の天井を先に）。
3. **その"入口・一段"としてA**を置く：「まずここから入って、自走できる人はそのまま、成果まで伴走してほしい人はB」。Aが**安く・自然に**見える。
4. **主推奨を1つに絞る**：下の判断軸で、相手に合う方を**1つ**強く推す（選択肢を並べて迷わせない）。

### 主推奨の判断軸

- **A主推奨**：予算を抑えたい／まず学んで自分で動きたい／法人は試行段階／独学不安の解消が主目的。
- **B主推奨**：法人を**本気の柱**にしたい／成果（初契約・本業案件）まで伴走を求める／共同募集で一緒に売りたい／既にある程度動けるが伸び悩み・時間を買いたい。

### クロージングの実務

- **割引はしない**（両プラン共通）。動機づけは**期限付き特典**（→ `07`）。
- **分割は"回数相談"**で対応（特にB＝300万は支払い方法で柔軟に。金額は下げない）。
- **B特有の価格正当化**：共同募集の**分配だけでも回収余地**（例：FP7割）／本業案件は1件が桁違い／**1年伴走＋成果保証でリスクは低い**。
- **A→Bアップグレード**：Aで受講後、成果志向が高まった人をBへ引き上げる（循環エンジンの③→④。→ `docs/mtg/2026_06_21_FP循環モデル_まとめ.md`）。

> ※価格・成果保証・分配率はすべて**仮**（→ `06`）。確定後に本節を更新。

## よくある反論と対応（Objection Handling）

| 反論 | 背後の本音 | 対応の方向 |
|---|---|---|
| 「お金が…」 | 価値 < 価格に見えている | 1契約で回収できる投資対効果を再提示／分割の選択肢 |
| 「時間が…」 | 優先順位・成果イメージ不足 | 必要な稼働量を具体化／伴走で挫折を防ぐ設計を説明 |
| 「自分にできるか不安」 | 自己効力感の不足 | 同じ状態から成果を出した例／サポート体制・保証を提示 |
| 「持ち帰って考えたい」 | 決断の先延ばし | 何が決まれば前に進めるかを一緒に特定／限定・締切を確認 |
| 「300万は高い」(B) | 価値 < 価格／回収イメージ不足 | 共同募集の分配だけでも回収余地（例FP7割）／本業案件は1件が桁違い／1年伴走＋成果保証でリスクは低い。難しければまず**A（30万）から入りB昇格**も可 |

> 反論は"拒否"ではなく"未解消の不安"。潰しにいくのではなく、一緒に解消する姿勢で。

## 成約率を上げる仕掛け

- **関与度の高い人を優先**：課題完走者・感想提出者から案内
- **社会的証明**：セミナー参加者の感想・実績を相談前後で共有（`03`へ再利用）
- **正当な限定・締切**：「今期は◯名まで」「募集は◯日まで」（理由を添える）
- **期限付き特典で即決を後押し**：「◯日までに決めた方へ」と特典を提示（**割引はしない**／`07`）
- **嘘の審査制**：「思いが揃う方だけ」と伝え、参加価値・本気度を高める
- **保証でリスクを下げる**：`02`のリスクリバーサルを提示

## 成約後・不成約後

- **成約**：オンボーディング（プログラム開始の流れ・初回案内）。実績は次回の素材に
- **不成約**：関係を切らない。公式LINEで継続フォロー → 次回セミナー/募集で再接点
