# 原稿テンプレート（コピーして使う）

> これは deck 1つ分の**原稿（中身）テンプレート**。コピーして `docs/<deck>/manuscript.md`
> にリネームして使う。ここには**中身だけ**を書く — 色・フォント・スライドレイアウト・
> スライド枚数は書かない（それらは `deck-strategy` と `theme.json` が決める）。

## メタ（deck-strategy が最初に固定するもの）

- **deck 名**：
- **聴き手（audience）**：誰に向けるか。役割・前提知識・温度感
- **場面（scene）**：いつ・どこで見せるか（例：Day1 セミナー冒頭 / 個別相談中 / 事前配布）
- **ゴール（goal-action）**：見た後に聴き手に**取ってほしい1つの行動**
- **メインメッセージ（main message）**：1文。この deck が結局言いたいこと
- **語りの枠（narrative frame）**：どういう筋で運ぶか（例：WHY→HOW→GAP）
