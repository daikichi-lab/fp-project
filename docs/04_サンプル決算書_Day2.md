> Day2前半「相談役の実演＝見る→聞く→提案」で使う**1ケース**。すべて **仮の数値**（中小企業の"簡単な案件"に寄せた典型例）。

## 5. 相談役の読み筋（見る→聞く→提案）

> **【2026/6/22 更新】** 以下の"読み筋"は旧アプローチ（相続・自社株中心）。**現行Day2は「お金の漏れ（売掛・在庫・借入返済・役員借入の痕跡）を見つけて語る」未来会計版**＝`04_台本_Day2.md` が正。BS/PLの数値（§2〜4）はそのまま流用。なお §3 提案表の『特例承継計画の期限 2027/9/30』は社内で割れており要・税理士確認（前面に出さない）。

### ①見る（最重点）＝ 決算書から"違和感"を拾う
Day2前半で一番時間をかけるパート。**精緻計算でなく「気づき」**で十分。

| 見る場所 | 拾う違和感 |
|---|---|
| **役員借入金 20** | 社長個人 → 会社への貸付。相続時に「貸付金」として**額面で相続財産**になりがち |
| **保険積立金 5 だけ** | 退職金・保障の準備がほぼ無い。社長62歳で勇退が近い |
| **利益剰余金 35（株価膨張）** | 自社株評価が上がり、長男への**承継時に税負担** |
| **自己資本比率 26%＋借入70** | 社長に万一のとき、借入返済の原資は？（事業保障の空白） |

### ②聞く（仮説を立てて確かめる）＝ 見て立てた仮説をぶつける
※質問の丸暗記ではなく、**①で立てた仮説を確認する形**で聞く（重点①＝初回面談の立ち回り）。

1. 「この**役員借入金2,000万**、社長が会社に貸しているお金ですよね？ 対策しないと、相続のとき額面で財産に乗りますよ。ご存じでしたか？」
2. 「退職金の準備、この**保険積立金500万**だけですか？ 社長、勇退は何歳頃をお考えですか？」
3. 「利益が出て**内部留保が貯まっています**ね。株価、毎年上がっています。後継は専務（息子さん）？ 自社株の評価額、見たことはありますか？」
4. 「社長に万一のとき、この**借入はどなたが返しますか**？」

> 狙い：1つでも「えっ、知らなかった」が出れば、社長は前のめりになる＝相談役のポジションが取れる。

### ③提案（方向を示す＝クロージングはしない）
Day2では"方向性"まで。具体設計はバックエンド。

| 課題 | 保険・対策の方向 |
|---|---|
| 退職金準備不足＋株価対策 | **役員退職金の準備**（長期平準/逓増定期 等）。勇退期の退職金支給で**利益圧縮→自社株評価も下げる**タイミング設計 |
| 役員借入金の整理 | 生前の整理（DES 等）＋万一の**納税資金**を保険で |
| 事業承継・自社株 | 後継への承継で生じる税の**納税資金**を保険で。**特例承継計画の期限 2027/9/30** のさわりに接続 |
| 保障の空白 | **事業保障保険**（借入返済原資）。受取人・必要保障額を設計 |

## 6. 講師メモ（Day2前半で使うポイント）

- **見せ方**：まず決算書を画面に出し「どこが気になりますか？」と問いかけ → 参加者に"見る"を体験させてから、相談役の着眼を重ねる。
- **強調**：「**精緻な計算はいらない。違和感に気づいて、仮説で聞くだけ**」＝ 基礎で十分・完璧不要（バックエンドの世界観と一致）。
- **Day3への布石**：自社株の**正確な評価**や税務の細部は「ここから先は本当に難しい」＝ Day3の"壁"で体感 → 基礎＋藤山バックアップへ。
- **数値はすべて仮**：本番用に1社、できれば**業種違いの予備1社**を用意するとリピート開催に強い。
