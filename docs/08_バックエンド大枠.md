## 1. コンセプト（表紙）

**「会計を武器に、FPが法人で保険を売れるようになる」3ヶ月集中プログラム。**

会計（決算書・財務）は目的ではなく、**経営者に保険を売るための"武器"**。会計が分かれば、経営者と対等に話せ、**相続・事業承継**という大型の保険ニーズにも踏み込める。

> **到達ゴール（2026/6/17〜18・追補）**：3ヶ月で**初商談〜初契約**まで（OK確認＝下表 差別化①と整合）。**基礎を固める**ことに集中し、**難しい内容はその都度 藤山＝フジヤマ氏に相談が上がる流れ**（受講者は基礎／専門領域はバックアップ）。**教える重点＝①初めて経営者と話すときの立ち回り ②決算書→提案への変換**、**＋相続・事業承継も込み**（中小企業オーナーの身近なニーズとして基礎を扱う／複雑な実務は藤山へ）。扱うケースは**中小企業に寄り添った"簡単な案件"中心**（難しい案件は少なめ）（→ `02`/`06`）。

## 2. 差別化（★市場リサーチの最重要結論）

「会計×法人保険」を教える講座は**すでに複数存在**（SHE／ミライbase／ゼットラボ／保険セールス実践塾 等）。
→ **「会計を扱うこと」自体は差別化にならない。** 売りは下の3つの"隙間"に置く：

| 差別化軸 | 既存市場 | 本プログラムの立ち位置 |
|---|---|---|
| **① 短期・成果コミット** | サブスク無期限 or 1年以上拘束 | **3ヶ月で"初商談〜初成約"まで**持っていく設計（ほぼ空白地帯） |
| **② 翻訳の実践** | 財務知識の"インプット止まり" | **決算書 → 売れる提案トークへの変換**（ロープレ・案件添削・同行） |
| **③ 個人→法人の橋渡し** | 「すでに法人をやる人」向け中心 | **個人FP/保険営業からの転換**に特化した伴走 |

> 一言キャッチ：**「会計を"売れるトーク"に変える、3ヶ月・成果コミットの実践伴走」**。

## 4. プログラム構成（月1回×2日間研修 × 3ヶ月＝計6日）

> 提供形態：**月1回の2日間研修を3ヶ月**（3セッション／計6日）。各日 **10:00〜17:00**（昼休憩含む・実質約6時間）→ **計約36時間**。研修間の約1ヶ月は**実案件に取り組む期間**とし、次回に持ち寄って添削する（＝差別化②「実践伴走」・成果コミットの担保）。
> 設計思想：1ヶ月目で「会計＝武器」の土台 → 2ヶ月目で保険・相続の専門武器 → 3ヶ月目で承継・営業の実戦化。会計は常に「保険提案につなげる」文脈で教える。

### 1ヶ月目（Day1-2）：会計を"武器"にする
| | 内容 | 到達目標 |
|---|---|---|
| Day1 AM | 決算書①（BS）— 役員借入金・保険積立金・自己資本比率 | BSから保険の着眼点を3つ指摘できる |
| Day1 PM | 決算書②（PL・CF）— 利益構造・退職金ニーズ・債務償還年数 | PLから利益水準と退職金準備ニーズを語れる |
| Day2 AM | 財務分析（安全性・収益性・生産性）＋実態BS | 表面利益と実態の乖離を見抜ける |
| Day2 PM | ★**課題発見→保険提案マトリクス**（演習） | 決算書から提案ストーリーを組める（★核） |
| 〜次回 | 実案件：見込み先の決算書を1社分析し課題仮説を作る | — |

### 2ヶ月目（Day1-2）：法人保険・相続を提案に変える
| | 内容 | 到達目標 |
|---|---|---|
| Day1 AM | 法人保険①（現行税務）— 2019通達4区分・30万特例・事業保障 | 現行の損金ルールを正確に説明できる |
| Day1 PM | 法人保険②（出口戦略）— 役員退職金・功績倍率・ハーフタックス・名義変更封じ | 出口設計込みで提案できる |
| Day2 AM | 相続対策の基礎 — 基礎控除・保険金非課税枠・配偶者軽減・二次相続 | 相続の必要保障額を試算できる |
| Day2 PM | 自社株評価と株価対策 — 類似業種比準/純資産価額38%・退職金で圧縮 | 自社株対策と保険を結びつけられる |
| 〜次回 | 実案件：分析した1社に保険提案の骨子を作る | — |

### 3ヶ月目（Day1-2）：事業承継・営業実戦
| | 内容 | 到達目標 |
|---|---|---|
| Day1 AM | 事業承継 — 特例措置/一般措置・期限（計画2027/9/30・実行2027/12/31）・取消リスク・M&A基礎 | 選択肢と期限を正確に案内できる |
| Day1 PM | 営業手法・士業連携・コンプラ — 決算書入手トーク・紹介連鎖・保険業法/税理士法 | 法令を守って紹介・士業連携を設計できる |
| Day2 AM | 統合ロールプレイ①（課題発見〜提案） | 決算書サンプルで提案を組み立てられる |
| Day2 PM | 統合ロールプレイ②（クロージング）＋実践計画 | 提案〜クロージングを一気通貫で完遂 |

**比重**：会計・財務（1ヶ月目）約33%／保険・相続（2ヶ月目）約33%／承継・営業・実戦（3ヶ月目）約33%。各月の最後（Day2 PM）で必ず「保険提案」に着地させる。

## 5. 教える6ドメイン（柱）

1. **決算書の読み方**（BS/PL/CF）— 役員借入金、保険積立金、債務償還年数など"保険の着眼点"
2. **財務分析 → 課題発見 → 保険提案**（安全性・収益性・生産性／同業種比較）
3. **法人保険の種類と現行税務**（★2019年通達、ハーフタックス、役員退職金、事業保障）
4. **相続対策**（基礎控除・保険金非課税枠・自社株評価）
5. **事業承継**（特例措置／一般措置・期限・納税猶予）
6. **経営者アプローチ・営業・コンプライアンス**（決算書入手トーク、紹介連鎖、士業連携の法規制）

## 7. コンプライアンスの核心（教材で必ず扱う）

- **2019年通達の損金4区分**：最高解約返戻率 50%以下=全額損金／50%超70%以下=40%資産計上／70%超85%以下=60%資産計上／85%超=当初10年は返戻率×90%資産計上。＋「年30万円特例」。
- **養老保険ハーフタックス（1/2損金）は2019改正の対象外で現行も有効**（要件＝普遍的加入）。
- **名義変更プラン封じ**（2021/7/1〜、資産計上額70%基準）。
- **士業連携の落とし穴**：士業が「商品の推奨・説明」をして実績連動報酬を得ると**無登録の保険募集（保険業法違反）**になり得る。**税務相談は税理士の独占業務**＝募集人の個別具体的な節税助言はNG。一般的知識にとどめ個別は税理士へ。
