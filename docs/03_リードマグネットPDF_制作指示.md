# 03（制作）. リードマグネットPDF 制作指示 ―「FPが仕事を取れない理由がわかるPDF」

> 用途：**FP専用オープンチャット参加者へ、最初に渡すウェルカム・プレゼント**（参加直後の信頼づくり＋相談役の世界観づくり）。**チラ見せはせず、完成品を丸ごと渡す**。
> 位置づけ：`03_集客設計.md` の動線 **メイン公式LINE → FP専用オープンチャット → サブ公式LINE → Facebookグループ** で、**参加直後の第一印象を作り、次（無料3日間チャレンジ）への期待に繋ぐ**役。※"参加を促す"告知（この贈り物を餌に参加させる）は**別バナー**＝`03_告知スケジュール・バナー制作指示.md` ⑥6/19「オープンチャット案内」・7/1「プレゼント告知」。本書は**単体で完結する読み物（カルーセル/PDF）**。
> 作り方の思想：ノンデザイナーの**判断基準**（①目的1行 ②読者の状態 ③文字を短く ④失格条件 ⑤人間が最終判断）に沿って Claude Design に渡す。本書はそのまま指示プロンプトとして使える。
> **未確定（仮）**：オープンチャット名・参加URL/QR・最終コピー文言の確定（→ `07`／来週目安）。本書のコピーは**叩き台**。
> **2026/6/24 更新**：判型を**pptx（16:9・紺×金）／全20枚**に変更（旧＝正方形カルーセル7枚）。**最新の構成・コピーは `03_リードマグネットPDF_スライド原稿.md` と `docs/slides/`（`_leadmagnet_data.py`＋`build_leadmagnet.py`）を正とする**。本書は5原則の"作り方の作法"が主目的。

## 0. 何を作るか（一言）

**オープンチャットに参加したFP・保険営業が、「保険屋として行くから取れない／"数字"から入れば相談役として頼られる」と腑に落ち、"この場は価値がある・続きを知りたい"と感じる、20枚のpptxスライド（参加直後のウェルカム・プレゼント）。**

- 形式：**pptx（16:9・紺×金）／全20枚**（`docs/slides/` の Day1-3 と同じエンジン）。必要なら PDF・画像へ書き出し可。
- 出力：`build_leadmagnet.py` → `リードマグネット_FPが仕事を取れない理由.pptx`。表紙は参加促進バナー（別物）にも流用可。
- ゴール：**読後に「この場は価値がある／会計を武器に相談役になれる」と感じ、来る無料3日間チャレンジの案内を心待ちにする**。途中で「これ、自分のことだ」と刺されば成功。

## 1.【目的を1行で】

> **個人マーケで頭打ちのFP・保険営業が、「保険屋として行くから取れない／相続・事業承継が分かれば相談役になれる」と気づき、続きを読むためにFP専用オープンチャットへ参加したくなるPDF。**

- 売り込まない。**痛みの自覚 → 希望の提示 → 「続きはチャットで」**だけ。
- このPDF単体で**価格・セミナー詳細・バックエンドは出さない**（オープンチャットに入れてから段階的に。`04`/`03`方針）。

---

## 2.【読者の状態】（＝ターゲット。`01_ターゲット設計.md` 準拠）

```
対象読者：
- FP・保険営業の実務者（経験3年以上／30〜50代）
- 個人マーケットはこなせるが、ここ数年で頭打ち。単価を上げたい
- 法人に挑戦したいが、社長に会っても何を話せばいいか分からない
- 決算書を見せられると固まる。相続・事業承継の"提案の型"がない
- 「保険屋」扱いされ、門前払いされる感覚に薄々気づいている
- でも「高額セミナー」「情報商材」っぽいものは警戒している
```

**この読者に効くこと**：抽象的な「便利」より、**"自分も社長にそう見られている"という痛みの言語化** → **"何が分かれば変わるか"の具体（相続・事業承継）**。専門用語は減らす（「管理会計」等の語は使わない）。煽り・金ピカ・情報商材臭は逆効果（警戒される）。

---

## 3.【文字を短く】（全枚共通の制約）

```
- 1枚＝1メッセージ。画像内の主要テキストは最大2要素（メイン＋補助）。
- メインコピー：7〜14文字。ゴールド箔・最大級。
- 補助コピー：1行・20文字以内。白・小。
- 比較/箇条は「短い名詞句」で（文章で書かない）。1項目12文字目安。
- 長い肩書き・説明文・但し書きの本文化は禁止（コンプラ注記は最小・小さく）。
- 余白を恐れない。文字を詰めるくらいなら、枚数を分ける。
```

> **最新の構成・コピーは `03_リードマグネットPDF_スライド原稿.md`（全20枚・pptx）を正とする**。

## 5. ビジュアル仕様（ブランド統一＝`03_告知` と同じ紺×金）

- **配色・質感**：ダークネイビー〜黒のグラデ背景 ＋ **ゴールドの光・粒子**。高単価・高級・落ち着き（**金ピカ・ネオン・パチンコ風は禁止**）。
- **メイン見出し**：**ゴールドのメタリック箔**＋白の差し色。極太ゴシック、強い視認性。**1画面1メッセージ**。
- **上部**：細いリボンに「**藤山プロジェクト**」（ブランド担保）。
- **下部**：ゴールド帯 or 赤帯に**まとめ一言**（最終枚はCTA帯）。
- **要素分割**：ゴールド丸枠＋数字（①②③）で3〜4個まで。
- **キャラ**：藤山の似顔絵を右下に小さく配置可（信頼・親近感／毎枚は不要、表紙とCTAに）。
- **トーン＆マナー**：誠実・専門家・静かな説得。**煽り/誇大/情報商材臭は失格**。

## 6.【失格条件】（1つでも当てはまれば作り直し）

```
失格条件：
- 3秒で「FP向けの、仕事が取れない理由のPDF」だと分からない
- メインコピーが15文字超／一覧・スマホで読めない小ささ
- 1枚に主役メッセージが2つ以上（情報過多）
- 背景と文字のコントラストが弱い（ゴールド文字が背景に溶ける）
- 金ピカ・過剰ネオン・パチンコ風・安いAI未来感
- 煽り/誇大（「絶対」「誰でも」「○○万円稼げる」等）＝情報商材臭
- 税の具体数字（控除率・株価評価額など）を断定で載せている ※全文PDFでも【要・税理士確認】必須
- 価格・セミナー名・バックエンドを出している（この段階では出さない）
- すでに参加済みの相手に“オープンチャットに参加”等の矛盾CTAを置いている／最終枚が"次の一歩（通知ON・無料セミナーへの期待）"に繋がっていない
- 「管理会計」などの専門用語が前面に出ている
- 実在ロゴ・商標・保険会社名・実在人物に寄せている
```

## 7.【人間が最終判断】（出力後、塩尻が最低限チェックする5つ）

1. **3秒で何のPDFか分かるか**（FP向け／仕事が取れない理由／続きはチャット）
2. **スマホ一覧で文字が読めるか**（メイン7〜14字・高コントラスト）
3. **主役が1枚1つに絞れているか**（②③で情報が渋滞していないか）
4. **ブランドと読者の期待からズレていないか**（高級・誠実 ／ 煽り・情報商材臭が出ていないか）
5. **実在ロゴ・商標・人物・税の断定**に踏み込んでいないか（コンプラ＝税理士法・保険業法／情報提供にとどめる）

> 「AIが出したから正しい」ではなく、**伝わるか・ブランドを傷つけないか・審査やコンプラに触れないか**は人間が最終判断する。

## このドキュメントの使い方

- **コピーは本書（自社資料発）／デザインは紺×金ブランド**（`03_告知スケジュール・バナー制作指示.md` の共通仕様、`docs/sample/` は質感・構図のみ参照）。
- 痛み・比較の出典＝`01_ターゲット設計.md`（Before→After）＋`research/経営者の保険屋イメージ・断り文句_リサーチ.md`（敵視・断り文句）。相続/事業承継の"頼られる力"＝`03_告知` ③の丸アイコン②③と整合。
- 動線（オープンチャット→サブ公式LINE→…）と限定・締切の方針は `03_集客設計.md`／`06_意思決定ログ.md` と同期。
- **税・保険のコンプラ**：本PDFは税の具体数字を載せない（概念のみ）。全文PDF・後続資料で数字を出す場合は `research/知識ドメイン_リサーチ.md` 準拠＋**【要・税理士確認】**（税理士法・保険業法＝情報提供にとどめる）。
- 確定後：オープンチャット名・参加URL/QR・全文PDFの実体（→ `07`）を差し込み、本書の（仮）を解消する。
