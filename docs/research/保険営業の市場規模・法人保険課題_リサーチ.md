## 4. 法人保険の課題 ― 「節税で売る時代」の終焉

- **バレンタインショック（2019/2/14）**：国税庁が法人定期保険の損金算入見直しを表明→各社一斉販売停止〔金融庁・高〕。
- **通達 9-3-5の2**：保険期間3年以上・**最高解約返戻率50%超**は区分に応じ資産計上。**適用＝2019/7/8以後契約**〔国税庁No.5364/5364-2・高〕。
  - 50〜70%→40%資産計上／70〜85%→60%／**85%超→最大90%資産計上（＝全損消滅）**／例外：70%以下かつ年換算保険料30万円以下は全額損金。※`知識ドメイン_リサーチ`と整合・提示時に国税庁一次再確認。
- 改正前は**全損/半損の逓増定期・長期平準**で課税繰延スキームが普及〔税務研究会・中〕。
- **2021 ホワイトデーショック**：低解約返戻金期間の**名義変更プラン**も封鎖。**金融庁・国税庁が監視強化（2022）**〔金融庁・高〕。
- **統計上の注意**：法人（経営者）保険は協会統計で**「個人保険」に合算**＝単独の時系列は存在しない〔生命保険協会脚注・高〕。「1兆円市場消滅」は見出しレベルで一次裏付けなし〔低〕。
- **シフト**：節税 → **保障・事業承継・役員退職金・福利厚生**。「節税トークが消え、財務・承継の文脈で価値を語れないと売れない」＝**販売の高度化**。
- 含意：知識ハードルが上がった分、**学んだ営業には参入障壁＝チャンス**（Day3「独学の壁→講座」のロジックを補強）。

## 6. コピー／ペルソナに使える代表値（厳選）

1. 個人は飽和：**世帯加入率89.2%／死亡保障額は2009年以降一貫減（1,936万・2024）** → 新規は奪い合い、単価は縮小。
2. 続けるリスク：**5年目在籍率25%**＝5年で約75%が脱落。**MDRT級は2%だけ**、平均500万 vs MDRT1,400万＝3倍。
3. 法人は高単価×少件数：頭打ちは「件数・単一商品・士業連携なし」が共通。法人は少件数で高収益。
4. 市場機会：**127万社が後継者未定／黒字廃業が半数／後継者不在50.1%** → 相談役需要は桁違い。
5. 追い風：**節税で売る時代は2019年に終了**（通達9-3-5の2）。**財務×保障×承継で語れる人が勝つ**＝学んだFPの参入障壁。
