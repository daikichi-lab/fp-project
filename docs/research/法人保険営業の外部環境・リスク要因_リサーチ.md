# リサーチ：法人保険営業の外部環境・リスク要因（課題／過去ショック／今後の外部要因）

> 調査日：2026年6月26日。Web横断（並列調査）＋`知識ドメイン_リサーチ.md`（税務の真実の源）。確度〔高=一次・官公庁/大手紙／中=業界解説・大手シンクタンク／低=観測・議論段階〕。
> 用途：セミナーで「**営業マン個人では動かせない構造変化＝だから今、学んで立ち位置を変える**」という危機感・WHYの外部根拠。`01ターゲット`／`04`Day1-3／`05`個別相談。

## 0. 一言で（この資料の主張）

法人保険営業を取り巻く外部環境は、**①個人マーケットの構造的縮小 ②節税モデルの制度的終焉 ③規制・資本・税制の三重圧力 ④事業承継の時限**——のすべてが**同じ一点を指している**：

> **「商品（特に節税・貯蓄性）で売る」モデルは外部要因で寿命が縮み続け、AI・比較・規制に代替されない「経営者の相談役（財務・保障・承継の当事者支援）」だけが生存線。**

これは精神論でなく、官公庁データと施行スケジュールで裏付く。**営業マン個人の努力では変えられない＝だから学んで立ち位置を変えるしかない**、がセミナーの背骨。

## 1. 法人保険営業マンの課題（"個人の壁"）

### 1-1. 個人マーケットは構造的に飽和〔一次・高〕
- 世帯加入率 **89.2%（2024）**／1994年の**95%がピーク**、以後微減＝**未加入世帯はほぼ残らず、新規は奪い合い（リプレイス）**。
- 世帯 普通死亡保険金額 **2,255万(2018)→1,936万(2024)・2009年以降一貫減**＝**頭数も単価も縮む**。
- 出典：生命保険文化センター／生命保険協会『生命保険の動向2025』。

### 1-2. 所得は頭打ち・脱落は激しい
- 平均年収 **約500万円**（男497.5/女306.1・賃金構造基本統計2024）〔中〜高〕。**MDRT級は約2%**、平均500万 vs MDRT1,400万＝約3倍〔中〕。
- **入社5年目在籍率25%**＝5年で約4人に3人が脱落（主要8社・日経2025）〔高〕。

### 1-3. 法人参入の壁（定性・複数ソース一致〔中〕）
| 壁 | 中身 |
|---|---|
| 会えない | 「保険屋」の顔では門前払い、社長は「税理士に任せている」で弾く |
| 読めない | **決算書が読めない**＝話の糸口がない（最大の壁・講座コンセプト直結） |
| 型がない | 法人保険・相続・事業承継の提案フレームを持っていない |
| 教わる場がない | 社内研修は商品知識止まり。法人開拓を教える人がいない |
| 連携できない | 税理士の信頼を得て紹介をもらう入口がない |

### 1-4. 法人保険そのものの難化
- 2019年以降「**節税で売る**」が封じられ、**保障・財務・事業承継の文脈で価値を語れないと売れない**＝販売の高度化。本質は「節税」でなく「**課税の繰延べ**」で、**出口（退職金等）を契約前に設計しないと"ただの先送り"**（知識ドメイン）。

## 2. すでに起きた外部ショック（過去＝地殻変動）

| 時期 | 外部要因 | 内容 | 確度 |
|---|---|---|---|
| 2019/2/14 | **バレンタインショック** | 国税庁が法人定期保険の損金算入見直しを表明→各社一斉販売停止 | 高 |
| 2019/7/8〜 | **通達9-3-5の2（4区分）** | 最高解約返戻率50%超は資産計上。**85%超→当初10年は返戻率×90%資産計上＝全損消滅**（例外：70%以下かつ年30万以下は全額損金） | 高 |
| 2021/7/1〜 | **ホワイトデーショック** | 所得税通達36-37改正で**名義変更プラン封じ**（低解約返戻金型の権利移転を資産計上額で評価） | 高 |
| 2022/7 | **金融庁×国税庁の連携強化** | 商品審査・モニタリング両段階で情報共有。節税商品の事前照会体制が恒常化 | 高 |
| 長期 | **個人保険の縮小** | 加入率95%→89.2%、死亡保障額の一貫減、顧客の高齢化（新契約の若年層比率低下） | 高 |

> 含意：「節税商品売り」モデルは**一過性でなく恒常的に潰され続ける**。次の主戦場（外貨建て一時払い）も既に規制入り（§3-B）。

## 3. 今後発生しうる外部要因（これから来る）

### 3-A. 税制（確定／予定／議論）

| 外部要因 | 時期・状態 | 営業への含意 | 確度 |
|---|---|---|---|
| **事業承継税制 特例の"崖"** | **適用（贈与・相続の実行）期限＝2027/12/31（法人版）は据え置き・延長見込みなし**。特例承継計画の提出期限は2027/9/30へ延長の方向（令和8年度大綱・法案待ち／※市中に旧2026/3/31残存＝要税理士確認） | **「使うなら今」の駆け込み根拠**。出口は動かない | 高（適用期限）/中（提出期限） |
| **自社株評価ルールの見直し** | 国税庁有識者会議2026/4開始、**引上げ方向**、早ければ**2028/1新方式** → 令和9(2027)年末までが現行ルールの"窓" | "今動く理由"の本命（期限が割れる承継計画より正確）。ただし**未確定＝断定しない** | 中/低 |
| **相続・贈与の一体化（生前贈与加算3→7年）** | 2024/1〜・**フル7年加算は2031/1相続〜**（段階移行）。延長4年分は計100万円控除 | 暦年贈与の駆け込み余地が縮む→**精算課税110万＋生保非課税枠**提案が有利化 | 高 |
| **相続時精算課税 年110万基礎控除** | 2024/1〜・既施行（持ち戻し不要） | 「精算課税＝全部足し戻し」の誤解を更新する提案ネタ | 高 |
| **退職所得控除の見直し** | **議論中・3年連続見送り**（2024/11再浮上）。勤続20年超の年70万円優遇が論点 | 役員退職金の出口を**前倒しする動機**。ただし**「削減確定」は誤り＝議論段階**と明示 | 事実中/今後低 |
| **退職金とDC一時金の通算「10年ルール」** | **確定・2026/1以後のDC一時金受給から**（5年→10年に延長） | 役員の退職金・年金の受取り順序/タイミング設計に即影響 | 高 |
| **純資産価額方式の控除38%** | 2026/4以後（37%→38%復帰） | 株価がわずかに下がる（納税者有利）＝前提が変わった更新ネタ | 高 |
| **生命保険料控除6万円（子育て世帯）** | 2026・2027年分の**時限**・**恒久化は見送り**（金融庁要望は通らず）。所得税のみ・+2万円 | **個人保険側**のフック（法人ではない）。「今のうち」根拠 | 高 |

### 3-B. 規制・市場（マクロ）

| 外部要因 | 時期・状態 | 営業への含意 | 確度 |
|---|---|---|---|
| **経済価値ソルベンシー規制（ESR）** | **適用＝2026/3末**（2025/4以降開始年度末の監査から）。ICS採択2025/1 | 負債を時価評価＝**「予定利率」概念が消え**、長期・固定の貯蓄性/一時払いは**資本コスト増→商品抑制・改定**の誘因 | 高（施行）/中（影響） |
| **顧客本位＋販売規制強化** | 外貨建一時払い「**4年で約6割解約**」を問題視→**2025/4にターゲット型機能の廃止・手数料率見直し**が窓販で拡大。共通KPI開示・販売後フォロー要請 | **「商品で売る・回転売買」モデルへの締め付け**。手数料の透明化 | 高 |
| **金利上昇・インフレ** | 日本生命が**40年ぶりに予定利率引上げ（2025/1）**、円建て貯蓄性が復活 | 既契約は固定で取り残し→**乗換提案の動機↑（FDと緊張）**。商品環境の転換 | 高（事実）/中（影響） |
| **新NISA「貯蓄から投資」** | 2024〜・恒久化・枠拡大 | 貯蓄性保険は運用効率でNISAに劣後＝**貯蓄性一本足の営業が苦しく**、役割分離（保障＝保険／資産形成＝NISA）へ | 高（制度）/中（競合） |
| **人口減・中小企業減** | 生産年齢人口 2020:7,508万→2043:5,969万（▲1,539万）。後継者不在50.1%・**2025年問題127万社・GDP22兆円** | 個人の頭数モデルは長期縮小／法人＝承継・相続は**今が需要のピーク帯** | 高 |
| **デジタル・AI・比較・組込型** | 進行中（比較サイト・ネット生保・embedded・生成AI） | 単純な商品仲介・比較は**中抜き**。AIに代替されない領域＝**相談役** | 中 |

## 4. 結論 ― 外部要因が指す"一つの方向"

過去ショック（2019/2021/2022）も、これから来る税制（2026-2028）も、マクロ（ESR・FD・金利・NISA・人口・AI）も、**すべて同じ結論に収束**する：

> **「節税」「貯蓄性」「商品比較」で売る入口は、外部要因で次々に塞がれていく。残るのは"経営者の数字に踏み込める相談役"だけ。**

- 営業マン個人では1つも変えられない＝**戦い方そのものを変える以外に道がない**。
- 法人＝承継・相続は**時限（2027/2028）**があり、**今がピーク帯**。「学ぶなら今」が外部要因で裏付く。
