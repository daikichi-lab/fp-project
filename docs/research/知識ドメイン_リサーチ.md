## ドメイン1：決算書の読み方（財務3表）

**BS（貸借対照表）— 保険営業の着眼点**
- 現預金水準（目安：月商1〜1.5ヶ月／総資産の約30%。業種差大【要確認】）
- 純資産（自己資本）＝会社の体力（自己資本比率30%以上で安定、50%以上で優良）
- 借入金（短期・長期、経営者保証の有無）
- **役員借入金**（社長→会社の貸付＝社長個人の貸付金債権。死亡時に額面で相続財産化→納税資金不足＝保険提案の最重要ポイント）
- 役員貸付金/仮払金（会社→社長。融資・税務でマイナス材料）
- **保険積立金・長期前払費用**（既加入の貯蓄性保険が読める）
- 含み損益（土地・有価証券・ゴルフ会員権・解約返戻金）

**PL（損益計算書）**
- 5つの利益（最重視は経常利益）、役員報酬、減価償却費、支払保険料（既加入保険が読める）

**CF（キャッシュフロー計算書）**
- 3区分（営業CFのプラス継続が最重要）、フリーCF＝営業CF＋投資CF
- 中小・非上場に**法的作成義務なし**（簡易CF＝当期純利益＋減価償却費で代用）。出典：[マネーフォワード](https://biz.moneyforward.com/accounting/basic/78664/)
- 債務償還年数＝借入金÷（経常利益＋減価償却費−法人税等）。10年以内健全。出典：[エフアンドエム](https://www.fmclub.jp/blog/zaimu/28)

**落とし穴**：中小は監査なしで数字操作されやすい／「実態BS」（不良債権・役員貸付金・含み損を控除）で見ると帳簿は資産超過でも実態は債務超過の例あり。
出典：[保険プロ.jp](https://hokenpro.jp/how-to-read-financial-statements/)／[上原会計事務所](https://u-ks.jp/column/company-management/loan-from-officers)／[経営力](https://www.keieiryoku.jp/column/detail/?id=88)

## ドメイン2：財務分析 → 課題発見 → 保険提案

**指標（同業種比較が原則。数値目安は業種差大【要確認】）**
- 収益性：粗利率、営業利益率（全業種平均約2.97%）、経常利益率、ROA（一般5%以上）、ROE（一般8〜10%以上）
- 安全性（最も使う）：自己資本比率（40%以上優良/20%未満注意/10%未満危険）、流動比率（200%理想/100%未満注意）、当座比率、固定比率
- 生産性：労働生産性、労働分配率（40〜60%【要確認】）
- 効率性：総資本回転率（目安1.0回）、損益分岐点比率（80%未満優良）

### ★課題発見→保険提案マトリクス（本プログラムの核）

| 決算書の状態 | 経営課題 | 保険提案 |
|---|---|---|
| 借入金が多い（経営者保証あり） | 死亡時の借入一括返済リスク | 事業保障保険・団信代替（保険金は雑収入課税で割増必要） |
| 利益が大きい | 役員退職金が未準備 | 長期平準/逓増定期で退職金原資（返戻金ピークと退任を合わせる） |
| 後継者がいない | 事業承継・自社株評価 | 事業承継保険（自社株買取・納税・代償分割）。後継者不在率50.1%（TDB2025） |
| 内部留保が厚い | 自社株評価高騰→相続税 | 株価対策（退職金で圧縮）＋納税資金を保険で |
| 役員借入金が多い | 貸付金債権が額面で相続財産化 | 納税資金準備＋出口（債務免除・DES）【要確認】 |
| 従業員数が多い | 退職金・弔慰金・定着 | 養老保険ハーフタックス（1/2損金、普遍的加入） |

出典：[エヌエヌ生命](https://www.nnlife.co.jp/bizd/death_risk/)／[TDB後継者不在率2025](https://www.tdb.co.jp/report/economic/20251121-successor25y/)／[freee](https://www.freee.co.jp/kb/kb-accounting/equity-ratio/)

## ドメイン3：法人保険の種類と現行税務 ★最重要

### 2019年通達（バレンタインショック）以降の現行ルール
法人税基本通達9-3-5改正＋**9-3-5の2新設**（令和元年6月28日発遣、契約日2019/7/8以後適用、遡及なし）。

| 最高解約返戻率 | 資産計上割合 |
|---|---|
| 50%以下 | 資産計上なし（**全額損金**） |
| 50%超70%以下 | 当期保険料×**40%** |
| 70%超85%以下 | 当期保険料×**60%** |
| 85%超 | 当初10年：返戻率×**90%**／11年目以降：返戻率×70% |

- **30万円特例**：返戻率70%以下かつ年換算保険料30万円以下/被保険者なら全額損金。
出典：[国税庁 No.5364-2](https://www.nta.go.jp/taxes/shiraberu/taxanswer/hojin/5364-2.htm)／[趣旨説明PDF](https://www.nta.go.jp/law/joho-zeikaishaku/hojin/200628/pdf/01-2.pdf)

### 名義変更プラン封じ（2021年）
所得税基本通達36-37改正。資産計上額の70%未満の契約の名義変更は「資産計上額」で評価。適用：2021/7/1以後。出典：[国税庁 36-37](https://www.nta.go.jp/law/tsutatsu/kihon/shotoku/05/04.htm)

### 現在も使える活用法
- **養老保険ハーフタックス（1/2損金）**：9-3-4(3)。**2019改正の対象外で現行有効**。要件＝普遍的加入。出典：[国税庁 No.5360](https://www.nta.go.jp/taxes/shiraberu/taxanswer/hojin/5360.htm)
- 逓増定期（早期ピーク→退職金）／長期平準定期（長期保障＋退職金）
- 役員退職金：退職所得＝（収入−退職所得控除）×1/2。控除＝20年以下:40万×年数／20年超:800万＋70万×(年数−20)。勤続5年以下役員は1/2なし。功績倍率法（社長3.0目安）。出典：[国税庁 No.1420](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1420.htm)
- 事業保障保険：返戻率50%以下の掛け捨ては全額損金。必要保障額＝借入返済＋運転資金（固定費6〜12ヶ月）

**落とし穴**：①出口戦略の欠如（節税＝繰り延べに過ぎず受取時益金課税）②返戻率ピーク管理失敗③過度な節税スキームの否認リスク④「1/2損金」など古い解説の残存

【要確認】退職所得控除の見直し議論（政府税調）／「2025年問題」（駆け込み加入の返戻金ピーク）の具体数値

## ドメイン4：相続対策

**基礎（2026年時点で変更なし）**
- 基礎控除＝3,000万円＋600万円×法定相続人
- 生命保険金の非課税枠＝**500万円×法定相続人**
- 相続税率10〜55%／配偶者軽減1.6億 or 法定相続分
出典：[No.4152](https://www.nta.go.jp/taxes/shiraberu/taxanswer/sozoku/4152.htm)／[No.4114](https://www.nta.go.jp/taxes/shiraberu/taxanswer/sozoku/4114.htm)／[No.4155](https://www.nta.go.jp/taxes/shiraberu/taxanswer/sozoku/4155.htm)／[No.4158](https://www.nta.go.jp/taxes/shiraberu/taxanswer/sozoku/4158.htm)

**自社株（取引相場のない株式）評価**
| 会社規模 | 原則的評価 |
|---|---|
| 大会社 | 類似業種比準100%（純資産選択可） |
| 中会社 | 類似:純資産を 0.9:0.1 / 0.75:0.25 / 0.6:0.4 で併用 |
| 小会社 | 純資産価額100%（類似0.5:純資産0.5 も可） |

- 類似業種比準：配当・利益・純資産を各1/3。斟酌率＝大0.7/中0.6/小0.5
- 純資産価額：含み益に**法人税相当額38%控除**（★2026/4以降。3/31以前37%）
- 配当還元：年配当÷10%×(1株資本金等÷50円)
出典：[No.4638](https://www.nta.go.jp/taxes/shiraberu/taxanswer/hyoka/4638.htm)／[財産評価基本通達186-2](https://www.nta.go.jp/law/tsutatsu/kihon/sisan/hyoka_new/08/04.htm)

**保険の役割**：①退職金原資（株価引下げと同時）②納税資金（自社株は売れない／保険金は現金化）③代償分割資金④争族対策（受取人指定で分割協議外）

**落とし穴**：受取人が相続人以外（孫・兄弟・放棄者）だと非課税枠×／配偶者軽減の使いすぎ→二次相続増税／控除率37%のまま記載

【要確認】★国税庁有識者会議（2026/4〜）で自社株評価方法そのものが見直し検討中（引上げ方向の可能性）。提案時は「現行制度は見直し議論中」を付言。出典：[有識者会議資料](https://www.nta.go.jp/about/council/nai-hyoka/20260420/pdf/01shiryo_kabukaigi.pdf)

## ドメイン6：経営者アプローチ・営業・コンプライアンス

**王道**：決算書診断を切り口にした課題提起型営業（保険ありきでない）／社長の関心事（節税・退職金・後継者・資金繰り・相続）と接続。

**決算書の入手実務**：BS・PL・販管費明細・**勘定科目内訳明細書（提案の宝庫）**・法人事業概況説明書。最低2期、できれば3期比較。

**紹介連鎖**：経営者交流会・法人会・商工会議所・青年会議所・ロータリー等。

**士業連携（コンプラが核心）**
- 士業が「具体的な商品の推奨・説明」をして実績連動報酬を得ると**無登録の保険募集（保険業法違反）**になり得る。安全側は「推奨・説明をせず情報提供のみ」。出典：[生命保険協会 募集関連行為ガイドライン](https://www.seiho.or.jp/activity/guideline/pdf/boshukanren.pdf)
- 「紹介料50%/30%」はガイドライン本文に明文なし＝実務目安【要確認】。出典：[legal-inc](https://legal-inc.co.jp/column-20220527/)
- 保険募集の再委託は保険業法275条3項で原則禁止／300条（断定的判断・特別利益提供の禁止）
- **税務相談は税理士の独占業務**：募集人の個別具体的な節税助言はNG（無償でも）。一般的知識にとどめる。出典：[国税庁 税理士法違反](https://www.nta.go.jp/taxes/zeirishi/zeirishiseido/qa/06.htm)

**トレンド（2024-2026）**：「節税商品」から「保障・事業保障・福利厚生・事業承継」へ軸足移動。出口戦略が要。

## ★2026/6/22 追加リサーチ（深掘り・要・税理士最終チェック／🔴＝流動的）

### 自社株評価の見直し＝"今動く理由"の主軸候補
国税庁「取引相場のない株式の評価に関する有識者会議」2026/4開始。是正の方向：
- **類似業種比準価額は純資産価額の約27.2%しかない**（中央値：類似11,622円／純資産42,648円）かい離の縮小。
- **会社規模区分の格差**（純資産価額に対する申告評価額の割合：大0.32／中0.50／小0.61）の是正。
- **配当還元の還元率10%＝昭和39(1964)年以来据置**の引下げ（＝評価UP方向）。
- 早ければ**令和10(2028)年1月から新方式** → **令和9(2027)年末までが現行ルールでの対策の"窓"**。
- 🔴 改正内容・施行日は未確定（決定事項として断定しない）。出典：国税庁有識者会議資料(2026/6/4)／ZEIKEN PRESS(2026/5)／森・濱田松本。
> 期限が割れている「特例承継計画」より、こちらが**正確で強い"今動く理由"**。Day1のWHYに使える。
- 純資産価額の控除38%は「令和7年度改正の防衛特別法人税創設に伴い37%→38%へ復帰（約10年ぶり）・2026/4以後」。控除UP＝株価はわずかに下がる（納税者有利）＝"2026/4で前提が変わった"更新ネタ。

### 役員退職金の"罠"（新規）
- **最終報酬月額をゼロ/著しく低額にして退職すると功績倍率法が使えず**「1年当たり平均額法」で再計算＝想定額が崩れる。"報酬を下げてから辞める"が裏目（KACHIEL／国税不服審判所）。
- 否認基準は原則「平均功績倍率法」（最高倍率法は例外）。東京地裁H25.3.22。

### 相続：精算課税110万＆7年持ち戻し（新規・2024〜）
- **相続時精算課税に年110万円の基礎控除（新設・2024/1〜）**：特別控除2,500万とは別枠、毎年110万までは贈与税ゼロ＋**相続財産に加算されない（持ち戻し不要）**。「精算課税＝全部足し戻し」という誤解の更新ネタ。
- 暦年贈与の生前贈与**持ち戻しが3年→7年（2024/1〜）**。延長4年分(3超〜7年)は合計100万円控除。フル7年が効くのは2031/1相続から（段階移行）。
- 死亡保険金非課税枠の引上げ（配偶者・扶養者加算）は**金融庁の要望段階＝未成立**。確定情報として語らない。

### 銀行格付：3ヶ月で効くレバー（新規・"明日使える"）
- **役員借入金（社長→会社）は銀行査定で"自己資本相当"に加算される**＝実質債務超過の判定が変わる。DESで正式に自己資本比率を改善。←経営者がほぼ知らない一手。
- **役員貸付金・仮払金を消す**：銀行が最も嫌う科目。税務上は正しくても格付では減点。決算前解消で印象一変。
- 売掛回収・在庫圧縮・支払サイト調整で正常運転資金を縮め、債務償還年数の分子を改善（数ヶ月で動く）。

### 法人保険の核トーク（既存「出口」論点の言語化）
- 2019通達後の本質＝「節税」でなく**「課税の繰延べ」**。損金で減った税は解約返戻金（雑収入）の出口で必ず戻る → **出口（退職金等）を契約前に設計していないと"ただの先送り"**。経営者が最も誤解する点。
