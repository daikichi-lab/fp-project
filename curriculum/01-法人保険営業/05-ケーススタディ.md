# 第5章　ケーススタディ

※本章は2025年度税制に基づく。適用時は最新の法令・通達・約款で確認。

本章では、具体的な法人を題材に、**保障設計 → 税務 → 退職金・承継準備**を統合した提案を組み立てます。数値はいずれも学習用の設定であり、実際の税額・返戻率・限度額は必ず設計書・顧問税理士・最新法令で確認してください（`〔要確認〕`）。

---

## ケース1：製造業・年商3億・社長60歳（事業保障＋退職金）

### 会社概要（設定）

| 項目 | 内容 |
|------|------|
| 業種 | 金属加工（製造業） |
| 年商 | 約3億円 |
| 従業員 | 25名 |
| 社長 | 60歳・最終報酬月額 150万円・在任30年 |
| 借入金 | 長期借入 8,000万円（社長の経営者保証あり） |
| 現預金 | 約4,000万円 |
| 株主 | 社長90%、長男（専務・35歳）10% |
| 後継者 | 長男（数年内に承継予定） |
| 既契約 | 事業保障目的の平準定期 3,000万円のみ |

### 課題の整理

1. **事業保障の不足**：借入8,000万円に経営者保証。社長に万一があれば、遺族・会社に返済負担が集中。既契約3,000万円では不足。
2. **退職金の未準備**：社長は数年内に勇退予定だが、退職金原資が積み立てられていない。
3. **承継の入口**：株式は社長90%。将来的な承継・納税資金の論点があるが、まずは保障と退職金を優先。

### 必要額の試算

**事業保障の必要額（概算）**

```
借入金 8,000万円 ＋ 固定費補填（月1,500万円 × 6か月＝9,000万円）－ 現預金4,000万円
≒ 1.3億円程度
```

既契約3,000万円を差し引くと、**追加で1億円前後の保障**が目安〔要確認〕。

**退職金の適正額の目安（功績倍率方式）**

```
150万円 × 30年 × 3.0倍〔要確認〕 ＝ 1億3,500万円
```

これは損金算入の目安であり、実際の支給額・妥当性は個別判断・規程整備が前提。

### 提案設計

社長勇退（数年内）と事業保障を両立させるため、**長期平準定期保険**を軸に設計します。

- 契約者=法人、被保険者=社長、死亡保険金受取人=法人。
- 保険金額は、事業保障の追加必要額（約1億円）をカバーする水準。
- 勇退予定時期に**解約返戻率ピークが重なる**設計を選ぶ。勇退時に解約し、返戻金を退職金原資へ。
- 勇退前に万一があれば、死亡保険金を死亡退職金・弔慰金と事業保障に充当。

### 税務・出口の流れ

1. **保険料**：長期平準定期の最高解約返戻率区分に応じて資産計上・損金算入（第2章）。区分は設計書で確定〔要確認〕。
2. **勇退時**：保険を解約 → 解約返戻金を受領。資産計上額を超える部分は**雑収入（益金）**。
3. 同じ期に**役員退職金を支給** → 多額の損金。雑収入と相殺し課税を平準化。
4. **死亡退職金・弔慰金**として遺族が受け取る場合は、相続税の非課税枠を活用（→ [03-相続](../03-相続/README.md)）。

> **実務メモ：** このケースの肝は「勇退時期＝返戻率ピーク＝退職金支給＝雑収入と損金の相殺」を一本の線で設計することです。バラバラだと、返戻金に課税されるだけで退職金の損金と噛み合いません。退職金規程の整備を必ず並走させます。

### 留意点

- 社長60歳・健康状態次第で加入可否・保険料が変わる。早期検討が必要。
- 保険料が年間キャッシュフローを圧迫しないか、利益水準で検証。
- 承継（株式・納税資金）は次のステップとして別途設計（ケース3的な発想へ）。

## ケース2：IT受託・年商1.2億・社長45歳（福利厚生＋成長対応）

### 会社概要（設定）

| 項目 | 内容 |
|------|------|
| 業種 | ソフトウェア受託開発 |
| 年商 | 約1.2億円 |
| 従業員 | 12名（平均年齢32歳） |
| 社長 | 45歳・報酬月額 100万円 |
| 借入金 | 少額（運転資金枠のみ） |
| 課題認識 | 採用・定着に苦戦。福利厚生を強化したい |

### 課題の整理

1. **人材の定着・採用力**：若手中心で離職が痛手。福利厚生の見える化で採用力を上げたい。
2. **社長の保障は最小限**：借入が少なく事業保障ニーズは限定的。
3. **将来の成長対応**：事業拡大で保障ニーズが増える可能性。

### 提案設計

**養老保険ハーフタックスプラン（福利厚生）**を軸に。

- 契約者=法人、被保険者=**全従業員**、満期保険金受取人=法人、死亡保険金受取人=従業員の遺族。
- 満期保険金は従業員の**退職金原資**、在職中の死亡は**遺族保障**。
- 保険料の**1/2を福利厚生費として損金**〔要確認〕、1/2を資産計上。
- **普遍的加入**を徹底（全員加入・合理的基準）。

あわせて、社長には成長に応じて見直せる**平準定期（保障中心）**を最小限で。

### 税務・留意点

- ハーフタックスの1/2損金は**普遍的加入が絶対条件**。役員だけ手厚くしない。
- 満期金は法人が受領 → 従業員退職金として支給（損金）。受領時の益金と支給の損金を対応させる。
- 福利厚生規程・退職金規程を整備し、制度として運用する。

> **実務メモ：** このケースでは「節税」ではなく「**人が辞めない会社づくり**」が経営者の関心事です。保険を福利厚生制度として設計し、採用・定着という経営課題に接続することが提案の価値になります。税務メリットを前面に出すのは筋が違います。

## ケース3：卸売業・年商5億・社長68歳（事業承継＋納税資金）

### 会社概要（設定）

| 項目 | 内容 |
|------|------|
| 業種 | 食品卸 |
| 年商 | 約5億円 |
| 社長 | 68歳・そろそろ承継を意識 |
| 株主 | 社長100% |
| 自社株 | 評価額が高く、相続時の納税資金が課題（概算〔要確認〕） |
| 相続人 | 長女（後継者・専務）、次女（会社に関与せず） |
| 現預金 | 個人・法人とも潤沢ではない |

### 課題の整理

1. **納税資金の不足**：自社株評価が高いが換金しにくく、相続税の納税原資が足りない見込み。
2. **遺産分割の公平**：株式を長女に集中させると、次女への配慮（代償分割の原資）が必要。
3. **経営の安定**：後継者への円滑なバトンタッチ。

### 提案設計

一生涯の保障が要るため、**終身保険**を軸に据えます。

- **納税資金の準備**：契約者=法人、被保険者=社長、受取人=法人。死亡時に法人が受け取り、**死亡退職金**として後継者（相続人）へ支給。死亡退職金・弔慰金の**相続税非課税枠**を活用（→ [03-相続](../03-相続/README.md)）。
- **遺産分割の調整**：株式は長女へ、次女には**代償分割の原資**として保険金を充てる設計を検討。個人契約（社長個人が契約者）で受取人を指定する方法もあり、法人契約と組み合わせて全体最適を図る。

### 税務・連携

- 死亡退職金は退職金規程・議事録の整備が前提。非課税枠（法定相続人の数に応じた枠〔要確認〕）を活用。
- 自社株の**評価引き下げ・事業承継税制**は税理士・事業承継専門家の領域。保険は「納税・分割の資金準備」で貢献。→ [04-事業承継](../04-事業承継/README.md)。
- 個人契約と法人契約で、保険金の課税関係（相続税／所得税／贈与税）が異なる点に注意〔要確認〕。

> **実務メモ：** 承継案件は「保険で全部解決」ではありません。株価対策・株式の集約・遺留分・親族の感情など、保険の外側の論点が主役です。FPは**専門家チームの一員**として、資金準備（納税・分割）のパートを確実に担う立ち位置が現実的かつ誠実です。

### 留意点

- 社長68歳・健康状態で加入可否・保険料が大きく変わる。**時間的猶予が少ない**ため早期着手が必須。
- 遺留分（次女の権利）への配慮を法務面（弁護士・税理士）と確認。
- 個人・法人どちらの契約が最適か、課税関係を比較して設計。

## 統合演習（章のまとめ）

3つのケースに共通する提案の型は次のとおりです。

1. **決算書・ヒアリングから課題を特定**（借入・退職金・承継のどれが主か）
2. **目的に合う保険種類を選ぶ**（事業保障→定期／退職金→長期平準・逓増／福利厚生→養老ハーフタックス／承継→終身）
3. **税務を正確に扱う**（返戻率区分・ハーフタックス・非課税枠。節税を煽らない）
4. **出口を設計する**（返戻率ピーク＝退職金＝損益マッチング）
5. **制度整備・専門家連携を並走**（退職金規程・承継スキーム）

## 確認問題

1. ケース1で「勇退時期・返戻率ピーク・退職金支給」を一致させる狙いを、税務の観点から説明せよ。
2. ケース1の事業保障必要額（追加分の目安）を、設定値から概算で示せ。
3. ケース2のハーフタックスプランで、1/2損金の絶対条件は何か。
4. ケース3で死亡退職金を用いる際に活用できる相続税上のメリットは何か。
5. ケース3のように承継案件でFPが取るべき現実的な立ち位置はどのようなものか。
6. 3ケースに共通する提案の型を、ステップで簡潔に述べよ。

<details>
<summary>解答</summary>

1. 勇退時に保険を解約すると資産計上超過分が雑収入（益金）になる。同じ期に退職金を支給して多額の損金を出し、両者を相殺して課税を平準化するため。
2. 借入8,000万円＋固定費補填9,000万円－現預金4,000万円≒1.3億円。既契約3,000万円を差し引き、追加で約1億円前後〔要確認〕。
3. 普遍的加入（全従業員対象・合理的基準）。役員・特定者のみを手厚くしない。
4. 死亡退職金・弔慰金の相続税非課税枠（法定相続人の数に応じた枠〔要確認〕）を活用できる。
5. 株価対策・株式集約・遺留分などは税理士・弁護士・事業承継専門家の領域とし、FPは専門家チームの一員として納税・分割の資金準備を確実に担う立ち位置。
6. ①課題特定 → ②目的に合う保険選択 → ③税務を正確に処理 → ④出口（ピーク・損益マッチング）設計 → ⑤制度整備・専門家連携の並走。
</details>
