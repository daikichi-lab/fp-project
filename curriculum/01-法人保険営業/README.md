# モジュール01：法人保険営業

法人契約の生命保険を「**保険種類・経理処理・税務・活用目的**」の4つの視点から正しく理解し、経営者に対して**保障目的とコンプライアンスを起点とした提案**ができるようになるためのモジュールです。

> 本モジュールは節税手法のカタログではありません。2019年（令和元年）の法人税基本通達改正により、いわゆる「節税保険」の税務メリットは大きく縮小しました。**保険本来の機能（保障・資金準備）を軸に、税務は正しく・保守的に扱う**というスタンスで学習してください。

---

## 学習目標

このモジュールを修了すると、以下ができるようになります。

1. 主要な法人向け保険種類（定期・逓増定期・長期平準定期・終身・養老・医療・がん等）の特徴を説明できる
2. 契約形態（契約者・被保険者・受取人）の組み合わせが税務に与える影響を理解している
3. 2019年通達改正後の**最高解約返戻率区分による資産計上ルール**を正しく適用できる
4. 事業保障・退職金準備・福利厚生・事業承継など、**目的別に保険を設計**できる
5. 経営者ヒアリングから提案書作成、契約後フォローまでの実務フローを回せる
6. 具体的な法人を題材に、保障・税務・退職金を統合した提案を組み立てられる

## 進め方

1. まず本 README で全体像をつかむ。
2. 第1章 → 第2章の順で**基礎と税務**を固める。ここが法人保険営業の土台です。
3. 第3章で**目的別の設計思想**を学び、第4章で**提案実務**に落とし込む。
4. 第5章の**ケーススタディ**で、保障設計→税務→退職金準備を一気通貫で演習する。
5. 各章末の**確認問題**と**実務チェックリスト**で理解度を自己点検する。

## 重要な前提

- 本モジュールは **2025年度（令和7年度）税制**をベースに記述しています。
- 変わりうる数値・区分・限度額には `〔要確認〕` を付しています。**提案時は必ず最新の法令・通達・保険会社の設計書で確認**してください。
- 保険の税務取扱いは**契約形態・加入時期・通達**により異なります。過去契約には契約時点のルールが適用される点に注意してください。
