# 第3章　承継スキーム

> ※本章は2025年度税制に基づく。事業承継税制の特例措置は適用期限・要件が改正されるため、適用時は必ず最新の中小企業庁・国税庁情報で確認すること。

承継の「相手」が決まれば、次は「どう移すか」の設計になる。本章では、親族内承継・役員従業員承継・M&Aのそれぞれで用いられる具体的スキームと、そのメリット・デメリット・留意点を整理する。自社株評価（第2章）と事業承継税制（第4章）を前提知識とする。

---

## 3-1　親族内承継のスキーム

自社株（＝経営権）を後継者へ移す方法は、大きく**生前贈与・相続・譲渡（売買）**の3つ。これらを組み合わせて設計する。

### 生前贈与

現経営者が生きているうちに、後継者へ株式を贈与する。

- **暦年課税：** 年110万円の基礎控除を使い、時間をかけて少しずつ移す。株価が低い時期に計画的に進めると効果的。ただし相続開始前一定期間の贈与は相続財産に持ち戻される点に注意〔要確認：加算期間〕。
- **相続時精算課税：** 累計2,500万円まで贈与時は課税されず、相続時に精算する制度。株価が低い（今後上がる見込みの）タイミングで一括移転するのに向く。近年は年110万円の基礎控除も併用可能〔要確認：控除・要件〕。**将来値上がりする自社株を、低い今の評価額で固定して渡せる**のが最大の利点。
- **事業承継税制の贈与税納税猶予**を併用すれば、贈与税負担を猶予・免除できる（第4章）。

### 相続による承継

現経営者の死亡により、後継者が株式を相続する。

- **メリット：** 手続きが相続の中で完結する。小規模宅地等の特例など相続の各種特例と組み合わせられる場合がある。
- **デメリット・留意点：** 株価が**死亡時点の評価**で確定するため、対策の自由度が低い。何より**遺産分割・遺留分**の問題が大きい。自社株を後継者に集中させると、他の相続人の取り分が減り紛争リスクが高まる。

### 譲渡（売買）

後継者（または後継者の持株会社）が、現経営者から株式を**買い取る**。

- **メリット：** オーナーは売却代金（現金）を得られ、贈与・相続と切り離して確実に移転できる。
- **デメリット・留意点：** 後継者側に**買取資金**が必要。オーナー側には譲渡所得課税（分離課税）が生じる。持株会社を使った資金調達（後述）と組み合わせることが多い。

> **実務メモ：** 実務では「株価が低い今、相続時精算課税＋事業承継税制で自社株を後継者へ移し、値上がり分を相続財産から切り離す」といった組み立てが有力。制度の併用可否・要件は複雑なので、必ず税理士とシミュレーションすること。相続との関係は [03-相続](../03-相続/README.md) を参照。

### 遺留分対策 ── 民法特例

自社株を後継者に集中させると、他の相続人の**遺留分**を侵害しうる。経営承継円滑化法の**遺留分に関する民法特例**を使うと、推定相続人全員の合意により、生前贈与した自社株を遺留分算定の基礎財産から**除外（除外合意）**したり、価額を**固定（固定合意）**したりできる。株価上昇分が遺留分に跳ね返るのを防げるため、後継者の地位を安定させる有効な手段である。〔要確認：適用要件・手続〕

### 議決権をコントロールする手法

株式を分散させつつ、経営権（議決権）は後継者に集中させたい ── そのための手法がある。

- **種類株式：** 議決権制限株式（無議決権株式）や、拒否権付株式（**黄金株**）などを発行。たとえば後継者に議決権のある普通株を集め、他の相続人には無議決権の配当優先株を渡せば、財産の公平と経営権集中を両立しやすい。黄金株は先代が経営を監督するために一時的に保有する使い方もある。
- **属人的株式：** 非公開会社で、定款により「株主ごとに」議決権・配当等の取扱いを変える定め。たとえば「先代が保有する間は1株につき多数の議決権」とし、承継後に効力を失わせる設計などが可能。柔軟だが定款変更（特殊決議）が必要で、設計を誤ると無効・紛争リスクがある。
- **持株会社化（ホールディングス化）：** 後継者が新設する持株会社が、借入等で事業会社株を買い取る。オーナーは売却代金を得て株式は持株会社に集約。以後の事業会社の成長（株価上昇）は持株会社側で受け止め、オーナー個人の相続財産に自社株の値上がりが乗らない。**株価対策・資金調達・経営権集中**を同時に狙える一方、借入負担・組織の複雑化・税務（株式保有特定会社の判定等）に注意。

> **実務メモ：** 黄金株や属人的株式は「切れ味の鋭い道具」だが、設計・回収を誤ると承継後の経営を縛る。特に黄金株は先代死亡時に相続され、意図せぬ人物が拒否権を持つ事故が起きうる。**発行だけでなく回収・消却まで含めた出口設計**を弁護士とともに行うこと。

## 3-2　役員・従業員承継のスキーム（MBO／EBO）

親族以外の役員・従業員へ承継する場合、最大の課題は**株式取得資金**である。これを解決する枠組みが MBO／EBO。

- **MBO（Management Buy-Out）：** 会社の**経営陣**が自社株を買い取り経営権を取得する。
- **EBO（Employee Buy-Out）：** **従業員**が買い取る。

### 資金調達の方法

後継者個人に数千万〜数億円の買取資金があることは稀なため、次のように調達する。

- **金融機関からの借入：** 後継者個人、または後継者が設立する**受け皿会社（持株会社）**が融資を受けて株式を買い取る。返済原資は事業会社からの配当・役員報酬。
- **持株会社スキーム：** 受け皿会社が借入で株式を取得し、事業会社と合併または連結で返済していく（LBO的手法）。
- **投資ファンドの活用：** 承継ファンド等が資本参加し、後継者とともに株式を取得するケースもある。

### 留意点

- 事業の返済能力（キャッシュフロー）で借入を賄えるかが成否を分ける。過大な借入は承継後の経営を圧迫する。
- オーナー一族が残す株式・退く条件の整理。
- **経営者保証**の引継ぎ。個人保証を後継者が引き受けられるか、「経営者保証に関するガイドライン」に基づく解除交渉が重要。
- 従業員承継では、他の従業員・役員との公平感・納得感の醸成。

> **実務メモ：** MBO/EBO は「良い後継者はいるが金がない」典型ケースの解。金融機関・ファンド・税理士との連携が不可欠で、FPは資金計画（返済シミュレーション）と保険による保証・納税準備で貢献できる。経営者保証解除は近年後押しする政策が進んでおり、最新の枠組みを確認したい。〔要確認〕

## 3-3　M&A（社外への引継ぎ）

後継者が社内外にいない場合、第三者への譲渡（M&A）が有力な選択肢となる。

### 主な手法

- **株式譲渡：** オーナーが保有株式を買い手へ売却する。手続きが比較的シンプルで中小M&Aの主流。会社（法人格）はそのまま引き継がれ、許認可・契約も原則継続。オーナーには譲渡所得課税（分離課税）。
- **事業譲渡：** 会社の事業（の一部）を切り出して譲渡する。買い手は必要な資産・負債だけを選べる（簿外債務リスクを避けやすい）が、契約・許認可の移転手続や消費税等の負担が生じる。
- **株式交換・合併等の組織再編：** 買い手の株式を対価にする等、より大きな再編の中で用いられる。

### M&Aのプロセス

```
1. 準備・意思決定      … 目的整理、株価の目線、アドバイザー選定
2. マッチング（相手探し）… ノンネームでの打診、候補選定
3. トップ面談・基本合意  … 条件の大枠合意（意向表明・LOI/MOU）
4. デューデリジェンス（DD）… 買い手による財務・法務・税務等の精査
5. 最終契約             … 株式譲渡契約（SPA）等の締結
6. クロージング         … 決済・経営権移転
7. PMI（統合）          … 承継後の統合・引継ぎ
```

情報管理が極めて重要で、従業員・取引先への開示は原則クロージング前後まで慎重に行う。早期の情報漏れは人材流出・取引停止を招く。

### バリュエーション（企業価値評価）の概要

M&Aでの価格は、相続税評価とは別の考え方で決まる。主なアプローチは3つ。

- **コストアプローチ（純資産法）：** 時価純資産を基礎に評価。中小M&Aでは「**時価純資産＋営業権（のれん）**」がよく使われる。営業権は「年間利益の数年分」で見積もることが多い。
- **インカムアプローチ（DCF法等）：** 将来生み出すキャッシュフローを現在価値に割り引く。理論的だが前提の置き方で変動。
- **マーケットアプローチ（類似会社比較法／マルチプル）：** 上場類似会社の指標（EV/EBITDA倍率等）と比較。

実際の売買価格は、これらを参考にしつつ**交渉**で決まる。相続税評価額とは一致しない。

### 仲介とFA（ファイナンシャル・アドバイザー）の違い

M&A支援の担い手には大きく2形態あり、**立場が異なる**。

- **仲介：** 売り手と買い手の**双方の間に立ち**、成約を目指す。中小M&Aで一般的。双方の事情を踏まえ話をまとめやすい一方、**利益相反**（どちらの味方か）の懸念があり、双方から手数料を受け取る構造への理解が必要。
- **FA（アドバイザー）：** 売り手**または**買い手の**一方に付き**、依頼者の利益最大化のために交渉する。条件を有利に運びやすいが、相手にもFAが付くと交渉が長期化しうる。

> **実務メモ：** 「中小企業M&Aガイドライン」（中小企業庁）は、仲介・FAの手数料体系や利益相反への対応、契約上の留意点を整理している。特に**専任条項・テール条項・最低手数料**などは事前に必ず確認を。FPは、経営者が有利な条件で・信頼できる支援者を選べるよう、契約内容のチェックを助ける立場に立てる。M&Aの実行は専門家（M&Aアドバイザー・税理士・弁護士）との連携が前提。

### M&Aのメリット・デメリット

- **メリット：** 後継者不在でも事業・雇用を存続。オーナーは創業者利益（現金）を確保し、個人保証も原則解除。従業員の雇用や取引が守られる。
- **デメリット・留意点：** 希望条件の相手が見つかる保証はない。企業文化・処遇の変化。従業員・取引先の不安。仲介者選定と情報管理を誤ると失敗する。

## 3-4　スキーム選択の考え方

| 観点 | 親族内承継 | 役員従業員承継（MBO/EBO） | M&A |
|------|-----------|--------------------------|-----|
| 後継者 | 親族に候補あり | 社内に有能な人材 | 社内外に不在 |
| 経営の継続性 | 高い | 高い（事業熟知） | 相手次第（PMIが鍵） |
| 資金の壁 | 贈与・相続なら小、譲渡なら要資金 | 大（買取資金） | 買い手が資金を用意 |
| オーナーの手取り | 原則なし（贈与・相続） | 譲渡なら現金化 | 現金化（創業者利益） |
| 主なコスト | 贈与税・相続税 | 借入・譲渡所得税 | 譲渡所得税・手数料 |
| 主な留意点 | 遺留分・株価・分割 | 資金調達・保証引継ぎ | 相手探し・情報管理 |

> **実務メモ：** 現実には「親族内を第一に検討しつつ、並行してM&Aの可能性も探る」ハイブリッドが多い。どのスキームでも共通するのは、**早期着手・株価対策・専門家連携**の3点。FPは全体設計とコーディネートで価値を出す。

## 確認問題

**問1**　自社株を後継者へ移す3つの基本手段を挙げよ。

**問2**　相続時精算課税が、値上がりが見込まれる自社株の承継に向くと言われる理由を述べよ。

**問3**　経営承継円滑化法の「遺留分に関する民法特例」における除外合意・固定合意とは、それぞれ何をする合意か。

**問4**　MBO/EBO における最大の課題と、その典型的な解決策を述べよ。

**問5**　M&Aにおける「仲介」と「FA」の立場の違いを説明せよ。

**問6**　中小M&Aのバリュエーションでよく用いられる「時価純資産＋営業権」方式で、営業権はおおむねどのように見積もられることが多いか。

### 解答

**問1**　生前贈与・相続・譲渡（売買）。

**問2**　贈与時点の（低い）評価額で課税関係を固定でき、その後の値上がり分を相続財産から切り離せるため。将来値上がりする株を今の低い評価で渡せる。

**問3**　除外合意＝生前贈与した自社株を遺留分算定の基礎財産から除外する合意。固定合意＝その株式の価額を合意時の価額に固定し、以後の値上がりを遺留分に反映させない合意。

**問4**　後継者に株式の買取資金がないこと。解決策は、後継者個人または受け皿会社（持株会社）が金融機関融資やファンドの出資を受けて買い取り、事業のキャッシュフローで返済する方法。

**問5**　仲介は売り手・買い手の双方の間に立って成約を目指す（利益相反に注意）。FAは売り手または買い手の一方に付き、依頼者の利益最大化のために交渉する。

**問6**　年間利益（または経常利益等）の数年分として見積もられることが多い。

## 実務チェックリスト

- [ ] 承継の類型（親族内／社内／M&A）の第一候補と並行検討先を定めたか
- [ ] 自社株移転の手段（贈与・相続・譲渡）の組み合わせを設計したか
- [ ] 株価対策と承継タイミングを連動させたか
- [ ] 遺留分の侵害リスクを確認し、民法特例や種類株式の活用を検討したか
- [ ] 議決権集中の手法（種類株式・属人的株式・持株会社）の出口まで設計したか
- [ ] MBO/EBO の場合、返済可能性（キャッシュフロー）と資金調達を検討したか
- [ ] 経営者保証の引継ぎ・解除の見通しを確認したか
- [ ] M&Aの場合、支援者（仲介／FA）の立場・手数料・契約条項を確認したか
- [ ] M&Aの情報管理（従業員・取引先への開示タイミング）方針を定めたか
- [ ] 税理士・弁護士・M&Aアドバイザーとの連携体制を組んだか
