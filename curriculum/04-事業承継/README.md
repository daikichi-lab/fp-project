# モジュール04：事業承継

中小企業経営者の最大の関心事である「**事業をどう次代に引き継ぐか**」を、**承継スキーム・自社株評価・事業承継税制**の3本柱で体系的に理解し、経営者に対して**承継プランの初期設計**ができるようになるためのモジュールです。

> 事業承継は「税金対策」ではありません。**誰に・何を・どう引き継ぐか**という経営そのものの問題であり、税務・法務・M&A・組織のすべてが絡みます。FPの役割は、全体像を提示し論点を整理して、税理士・M&Aアドバイザー等の専門家との連携をコーディネートすることにあります。**単独で判断・実行させない**という姿勢を貫いてください。

---

## 学習目標

このモジュールを修了すると、以下ができるようになります。

1. 事業承継の3類型（親族内・役員従業員・社外／M&A）と、承継の3要素（人・資産・知的資産）を説明できる
2. 取引相場のない株式（自社株）の評価の**仕組みと考え方**を理解し、株価を動かす要因を挙げられる
3. 親族内承継・MBO/EBO・M&Aの各スキームのメリット・デメリットと留意点を整理できる
4. 事業承継税制（特例措置・一般措置）の**枠組みとリスク**を説明し、活用の判断ポイントを示せる
5. 具体的な会社を題材に、自社株評価→スキーム選定→税負担比較→計画の初期設計ができる

## 進め方

1. まず本 README で全体像をつかむ。
2. 第1章で**承継の全体像と進め方**を押さえ、経営課題としての事業承継を理解する。
3. 第2章で**自社株評価の仕組み**を固める。ここがスキーム・税制すべての土台です。
4. 第3章で**スキームの選択肢**を、第4章で**事業承継税制**を学ぶ。
5. 第5章の**ケーススタディ**で、評価→スキーム選定→税負担比較を一気通貫で演習する。
6. 各章末の**確認問題**と**実務チェックリスト**で理解度を自己点検する。

## 重要な前提

- 本モジュールは **2025年度（令和7年度）税制**をベースに記述しています。
- **事業承継税制の特例措置**は適用期限・要件が改正されやすいため、該当箇所には `〔要確認〕` を付しています。**適用時は必ず最新の中小企業庁・国税庁情報で確認**してください。
- 自社株評価は**仕組みと考え方**を学ぶことを主眼とし、具体的な評価額の断定は避けています。ケーススタディの数値は**教材用の概算・架空値**です。
- 事業承継・M&A・税制の実行は、**税理士・M&Aアドバイザー等の専門家との連携が前提**です。FPは全体設計とコーディネートを担います。
