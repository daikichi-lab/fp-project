# 第5章　ケーススタディ

> ※本章は2025年度税制に基づく。事業承継税制の特例措置は適用期限・要件が改正されるため、適用時は必ず最新の中小企業庁・国税庁情報で確認すること。
>
> **本章の数値はすべて教材用の概算・架空値である。** 自社株評価額・税額は会社の個別事情と最新の通達・税率で大きく変わるため、実際の提案では必ず税理士による正式評価とシミュレーションを行うこと。ここでは「思考の流れ」を体得することを目的とする。

本章では、第1〜4章の知識を統合し、3つの架空事例で「**評価 → スキーム選定 → 税負担比較 → 計画**」の一連を演習する。数字の正確さより、**論点の拾い方と設計の筋道**に注目してほしい。

---

## ケース1　親族内承継 ── 株価が高い製造業

### 会社・家族の概要（架空値）

| 項目 | 内容 |
|------|------|
| 会社 | A製作所（金属加工、従業員35名、業歴40年） |
| 会社規模区分 | 中会社の大（想定） |
| 直近利益 | 経常利益 年6,000万円前後（好業績） |
| 純資産 | 簿価4億円、含み益ある工場用地あり |
| 自社株評価額（概算・架空） | 原則的評価で **約5億円**（発行済全株、社長保有100%） |
| 社長 | 68歳、健康。引退を意識し始めた |
| 後継者 | 長男（40歳、常務、入社15年、経営意欲・資質とも十分） |
| 他の相続人 | 長女（会社と無関係、都内在住） |
| 社長個人資産 | 自宅・預金等で約1.5億円 |

### ステップ1　論点の見える化

- 自社株評価が約5億円と高く、**そのまま相続・贈与すると多額の税負担**。長男に納税資金がない。
- 相続財産の大半が自社株。**長男に自社株を集中させると、長女の遺留分**（および感情面）が問題化。
- 好業績ゆえ、**放置すると株価はさらに上昇**（利益・内部留保の蓄積）。時間が経つほど不利。

### ステップ2　自社株評価と引下げ

- 中会社の大 → **併用方式**（類似業種比準のウエイト高め）。利益が大きいため類似業種比準価額が高い。
- **引下げ策：** 社長退任時に**役員退職金**（功績倍率法で合理的な範囲、架空で1.2億円想定）を支給。支給期は利益が大きく減り、純資産も圧縮され、株価は概算で**5億→3.5億円程度**に低下（架空値）。退職金原資は既契約の法人生命保険の解約返戻金を充当（[01-法人保険営業](../01-法人保険営業/README.md) 参照）。

### ステップ3　スキーム選定

- **株価が下がった期に、相続時精算課税＋事業承継税制（特例措置）の贈与税納税猶予**を使い、長男へ全株を一括贈与。経営権を生前に確定し、値上がり分を相続財産から切り離す。
- 特例措置の**特例承継計画**を期限内に提出することが前提〔要確認：提出期限・適用期限〕。
- **遺留分対策：** 経営承継円滑化法の民法特例（除外合意）で、贈与した自社株を遺留分の基礎から除外。あわせて、長女には社長個人資産（自宅・預金）や生命保険金を相続させ、**財産の公平感**を確保。

### ステップ4　税負担の比較（概算・架空）

| シナリオ | 自社株の扱い | 承継時の税負担イメージ |
|---------|------------|----------------------|
| A：何もせず相続 | 評価5億円で相続 | 相続税が高額（納税資金不足で株の売却も検討せざるを得ない） |
| B：退職金で引下げ＋暦年贈与 | 3.5億円を年々贈与 | 税負担は軽減するが完了まで長期、途中の相続リスク |
| C：退職金で引下げ＋特例事業承継税制 | 3.5億円を一括贈与し**贈与税100%猶予**〔要確認〕 | 承継時の贈与税負担を猶予。長期の継続要件管理が必要 |

長男が長期保有・事業継続の意思が固いため、**C案（退職金による引下げ＋特例措置）を軸に、遺留分は民法特例＋長女への代替財産で手当て**する設計が有力。

> **実務メモ：** C案は「取消リスク」と裏表。長男に将来M&Aの意思がなく、届出管理を顧問税理士が担える体制が前提。もし将来売却の可能性が残るなら、B案（引下げ＋計画贈与）で身軽さを残す判断もある。**株価対策（退職金・保険）はどの案でも先に効く**点がポイント。

## ケース2　役員承継（MBO）── 後継者はいるが資金がない

### 会社・関係者の概要（架空値）

| 項目 | 内容 |
|------|------|
| 会社 | B商事（卸売業、従業員20名、安定収益） |
| 自社株評価額（概算・架空） | 原則的評価で **約2億円**（社長100%保有） |
| 社長 | 72歳、子は会社を継ぐ意思なし（親族内承継は不可） |
| 後継者候補 | 専務（55歳、生え抜き、社内外の信頼厚い。ただし個人資産は限られる） |
| 事業のキャッシュフロー | 年間 営業CF 約3,000万円 |

### ステップ1　論点の見える化

- 親族内承継は不可。**社内に有能な後継者（専務）**がいる → MBOが第一候補。
- 専務個人に**2億円の買取資金はない**。資金調達が最大の課題。
- M&A（社外売却）も選択肢だが、社長は「社員に継がせたい」意向が強い。

### ステップ2　スキーム設計（MBO＋持株会社）

- 専務が**受け皿会社（持株会社）H社**を設立。
- H社が金融機関から借入（＋一部は専務の自己資金・ファンド出資も検討）を受け、社長からB商事株を**約2億円で買い取る**。
- 社長は**売却代金（現金）約2億円**を得て引退。譲渡所得として分離課税〔要確認：税率〕。
- H社は、B商事からの配当・（将来的な合併による）キャッシュフローで借入を返済。

### ステップ3　資金・返済の検証

- 借入2億円を営業CF年3,000万円で返済 → 元利返済に無理がないか、返済年数・金利ストレスを試算。**過大な借入は承継後の経営を圧迫**するため、譲渡価格の交渉（株価引下げ策の併用）や返済期間の設計が重要。
- **経営者保証：** 社長の個人保証を、金融機関と「経営者保証に関するガイドライン」に沿って専務へ引継ぎ・整理。〔要確認〕

### ステップ4　税負担・手取りの比較（概算・架空）

| 論点 | MBO（B商事継続） | M&A（第三者売却） |
|------|-----------------|-------------------|
| 社長の手取り | 譲渡代金 約2億円（分離課税後） | 交渉次第で同等〜上振れの可能性 |
| 事業の継続性 | 高い（専務が熟知） | 相手・PMI次第 |
| 社長の希望との整合 | 「社員に継がせたい」に合致 | 希望と乖離しうる |
| 主なリスク | 借入返済負担・保証引継ぎ | 相手が見つからない・条件次第 |

社長の意向（社員への承継）と専務の資質を踏まえ、**MBO＋持株会社スキームを軸に、資金計画と保証解除を金融機関・税理士と詰める**設計とする。

> **実務メモ：** MBOの成否は「返済可能性」に尽きる。FPは返済シミュレーションと、社長引退後の生活資金設計（受取代金の運用・保険）、専務の保障（借入に対する団信的な保険）で貢献できる。株価が高ければ、社長退任時の退職金支給で評価・譲渡価格を適正化する余地もある。

## ケース3　M&A ── 後継者不在の好業績サービス業

### 会社の概要（架空値）

| 項目 | 内容 |
|------|------|
| 会社 | C社（対事業所サービス業、従業員15名、無借金・高収益） |
| 財務 | 時価純資産 約1.5億円、経常利益 年4,000万円 |
| 社長 | 65歳、後継者は社内外に不在。健康なうちに出口を考えたい |
| 株主 | 社長80%、配偶者20% |

### ステップ1　論点の見える化

- 親族・社内に後継者不在 → **M&A（社外承継）が有力**。
- 好業績・無借金で、**買い手にとって魅力的**（高い価格が期待できる）。
- 社長の関心は「従業員の雇用維持」と「創業者利益の確保」。

### ステップ2　バリュエーションの目線（概算・架空）

- 中小M&Aで多い「**時価純資産＋営業権**」方式。
  - 時価純資産：約1.5億円
  - 営業権：年間利益4,000万円 × 3年分 ≒ 1.2億円（架空の倍率）
  - **想定譲渡価格：約2.7億円**（あくまで交渉の出発点）
- DCFやマルチプル（EV/EBITDA）でクロスチェックし、目線を持って交渉に臨む。実際の価格は買い手との交渉で決まる。

### ステップ3　プロセスと支援者の選定

- **株式譲渡**を基本線に（法人格・許認可・契約を維持しやすい）。
- 支援者は**仲介かFAか**を検討。売り手の利益を最大化したいなら**FA**、幅広い相手探しと成約重視なら**仲介**。いずれも「中小企業M&Aガイドライン」に沿って、専任条項・テール条項・最低手数料を確認〔要確認〕。
- **情報管理：** 従業員・取引先への開示はクロージング前後まで慎重に。ノンネーム打診 → 基本合意 → デューデリジェンス → 最終契約 → クロージング → PMI の順で進める。

### ステップ4　税負担・手取り（概算・架空）

- 社長・配偶者は株式譲渡益に**譲渡所得課税（分離課税）**〔要確認：税率〕。譲渡価格2.7億円に対し取得費・手数料を控除した譲渡益に課税。
- 手取り現金は、引退後の生活資金・資産運用・相続対策（[03-相続](../03-相続/README.md)）へ引き継ぐ。**個人保証は原則解除**。

### スキーム比較のまとめ

| 案 | 内容 | 向くケース | 主な留意点 |
|----|------|-----------|-----------|
| 廃業 | 事業を畳む | 継続価値が低い場合 | 雇用喪失・清算コスト。好業績では最も惜しい |
| MBO/EBO | 社内の人材へ | 有能な社内後継者がいる | 資金調達・返済負担 |
| M&A | 第三者へ譲渡 | 後継者不在・魅力ある事業 | 相手探し・情報管理・支援者選定 |

C社は後継者不在かつ好業績のため、**M&Aで雇用維持と創業者利益を両立**する方向が最有力。廃業は企業価値を捨てることになり、避けたい。

> **実務メモ：** 好業績・無借金の会社は「畳むのは惜しい」典型。M&Aなら雇用も守れ現金も得られる。FPは、経営者がM&Aを「社員を売る」とネガティブに捉える心情に配慮しつつ、**存続の手段**として前向きに位置づけ直す対話が価値になる。実行はM&Aアドバイザー・税理士・弁護士との連携が前提。

## 総合演習の視点

3ケースに共通する「思考の型」を最後に確認する。

1. **見える化：** 株主構成・株価・財務・後継者の有無・家族関係を洗い出す。
2. **評価と引下げ：** 会社規模・評価方式を見極め、退職金・保険・不動産等で適法に株価を調整。
3. **スキーム選定：** 後継者の有無と意向から、親族内／MBO／M&Aを選ぶ。
4. **税負担比較：** 複数案を並べ、承継時コストと将来リスク（取消・返済・相手探し）を天秤にかける。
5. **計画化と連携：** 時間軸に落とし込み、税理士・弁護士・M&Aアドバイザー・金融機関と役割分担する。

> **実務メモ：** どのケースでも、FPが単独で税額や法的可否を断定してはならない。FPの価値は「**全体像を描き、論点を整理し、正しい専門家へ最適なタイミングでつなぐ**」ことにある。数字は概算で仮説を示し、最終判断は専門家の正式評価に委ねる ── この分業がFPへの信頼を生む。

## 確認問題

**問1**　ケース1で、贈与前に役員退職金を支給する狙いは何か。株価の観点から述べよ。

**問2**　ケース1で、長男に自社株を集中させる際、長女への配慮として用いた2つの手当てを挙げよ。

**問3**　ケース2のMBOで、専務個人に買取資金がない問題をどう解決したか。

**問4**　ケース2で、MBOの成否を左右する最も重要な検証項目は何か。

**問5**　ケース3のバリュエーションで用いた「時価純資産＋営業権」方式について、営業権をどう見積もったか（架空値で）。

**問6**　3ケースを通じて示された、FPが守るべき基本姿勢を一言で述べよ。

### 解答

**問1**　退職金の損金計上でその期の利益と純資産を圧縮し、類似業種比準・純資産価額の両面から自社株評価額を引き下げ、下がった評価額で贈与するため。

**問2**　（1）経営承継円滑化法の民法特例（除外合意）で贈与株式を遺留分の基礎から除外、（2）長女には社長個人資産（自宅・預金）や生命保険金を相続させ財産の公平感を確保。

**問3**　専務が受け皿会社（持株会社）を設立し、その会社が金融機関借入等で社長から株式を買い取り、事業のキャッシュフローで返済していく（MBO＋持株会社スキーム）。

**問4**　返済可能性（事業のキャッシュフローで借入の元利返済が無理なく賄えるか）。

**問5**　年間利益4,000万円 × 約3年分 ≒ 1.2億円（いずれも架空値。時価純資産約1.5億円と合わせ想定譲渡価格 約2.7億円）。

**問6**　単独で税務・法務を断定せず、全体像を描いて論点を整理し、適切な専門家へ最適なタイミングでつなぐこと（数字は概算の仮説、最終判断は専門家に委ねる）。

## 実務チェックリスト

- [ ] 株主構成・議決権割合を正確に把握したか
- [ ] 自社株評価の概算と、引下げ余地（退職金・保険・不動産・再編）を検討したか
- [ ] 後継者の有無・意向から、親族内／MBO／M&Aの方向性を定めたか
- [ ] 複数スキームを並べ、承継時コストと将来リスクを比較したか
- [ ] 遺留分・分割の公平（親族内）を手当てしたか
- [ ] 資金調達と返済可能性（MBO）を検証したか
- [ ] 支援者の立場・契約条件（M&A）を確認したか
- [ ] 事業承継税制を使う場合、取消リスクと継続管理体制を確認したか
- [ ] 概算値であること・正式評価は専門家によることを経営者に伝えたか
- [ ] 税理士・弁護士・M&Aアドバイザー・金融機関との連携体制を組んだか
