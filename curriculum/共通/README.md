# 共通モジュール　面談設計・コンプライアンス・用語集

法人・資産家マーケットで活動するFPが、**全モジュール（法人保険・企業分析・相続・事業承継）に共通して必要とする「面談実務」と「コンプライアンス」**をまとめた土台モジュールです。専門知識をどれだけ蓄えても、面談で引き出せなければ提案に届かず、法令の線引きを誤れば信用も資格も失います。本モジュールはその両輪を扱います。

> ※本モジュールは**2025年度（令和7年度）時点**の制度・実務に基づく。制度は改正されるため、適用時に必ず最新情報を確認すること。

## 位置づけ

- 本モジュールは特定の商品・スキームを扱いません。**「どう聴くか」「どこまで踏み込んでよいか」「何を記録するか」**という、あらゆる面談に通底する作法を扱います。
- 他の4モジュールと**並行して**参照してください。知識モジュールが「何を提案するか（What）」なら、本モジュールは「どう関わるか（How）」を担当します。
- 特にコンプライアンス（第2章）は、提案活動を始める前に一度通読し、面談のたびに立ち返ることを推奨します。

## 進め方

1. まず本 README で全体像をつかむ。
2. **第2章コンプライアンス**を先に通読し、「FPとして踏み込んでよい範囲」の地図を頭に入れる。
3. **第1章面談設計**で、その範囲内で最大限に情報を引き出し、信頼を得る技術を学ぶ。
4. 各章末の**確認問題**と**実務チェックリスト**で自己点検する。
5. 用語集は、他モジュール学習中に不明な語が出たら随時引く。

## 本モジュールの基本スタンス

- **FPは税務・法務の「個別具体的判断」はできません。** できるのは制度の一般的説明と情報提供、そして専門家（税理士・弁護士・司法書士等）への橋渡しです。この線引きを全編で一貫させます。
- 面談で得た情報は顧客の資産・家族・健康に関わる**機微情報**です。取得・利用・保管のすべてで慎重に扱います。
- 提案は「売る」ためでなく「顧客の課題を解決する」ために行う——このスタンスが結果的に最大の営業力になります。

## 重要な前提・免責

- 本教材は**教育目的**であり、個別の法令解釈・税務・法務判断を保証しません。
- 業法・監督指針・ガイドラインは改正されます。本文中の変わりうる内容には `〔要確認〕` を付しています。**実務適用時は必ず最新の法令・監督指針・所属先の社内規程で確認**してください。
- 保険募集に関するルールは、所属する保険会社・代理店の**社内コンプライアンス規程が優先**します。本教材と社内規程に相違がある場合は社内規程に従ってください。
