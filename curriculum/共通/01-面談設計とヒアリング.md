# 第1章　面談設計とヒアリング

> ※本章は**2025年度（令和7年度）時点**の実務に基づく。制度は改正されるため、適用時に必ず最新情報を確認すること。

法人・資産家との面談は、商品説明の場ではなく**「経営者の頭の中にある課題を、本人と一緒に言語化する場」**です。提案の質は、面談でどれだけ深く正確に情報を引き出せたかでほぼ決まります。本章では、面談を設計し、経営者から必要情報を体系的に引き出し、記録に残すまでの実務を扱います。

---

## 1-1　面談の全体設計

### 面談は「一度の商談」ではなく「複数回の関係構築」

法人・資産家案件は、初回で提案・成約に至ることはまずありません。**初回（信頼構築・情報収集）→ 分析 → 提案 → クロージング → フォロー**という複数回の面談を前提に設計します。各回の「目的」を一つに絞ることが成功の鍵です。1回の面談で情報収集も提案も詰め込むと、どちらも中途半端になります。

| 面談 | 主目的 | ゴール（この面談で得るもの） |
|------|--------|------------------------------|
| 初回 | 信頼構築・課題の仮説づくり | 「もう一度会う理由」と決算書等の資料 |
| 2回目 | 詳細ヒアリング・現状把握 | 家族・株主・財務・保障の全体像 |
| 提案 | 課題の共有と解決策の提示 | 顧客が課題を「自分事」と認識する |
| クロージング | 意思決定の支援 | 具体的な行動（申込・専門家紹介等） |
| フォロー | 実行支援・関係維持 | 次の課題・紹介の獲得 |

> **実務メモ：** 初回面談のゴールを「契約」に置かないこと。初回のゴールは「次回のアポイント」と「判断材料（決算書・保険証券・家族構成）を預かること」で十分です。焦って提案すると、情報が足りないまま的外れな提案になり、かえって信頼を失います。

### 初回面談の型（オープニング）

初回の冒頭5分で面談全体の主導権と信頼が決まります。次の順で進めます。

1. **自己紹介と立場の明示**：所属・資格・何ができる人間かを簡潔に。士業ではないこと、専門的判断は専門家と連携することも最初に伝えると誠実さが伝わります。
2. **面談の目的とゴールの共有**：「本日は売り込みではなく、まず現状を教えていただく時間です」と枠組みを合意する。
3. **所要時間とアジェンダの確認**：相手の時間を尊重する姿勢を示す。
4. **守秘の約束**：伺った内容は外部に漏らさない旨を明言する。これがヒアリングの深さを左右します。

## 1-2　経営者・資産家から引き出すヒアリング項目

法人・資産家案件では、**「ヒト・カネ・カブ（株）・ミライ（将来）」**の4領域を漏れなく押さえます。以下は最低限カバーすべき項目群です。すべてを初回で聞き切る必要はなく、複数回に分けて自然に埋めていきます。

### (1) 家族・親族（ヒト）

- 家族構成（配偶者・子・その年齢・職業）
- 子の中に後継者候補がいるか、経営への関与度
- 家族間の人間関係（相続で揉める要素の有無）——直接聞かず、会話の中で察知する
- 経営者本人の健康状態・年齢・引退希望時期

### (2) 株主構成（カブ）

- 現在の株主と持株比率（分散していないか、名義株の有無）
- 過去の増資・株式の移動の経緯
- 種類株式・属人的株式の有無
- 少数株主・疎遠な親族株主の存在（承継の障害になりやすい）

### (3) 決算・財務（カネ）

- 直近3期分の決算書（BS・PL・販管費内訳・勘定科目内訳明細書）
- 売上・利益の趨勢、季節変動
- 役員報酬の水準、役員貸付金・借入金の有無
- 手元資金と月商の関係（資金繰りの余裕度）
- 詳細な財務分析の視点は [02 企業分析・経営相談](../02-企業分析経営相談/README.md) を参照。

### (4) 借入・金融取引（カネ）

- 借入残高・返済スケジュール・金利
- 取引金融機関とメインバンクとの関係
- 経営者個人の連帯保証の有無（経営者保証ガイドラインの適用可能性〔要確認〕）
- 担保に供している資産（自宅・事業用不動産等）

### (5) 退職金（ミライ）

- 役員退職金規程の有無と支給基準（最終報酬月額×勤続年数×功績倍率）
- 退職金の準備状況（保険・社外積立・内部留保）
- 想定される退職時期と必要額
- 死亡退職金・弔慰金の規程（相続対策と直結。[03 相続](../03-相続/README.md) 参照）

### (6) 後継者・事業承継（ミライ）

- 後継者の有無（親族内・従業員・第三者=M&A）
- 承継時期の希望
- 自社株の評価水準の把握状況と納税資金の準備
- 事業承継税制の検討有無（[04 事業承継](../04-事業承継/README.md) 参照）

### (7) 保険（現状把握）

- 加入中の法人契約・個人契約（保険証券を預かる）
- 契約形態（契約者・被保険者・受取人）と加入目的
- 保障額が現状のニーズ（借入・退職金・遺族保障）に合っているか
- 解約返戻金の水準（含み資産・簿外の退職金原資として）

> **実務メモ：** 保険証券は必ず現物（またはコピー）を預かり、証券から契約形態・保険期間・解約返戻率推移を読み取ります。「入っているはず」という経営者の記憶は高い確率で不正確です。証券がなければ保険会社の契約内容照会で確認します。

## 1-3　質問設計——「聴く技術」

ヒアリング項目を「尋問」ではなく「対話」で埋めるための質問設計を身につけます。

### オープン質問とクローズド質問の使い分け

- **オープン質問**（自由に答えさせる）：「会社の10年後、どうなっていたいですか」——課題や本音を引き出す序盤で多用する。
- **クローズド質問**（Yes/Noや選択で答えさせる）：「後継者は決まっていますか」——事実確認や合意形成で使う。

序盤はオープンで広げ、核心に近づくにつれクローズドで絞る、が基本の流れです。

### 課題を「自分事」にするSPIN型の展開

保険や承継のような「今すぐ困っていない」テーマは、顧客自身に問題の重大さを気づいてもらう必要があります。次の順で質問を組み立てます。

1. **状況質問（Situation）**：現状の事実を確認する。「借入は何行から、いくらほどですか」
2. **問題質問（Problem）**：潜在的な不満・不安を引き出す。「その借入、社長に万一のとき、どなたが返済されますか」
3. **示唆質問（Implication）**：問題を放置した場合の影響を広げる。「返済が滞ると、ご家族や事業はどうなりますか」
4. **解決質問（Need-payoff）**：解決策の価値を顧客に語らせる。「その借入がゼロになる仕組みがあれば、安心ですよね」

このうち**示唆質問**が最も重要で、ここで顧客が「確かにまずいな」と自ら気づくと、提案は「売り込み」でなく「相談」になります。

> **実務メモ：** 沈黙を恐れないこと。核心的な質問（後継者、健康、家族関係）の後は、経営者が考えをまとめる時間が必要です。こちらから言葉を継がず、相手が話し出すまで待つ。沈黙の後にこそ本音が出ます。

### 聴く姿勢の基本

- **バックトラッキング**（オウム返し）で「聴いている」を示す。
- 相手の言葉を**要約して返す**ことで理解の確認と信頼を得る。「つまり、承継はしたいが後継者候補と時期が悩ましい、ということですね」
- **評価・否定をしない**。経営判断を批評すると心を閉ざされます。

## 1-4　面談準備

準備の質が面談の質を決めます。事前に調べられることは調べ、面談時間は「本人にしか聞けないこと」に使います。

### 事前調査（面談前にやること）

- 会社の登記情報・ホームページ・業界動向・決算公告（あれば）
- 業種特有の商流・季節性・許認可
- 面談相手の役職・意思決定権限・過去の面談履歴
- 想定する仮説（この会社ならこういう課題があるはず）を2〜3本立てておく

### 面談準備チェックリスト

- [ ] 面談の**目的（ゴール）を一つ**に定めたか
- [ ] 相手・会社の事前情報を調べたか（登記・HP・業界）
- [ ] 前回議事録・宿題事項を確認したか（2回目以降）
- [ ] 当日聞くべきヒアリング項目を優先順位付けしたか
- [ ] 提示資料（会社案内・事例・提案書）を準備したか
- [ ] 名刺・パンフ・記録用の筆記具／端末を用意したか
- [ ] 所要時間とアジェンダを相手に事前共有したか
- [ ] 守秘・立場（士業でない旨）を伝える準備をしたか
- [ ] 次回アポイントの候補日を用意したか

## 1-5　記録の残し方

面談記録は、①提案の精度を上げる材料、②コンプライアンス上の証跡（言った・言わない対策）、③引き継ぎ資料、の3つの役割を持ちます。記憶は薄れ、歪みます。**面談直後（できれば当日中）**に記録します。

### 記録すべき項目

- 日時・場所・出席者（相手・当方）
- 面談の目的と実際に話した論点
- 顧客の発言（特に**意向・要望・懸念**は原文に近い形で）
- 提示した情報・資料、説明した内容
- 合意事項・宿題（誰が・いつまでに・何を）
- 次回アポイント

### 記録の作法

- **事実（顧客が言ったこと）と、当方の解釈・所感を分けて書く**。混ぜると後で誤読します。
- 保険募集に関わる面談では、**意向把握の内容・情報提供した事項・比較推奨の理由**を必ず残す（コンプライアンス要件。詳細は [02 コンプライアンス](./02-コンプライアンス.md) 参照）。
- 機微情報（健康・家族関係・資産）を含むため、記録の**保管・アクセス制限**を徹底する。
- 顧客に確認してもらう議事録は、認識のズレを防ぎ信頼も高める。重要案件では議事録を共有するとよい。

> **実務メモ：** 「言った・言わない」のトラブルは、記録があれば大半が防げます。特に「リスクや不利益を説明した事実」は自分を守る証跡になります。面談記録は営業ツールであると同時に、自分を守る保険だと考えてください。

## 確認問題

**問1**　初回面談のゴールとして最も適切なものはどれか。
- (A) その場で保険契約を成約する
- (B) 次回アポイントの取得と判断材料（決算書等）を預かること
- (C) 提案書を完成させて渡すこと

<details><summary>解答</summary>

**(B)**。初回のゴールは信頼構築と情報収集であり、成約や提案は情報が揃ってから。焦った提案は的外れになり信頼を損なう。
</details>

**問2**　SPIN型の質問のうち、顧客が問題の重大さに自ら気づく上で最も重要とされるのはどれか。

<details><summary>解答</summary>

**示唆質問（Implication）**。問題を放置した場合の影響を広げることで、顧客が「これはまずい」と自覚し、提案が相談に変わる。
</details>

**問3**　法人・資産家ヒアリングの4領域「ヒト・カネ・カブ・ミライ」のうち、「カブ」で押さえるべき項目を2つ挙げよ。

<details><summary>解答</summary>

株主構成・持株比率、名義株の有無、種類株式の有無、少数株主・疎遠な親族株主の存在、過去の株式移動の経緯——のうち2つ。
</details>

**問4**　保険証券について、経営者の記憶に頼らず現物を預かるべき理由を述べよ。

<details><summary>解答</summary>

「入っているはず」という経営者の記憶は不正確なことが多く、契約形態・保険期間・保障額・解約返戻率推移といった提案に不可欠な情報は証券（または契約内容照会）でしか正確に把握できないため。
</details>

**問5**　面談記録を「面談直後（当日中）」に作成すべき理由を2つ述べよ。

<details><summary>解答</summary>

(1) 記憶は時間とともに薄れ歪むため、正確な記録は直後にしか残せない。(2) 「言った・言わない」トラブルやコンプライアンス上の証跡（リスク説明の事実等）として、鮮度と正確性が自分を守るため。
</details>

**問6**　面談記録を書く際、「事実」と「解釈・所感」を分けて書くべき理由を述べよ。

<details><summary>解答</summary>

両者を混ぜると、後から読んだ際に顧客の実際の発言と当方の推測を取り違え、誤った前提で提案を組み立てるおそれがあるため。事実（顧客の意向・要望・懸念）は特に原文に近い形で残す。
</details>

## 実務チェックリスト

- [ ] 各面談の**目的（ゴール）を一つ**に絞って臨んでいるか
- [ ] 初回のゴールを「成約」でなく「次回アポ＋判断材料の預かり」に置いているか
- [ ] 冒頭で自己紹介・立場（士業でない旨）・守秘・アジェンダを共有したか
- [ ] ヒアリングは「ヒト・カネ・カブ・ミライ＋保険現状」を漏れなくカバーしたか
- [ ] 直近3期の決算書・保険証券など**現物資料**を預かったか
- [ ] オープン→クローズドの流れ、SPIN（特に示唆質問）を意識したか
- [ ] 核心的な質問の後、沈黙を恐れず相手の言葉を待ったか
- [ ] 顧客の**意向・要望・懸念**を原文に近い形で記録したか
- [ ] 記録を面談直後（当日中）に作成し、事実と所感を分けたか
- [ ] 合意事項・宿題（誰が・いつまでに・何を）と次回アポを確定したか
- [ ] 機微情報を含む記録の保管・アクセス制限は適切か（[02 コンプラ](./02-コンプライアンス.md) 参照）
