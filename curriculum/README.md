# 法人・資産承継FP育成カリキュラム（本番版）

法人顧客および資産家層に対して、保険・財務・相続・事業承継の一気通貫コンサルティングができるFP（ファイナンシャル・プランナー）を育成するための実務教材です。

## 対象者

- 法人・富裕層マーケットを担当する保険営業／FP／士業事務所スタッフ
- 一般的なFP資格（3級・2級）の知識を前提に、**実務レベル**へ引き上げたい方
- 経営者・資産家との面談で、財務・税務・承継の論点を扱えるようになりたい方

## 到達目標

このカリキュラムを修了すると、以下ができるようになります。

1. 法人保険を「経理処理・税務・目的」の観点から正しく説明・提案できる
2. 決算書を読み、経営課題と資金・保障ニーズを結びつけて提案できる
3. 相続税の概算計算と、生前対策の全体像を顧客に提示できる
4. 事業承継の手法（親族内・従業員・M&A）と自社株対策を体系的に説明できる
5. 4領域を横断した「法人まるごと」の提案ストーリーを組み立てられる

## 学習の進め方

1. 各モジュールの `README.md`（モジュール目次）で全体像をつかむ
2. 章立てされた本文を順に読む（各章に**確認問題**と**実務チェックリスト**を用意）
3. モジュール末の**ケーススタディ**で統合的に演習する
4. `共通` モジュールの面談設計・コンプライアンスは全モジュールと並行して参照する

## 重要な前提・免責

- 本教材は**教育目的**であり、個別の税務・法務判断を保証するものではありません。
- 税率・控除額・非課税枠・各種特例は**毎年の税制改正で変わります**。本文中の数値には「**〔要確認〕**」タグを付し、**提案時は必ず最新の国税庁・法令・約款で確認**してください。
- 記載時点の基準：**2025年度（令和7年度）税制**をベースに作成。適用年度は各章冒頭に明記します。
- 保険商品の税務取扱いは、契約形態・加入時期・通達により異なります。個別契約は必ず保険会社の設計書・税務資料で確認してください。
