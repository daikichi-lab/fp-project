# 第4章　経営課題の抽出と提案

> ※本章は**2025年度（令和7年度）時点**の実務・制度に基づく。適用時は最新情報で確認すること。

数字を読めても、それを**経営者に響く課題と提案**に変えられなければFPの仕事にはなりません。本章では、決算書からの課題抽出、経営者ヒアリング、SWOT、そして保険・相続・承継ニーズへの橋渡しと提案の組み立てを扱います。

## 1. 決算書から課題を抽出する着眼点

決算書は「症状の記録」です。異常値や変化から仮説を立てます。着眼点を領域別に整理します。

### 収益性の着眼点

- 粗利率の低下 → 値引き・原価高・不採算品の混入
- 販管費の増加 → 人件費・広告費・地代の膨張、固定費肥大
- 営業赤字 → ビジネスモデルそのものの見直し

### 安全性の着眼点

- 自己資本比率の低下 → 赤字累積・過大配当・過大投資
- 実質債務超過 → 役員貸付金・不良資産の存在（第1章）
- 固定長期適合率100%超 → 設備投資の資金調達ミスマッチ

### 資金・効率の着眼点

- 売上債権回転期間の長期化 → 回収悪化・不良債権・押し込み販売
- 在庫回転期間の長期化 → 過剰在庫・不良在庫・架空在庫
- 短期借入の膨張 → 運転資金の恒常的不足、資金繰り逼迫

### ヒト・承継の着眼点

- 役員報酬の水準・退職金の準備状況 → 退職金原資・純資産圧縮ニーズ
- 社長貸付金・借入金 → 相続財産化・自社株評価への影響
- 後継者の有無（決算書外だが必ず確認）→ 事業承継ニーズ

> **実務メモ：** 「決算書から課題を10個挙げる」訓練を勧める。1つの数字から複数の仮説を出す癖がつくと、面談で経営者に「うちの会社をよく見ている」と信頼される。ただし数字はあくまで仮説。断定せず、次のヒアリングで裏を取る。

## 2. 経営者ヒアリング

決算書で立てた仮説は、経営者との対話で検証します。ヒアリングは「詰問」でなく「一緒に整理する」姿勢が基本です。

### ヒアリングの5領域

1. **事業・商流**：主力商品、得意先・仕入先の構成、業界動向、競合。
2. **ヒト**：後継者の有無・意向、キーパーソン、従業員の年齢構成・定着。
3. **カネ**：資金繰りの実感、借入・返済の負担感、金融機関との関係。
4. **経営者個人**：役員報酬、個人資産、家族構成、退職後の生活設計。
5. **将来**：5年後・10年後の姿、引退時期、承継・売却の考え。

### 良い質問の型

- 数字を起点に開く：「在庫がこの2年で増えていますが、何か背景がありますか」
- 未来を聞く：「社長が第一線を退くのは、だいたい何歳頃をお考えですか」
- 感情に触れる：「今、経営で一番気がかりなことは何ですか」

> **実務メモ：** 経営者が最も話したいのは「税金」「資金繰り」「後継ぎ」であることが多い。ここに保障・相続・承継ニーズが潜む。面談設計・ヒアリングの詳細は[共通モジュール](../共通/README.md)を参照。個人情報・決算情報の取扱いはコンプライアンス上、書面同意と管理を徹底する。

## 3. SWOT分析で整理する

抽出した課題と対話内容を、SWOTで構造化します。財務分析（内部・定量）に、事業・市場の定性情報を加えて全体像にします。

| | プラス要因 | マイナス要因 |
|---|-----------|------------|
| **内部環境** | 強み（Strength）：高粗利、技術、顧客基盤、無借金 | 弱み（Weakness）：後継者不在、過大債務、在庫過多 |
| **外部環境** | 機会（Opportunity）：市場拡大、規制緩和、値上げ余地 | 脅威（Threat）：競合、原価高、人手不足、需要縮小 |

SWOTは並べて終わりでなく、**クロスSWOT**で戦略に変換します。「強み×機会＝攻め」「弱み×脅威＝守り・撤退」の掛け合わせで、優先課題を絞ります。

## 4. 保険・相続・承継ニーズへの橋渡し

財務課題は、そのまま各領域の提案テーマに変換できます。これが本モジュールの中心です。

| 決算書・面談で見えた課題 | つながるニーズ | 接続先モジュール |
|------------------------|--------------|----------------|
| 借入過大・社長依存が高い | 事業保障（社長万一時の返済原資） | [法人保険](../01-法人保険営業/README.md) |
| 退職金の準備がない | 役員退職金原資・純資産圧縮 | [法人保険](../01-法人保険営業/README.md) |
| 社長個人資産が大きい・相続税懸念 | 相続税対策・納税資金・遺産分割 | [相続](../03-相続/README.md) |
| 社長貸付金・借入金がある | 相続財産・債務の整理 | [相続](../03-相続/README.md) |
| 後継者がいる／いない | 承継スキーム・自社株対策 | [事業承継](../04-事業承継/README.md) |
| 自社株評価が高い（利益・資産の蓄積） | 株価引下げ・納税猶予 | [事業承継](../04-事業承継/README.md) |

> **実務メモ：** 保険提案が先にありきになると信頼を失う。順序は「①財務・経営の課題を経営者と共有 → ②課題の優先順位づけ → ③解決手段の一つとして保険・承継対策を位置づける」。保険はあくまで手段。この順序を崩さないことが、本番のFPと押し売りの差になる。

## 5. 提案の組み立て

提案は「課題→あるべき姿→打ち手→効果→次アクション」の流れで構成します。

### 提案書の基本構成

1. **現状分析**：財務分析の要点（強み・弱み）を数字で示す。
2. **課題の特定**：優先順位をつけた3つ程度に絞る（総花はNG）。
3. **あるべき姿**：数値目標（例：自己資本比率30%、債務償還年数10年以内）。
4. **打ち手**：課題ごとの具体策（財務改善＋保険・承継等の手段）。
5. **効果とリスク**：定量効果と、留意点・前提（税制は `〔要確認〕`）。
6. **実行計画**：誰が・いつ・何を。専門家（税理士・弁護士）連携の要否。

### 提案を通す原則

- **優先順位を絞る**：課題10個でも、提案は「今やる3つ」に絞る。
- **数字で語る**：「良くなります」でなく「自己資本比率が○%改善」。
- **手段を中立に**：保険ありきでなく、複数の選択肢と長短を示す。
- **専門家連携**：税務・法務判断は税理士・弁護士へ。FPは全体設計と橋渡し。

## 確認問題

1. 「在庫回転期間の長期化」から立てられる仮説を2つ挙げよ。
2. 決算書の課題を提案に変える際の、正しい順序（3ステップ）を述べよ。
3. クロスSWOTで「弱み×脅威」はどんな戦略方向になるか。
4. 「社長貸付金がある」ことは、どのモジュールのどんなニーズにつながるか。
5. 提案書で課題を3つ程度に絞るのはなぜか。

### 解答

1. 過剰在庫（需要見込み違い・仕入過多）、不良在庫・架空在庫（実在性・評価の問題）など。
2. ①財務・経営課題を経営者と共有 → ②課題の優先順位づけ → ③解決手段の一つとして保険・承継対策を位置づける。
3. **守り・縮小・撤退**の方向（弱みが脅威で顕在化しないよう防御する）。
4. [相続モジュール](../03-相続/README.md)の**相続財産・債務の整理**（貸付金の相続財産化）、および自社株評価への影響を通じ[事業承継](../04-事業承継/README.md)にもつながる。
5. 課題を総花的に並べると実行されないため。**優先順位をつけ「今やる3つ」に絞る**ことで行動につながる。

- [ ] あるべき姿を数値目標で示したか
