# 第3章　資金繰りとキャッシュフロー

> ※本章は**2025年度（令和7年度）時点**の実務・制度に基づく。適用時は最新情報で確認すること。

「利益が出ていても現金が無ければ倒産する」——中小企業支援の核心は資金繰りです。本章では資金繰り表、運転資金、CCC、返済原資、そして金融機関が企業をどう格付けするか（債務者区分）を扱います。

## 1. 利益とキャッシュのズレ

PLの利益は**発生主義**で計上されます。売上は入金前に計上され、仕入も支払前に費用化されます。そのため利益とキャッシュには必ずズレが生じます。ズレの主因は次の3つです。

- **運転資金の増減**（売掛金・在庫・買掛金の変動）
- **設備投資**（費用ではなく資産計上、現金は一括流出）
- **借入の返済**（費用ではないが現金は流出）

黒字倒産は、この3つで現金が流出し続けたときに起きます。FPは「損益」ではなく「資金の入り繰り」で会社を見る視点を持ちます。

## 2. 資金繰り表

資金繰り表は、月次で**現金の入りと出**を予測・管理する表です。決算書と違い、あくまで**現金主義**で作ります。基本構造は以下の通りです。

```
前月繰越現金
＋ 経常収入（売上入金・受取手形期日入金 等）
− 経常支出（仕入・人件費・経費・利息・税金 等）
＝ 経常収支
± 財務収支（借入 − 返済）
± 設備等収支（設備投資・売却）
＝ 当月収支
＝ 翌月繰越現金
```

> **実務メモ：** 資金繰り表は「経常収支」がプラスであることが第一。ここがマイナスなら本業で現金が回っておらず、借入で穴埋めしている状態。金融機関も真っ先にここを見る。3〜6か月先まで作れると、賞与・納税・設備等の資金ショートを事前に手当てできる。

## 3. 運転資金（所要運転資金）

運転資金は「事業を回すために常時寝かせておく必要のある資金」です。中小企業金融の最重要概念です。

```
所要運転資金 ＝ 売上債権 ＋ 棚卸資産 − 仕入債務
```

売掛金と在庫は「まだ現金になっていない資産」、買掛金は「まだ払っていない負債（他人の資金で回している部分）」です。差額の分だけ、企業は自前で資金を用意しなければなりません。

### 運転資金は「増える」と資金を食う

売上が伸びると売掛金・在庫も増え、運転資金が増加します。これを**増加運転資金**といい、成長企業ほど資金需要が生まれます。「増収なのに金が無い」典型がこれです。回転期間で言い換えると次の通りです。

```
所要運転資金 ≒ 1日あたり売上 ×（売上債権回転期間 ＋ 在庫回転期間 − 仕入債務回転期間）
```

回収を早め（債権回転短縮）、在庫を絞り、支払を遅らせる（債務回転長期化）と運転資金は縮小します。

## 4. キャッシュ・コンバージョン・サイクル（CCC）

CCCは「仕入代金を払ってから、売上代金を回収するまでの日数」です。運転資金の効率を日数で表します。

```
CCC ＝ 売上債権回転期間 ＋ 棚卸資産回転期間 − 仕入債務回転期間
```

- CCCが**短い**ほど資金効率が良い（回収が早く、支払が遅い）。
- CCCが**長い**ほど資金が寝て、運転資金負担が重い。
- CCCが**マイナス**の業態（先に現金回収、後で仕入代金支払）もある（一部の小売・飲食等）`〔要確認〕`。

> **実務メモ：** CCCの改善は「無借金化」より即効性のある資金対策になることが多い。回収サイト短縮・在庫圧縮・支払サイト交渉の3レバーで、借入を増やさず手元資金を厚くできる。数字（回転期間）を示して経営者と改善余地を共有するのがFPの腕の見せどころ。

## 5. 借入と返済原資

借入の可否・妥当性は「何で返すか（返済原資）」で決まります。返済原資の基本式は次の通りです。

```
年間返済原資 ≒ 税引後当期純利益 ＋ 減価償却費
```

減価償却費は現金流出のない費用なので、返済に充てられる現金として足し戻します。これを**簡易キャッシュフロー**とも呼びます。

### 債務償還年数

```
債務償還年数 ＝（有利子負債 − 所要運転資金）÷ 簡易キャッシュフロー
```

現状の利益で借入を何年で返せるかを示します。目安は**10年以内なら健全、10年超は要改善、20年超は過剰債務**と見られることが多い `〔要確認〕`。運転資金見合いの借入は「回り続ける」性質なので、分子から控除して評価するのが実務的です。

### 資金使途の峻別

借入は資金使途で性質が異なります。**運転資金**（回り続ける、短期継続）と**設備資金**（長期・投資回収で返す）は、返済計画も金融機関の見方も別物です。設備資金を短期で借りると資金繰りが逼迫し（固定長期適合率の悪化）、運転資金を長期一括返済にすると事業縮小時に苦しくなります。

## 6. 金融機関の見方（債務者区分・格付）

金融機関は融資先を**債務者区分**に分類し、これが金利・融資姿勢・保全（担保・保証）を左右します。区分の考え方は概ね次の通りです `〔要確認〕`。

| 区分 | 状態のイメージ |
|------|--------------|
| 正常先 | 業績良好・財務内容も特段問題なし |
| 要注意先 | 業績低調・貸出条件や返済に懸念（うち要管理先＝3か月以上延滞・条件緩和） |
| 破綻懸念先 | 経営難で今後経営破綻に陥る可能性が大きい |
| 実質破綻先 | 法的・形式的には未破綻だが実質破綻状態 |
| 破綻先 | 法的・形式的に破綻 |

区分の判定では、決算書の表面値でなく**実態BS**（第1章参照：役員貸付金・不良在庫・回収不能債権を控除した実質純資産）と、**債務償還年数・キャッシュフロー**が重視されます。

### 格付を上げる着眼点

- **実質債務超過の解消**：役員貸付金の整理、含み損の実現・処理、増資・DES等。
- **債務償還年数の短縮**：利益改善、運転資金の圧縮（CCC改善）、不要資産の売却。
- **返済実績と情報開示**：試算表・資金繰り表の定期提出、条件変更（リスケ）歴の解消。

> **実務メモ：** 「役員貸付金の整理」「退職金による純資産圧縮の是正」「事業保障・借入返済原資の確保」は、そのまま[法人保険](../01-法人保険営業/README.md)の提案テーマになる。決算書の弱点＝保障・資金ニーズと捉え、金融機関目線を提案の根拠に使う。ただし融資審査そのものへの助言は銀行・専門家の領域であり、FPは「準備を整える支援」に徹する。

## 確認問題

1. 所要運転資金の算式を書け。
2. 増収局面で「増加運転資金」が発生するのはなぜか。
3. CCCの算式を書き、短いほど良い理由を述べよ。
4. 借入の年間返済原資（簡易キャッシュフロー）の算式を書け。
5. 債務償還年数の算式と、過剰債務とされる目安を答えよ（目安は `〔要確認〕`）。
6. 金融機関が債務者区分の判定で、表面純資産でなく重視するものは何か。

### 解答

1. 所要運転資金 ＝ 売上債権 ＋ 棚卸資産 − 仕入債務。
2. 売上増に伴い**売掛金と在庫が増え、その分の資金を自前で用意**する必要が生じるため。
3. CCC ＝ 売上債権回転期間 ＋ 棚卸資産回転期間 − 仕入債務回転期間。短いほど**支払から回収までの資金が寝る期間が短く**、運転資金負担が軽いため。
4. 年間返済原資 ≒ 税引後当期純利益 ＋ 減価償却費。
5. 債務償還年数 ＝（有利子負債 − 所要運転資金）÷ 簡易キャッシュフロー。**20年超で過剰債務**とされることが多い `〔要確認〕`。
6. **実態BS（実質純資産）**と**債務償還年数・キャッシュフロー**。
