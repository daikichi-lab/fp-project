# 第1章　決算書の基礎

> ※本章は**2025年度（令和7年度）時点**の実務・制度に基づく。適用時は最新情報で確認すること。

決算書は経営者との共通言語です。FPが決算書を読めると、面談は「保険の話」から「経営全体の相談」へ広がります。本章では財務3表（BS・PL・CF）の構造と、中小企業特有の会計実態を押さえます。

## 1. 財務3表の全体像

決算書の中心は次の3つです。役割を一言で言うと以下の通りです。

| 表 | 正式名称 | 何を表すか | 時点／期間 |
|-----|---------|-----------|-----------|
| BS | 貸借対照表（Balance Sheet） | 期末時点の財産と資金調達源泉 | 一時点（ストック） |
| PL | 損益計算書（Profit & Loss） | 1年間の儲け | 期間（フロー） |
| CF | キャッシュフロー計算書 | 1年間の現金の増減 | 期間（フロー） |

3表はつながっています。**PLの当期純利益がBSの純資産（繰越利益剰余金）を増やし、BSの現金の増減理由をCFが説明する**——この関係を常に意識します。

> **実務メモ：** 中小企業では**CF計算書の作成義務がない**（会社法上、作成・開示が義務づけられるのは上場企業等）。そのためCF計算書が手元にないことが多く、BSの2期比較とPLから**簡易CFを自分で組む**スキルが実務では必須になる。

## 2. 貸借対照表（BS）の構造

BSは左右（借方・貸方）が必ず一致します。左が「資産（資金の使い道）」、右が「負債＋純資産（資金の出どころ）」です。

```
【資産の部】        │【負債の部】
 流動資産           │ 流動負債
  現金預金          │  買掛金・支払手形
  売掛金・受取手形  │  短期借入金
  棚卸資産          │  未払金
 固定資産           │ 固定負債
  有形固定資産      │  長期借入金
  無形固定資産      │──────────────
  投資その他        │【純資産の部】
                    │ 資本金・利益剰余金
```

### 流動と固定の区分

**ワンイヤールール（1年基準）**が原則です。1年以内に現金化・支払期限が来るものを流動、それを超えるものを固定に分類します。ただし営業循環内（仕入→在庫→販売→回収）で生じる債権債務は、1年を超えても流動に入れる**正常営業循環基準**が優先されます。

### 純資産の意味

純資産（自己資本）は「返済不要の元手」です。**資産−負債＝純資産**であり、これがマイナスなら**債務超過**（資産をすべて処分しても負債を返せない状態）を意味します。

## 3. 損益計算書（PL）の構造

PLは5つの利益を段階的に示します。**どの段階で儲かり、どの段階で失っているか**を読むのが要点です。

| 段階 | 利益 | 算式 | 意味 |
|------|------|------|------|
| 1 | 売上総利益（粗利） | 売上高 − 売上原価 | 商品・サービスそのものの稼ぐ力 |
| 2 | 営業利益 | 粗利 − 販管費 | 本業の稼ぐ力 |
| 3 | 経常利益 | 営業利益 + 営業外収益 − 営業外費用 | 財務も含めた通常の実力 |
| 4 | 税引前当期純利益 | 経常利益 + 特別利益 − 特別損失 | 臨時損益込みの利益 |
| 5 | 当期純利益 | 税引前 − 法人税等 | 最終的に残る利益 |

> **実務メモ：** 中小企業では**営業利益と経常利益の差＝支払利息**であることが多い。借入依存度が高いと、本業（営業利益）は黒字でも経常利益が薄い。「営業利益は出ているのに手元が苦しい」経営者は、まず**支払利息の重さ**を疑う。

## 4. キャッシュフロー計算書（CF）の構造

CFは現金の増減を3区分で示します。**利益とキャッシュは一致しない**（黒字倒産があり得る）ことを説明する道具です。

- **営業CF**：本業で稼いだ現金。プラスが健全。
- **投資CF**：設備投資・有価証券等。成長企業は通常マイナス。
- **財務CF**：借入・返済・増資・配当。返済を進めるとマイナス。

理想的なパターンは**営業CFプラス／投資CFマイナス／財務CFマイナス**（本業で稼ぎ、投資し、借入を返す）です。営業CFがマイナスなら本業から現金が出ておらず、危険信号です。

### 簡易CFの作り方（営業CF近似）

```
簡易営業CF ≒ 当期純利益 + 減価償却費 − 運転資本の増加
```

減価償却費は現金流出を伴わない費用なので足し戻し、売掛金や在庫が増えた分は現金が寝ているので差し引きます。フリーキャッシュフロー（FCF）は「営業CF＋投資CF」で、返済や配当に回せる自由な現金を表します。

## 5. 中小企業会計の実態と注意点

中小企業の決算書は、税務申告目的で作られ、**実態と乖離している**ことが珍しくありません。分析前に「決算書のクセ」を疑う項目を挙げます。

### 役員貸付金・仮払金

BSの「短期貸付金」「仮払金」「立替金」に**役員貸付金**が隠れていることがあります。実質は回収見込みの薄い資産で、金融機関は**資産から控除**して評価します。過大なら「会社の金の私的流用」と見られ、格付を下げます。

> **実務メモ：** 役員貸付金は、生命保険を活用した役員報酬の組み替えや、貸付金の相続財産化（社長死亡時に会社への貸付金＝相続財産になる論点）など、[相続](../03-相続/README.md)・[法人保険](../01-法人保険営業/README.md)へつながる典型的な入口。BSの貸付金・借入金は必ずチェックする。

### 棚卸資産（在庫）

在庫は利益調整に使われやすい科目です。**架空在庫・不良在庫の水増し**で原価を圧縮し利益を大きく見せることがあります。回転期間が急に伸びていたら実在性・評価を疑います。

### 減価償却

中小企業は**任意償却**が事実上黙認されており、赤字回避のため償却費を計上しない（償却不足）ケースがあります。金融機関は「償却前提で利益が出ているか」を見ます。別表16で**償却不足額**を確認するのが実務です。

### 売掛金・貸倒れ

長期滞留の売掛金が「資産」として残っていることがあります。回収不能なら実質は損失です。得意先別の年齢表（エイジング）で滞留を確認します。

### 純資産の実質評価（実態BS）

以上を踏まえ、金融機関は**実態純資産＝表面純資産 −（役員貸付金・不良在庫・回収不能売掛金・含み損）＋含み益**で会社を評価します。表面上は資産超過でも、実態では債務超過というケースがあり、ここが提案の出発点になります。

## 確認問題

1. BSの左右が一致するのはなぜか、また「純資産＝○○−○○」の算式を答えよ。
2. PLの5つの利益のうち「本業の稼ぐ力」を表すのはどれか。
3. 「黒字なのに現金が足りない」状況を説明できる財務諸表はどれか、理由も述べよ。
4. 中小企業のBSで、金融機関が資産から控除して評価しがちな科目を2つ挙げよ。
5. 簡易営業CFの算式を書け。

### 解答

1. 「資産＝負債＋純資産」という複式簿記の関係があるため一致する。**純資産＝資産−負債**。
2. **営業利益**（＝売上総利益−販管費）。
3. **キャッシュフロー計算書（CF）**。利益は発生主義で計上され、売掛金・在庫の増加で現金が寝るため、利益とキャッシュは一致しないから。
4. **役員貸付金（短期貸付金・仮払金）**、**不良在庫（過大在庫）**、回収不能の**長期滞留売掛金**などから2つ。
5. 簡易営業CF ≒ 当期純利益 ＋ 減価償却費 − 運転資本の増加。

- [ ] 短期貸付金・仮払金・立替金に役員貸付金が無いか確認したか
- [ ] 在庫回転期間の異常な伸びをチェックしたか
- [ ] 減価償却の不足（別表16）を確認したか

- [ ] 表面純資産から実態純資産を試算し、実質債務超過でないか確認したか
