# モジュール02　企業分析・経営相談

法人顧客の**決算書を読み解き、財務・資金面の課題を抽出し、保険・相続・承継の提案へ橋渡しする**ための実務教材です。数字を「読む」だけでなく、経営者との対話で「使える論点」に変換する力を養います。

> ※本モジュールは**2025年度（令和7年度）時点**の実務・制度に基づく。適用時は最新情報で確認すること。

## 学習目標

このモジュールを修了すると、以下ができるようになります。

1. BS・PL・CFの構造を理解し、勘定科目から企業の実態を推測できる
2. 収益性・安全性・効率性・生産性・成長性の各指標を算出し、解釈できる
3. 資金繰り表・運転資金・CCCを用いて資金の流れを説明できる
4. 金融機関の「債務者区分・格付」の視点で自社を客観視できる
5. 決算書から経営課題を10個以上挙げ、保障・承継ニーズへ結びつけられる
6. 財務分析→課題抽出→提案までの一連のストーリーを組み立てられる

## 進め方

1. **01章**で決算書3表の構造と勘定科目を押さえる（土台）。
2. **02〜03章**で分析ツール（指標・資金繰り）を手に入れる。
3. **04章**で「数字を提案に変える」思考法を学ぶ。
4. **05章**のケーススタディで統合演習を行う。
5. 抽出した課題は、保障ニーズ→[法人保険](../01-法人保険営業/README.md)、資産承継→[相続](../03-相続/README.md)、株式・経営承継→[事業承継](../04-事業承継/README.md)の各モジュールへ接続する。

## 他モジュールとの関係

企業分析は**入口**です。決算書から見えた課題（過大な借入、後継者不在、退職金原資不足、自社株評価の上昇等）は、単独では解決しません。本モジュールで論点を整理し、以下へつなげます。

- 保障・事業保障・退職金原資 → [01 法人保険営業](../01-法人保険営業/README.md)
- 経営者個人の資産・相続税 → [03 相続](../03-相続/README.md)
- 自社株評価・承継スキーム → [04 事業承継](../04-事業承継/README.md)
- 面談設計・ヒアリング・コンプラ → [共通](../共通/README.md)
