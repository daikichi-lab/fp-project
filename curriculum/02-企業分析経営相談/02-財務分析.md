# 第2章　財務分析

> ※本章は**2025年度（令和7年度）時点**の実務・制度に基づく。適用時は最新情報で確認すること。

財務分析は「収益性・安全性・効率性・生産性・成長性」の5視点で企業を診ます。指標は**単年の絶対値より、2〜3期の推移と同業他社比較**で意味を持ちます。本章では主要指標の算式・目安・解釈を整理します。

> **重要：** 本章の「目安値」は代表的な水準を示すものです。**適正水準は業種・規模で大きく異なる**ため、業種依存の目安には `〔要確認〕` を付しています。同業比較は**中小企業実態基本調査**（中小企業庁）・TKC経営指標（BAST）・業種別審査事典等の最新データで確認してください。

## 1. 収益性分析（稼ぐ力）

### 売上高利益率

売上に対して各利益がどれだけ残るかを見ます。

| 指標 | 算式 | 見るポイント |
|------|------|-------------|
| 売上高総利益率（粗利率） | 売上総利益 ÷ 売上高 | 商品力・価格競争力 |
| 売上高営業利益率 | 営業利益 ÷ 売上高 | 本業の効率 |
| 売上高経常利益率 | 経常利益 ÷ 売上高 | 財務込みの総合力 |

目安は業種で全く異なります。卸売業は粗利率が低く（10〜20%程度）、サービス業は高い傾向があります `〔要確認〕`。**自社の推移**で粗利率が下がっていれば、値引き・原価高・不採算品の混入を疑います。

### ROA（総資産利益率）

```
ROA ＝ 利益 ÷ 総資産
```

分子は「経常利益」または「事業利益（営業利益＋受取利息配当）」を用いるのが一般的です。**投下した総資産がどれだけ利益を生んだか**を表す、資本効率の総合指標です。目安は5%程度 `〔要確認〕`。ROAは次のように分解できます。

```
ROA ＝ 売上高利益率 × 総資産回転率
```

これにより「利益率で稼ぐ型」か「回転で稼ぐ型」かが分かります。

### ROE（自己資本利益率）

```
ROE ＝ 当期純利益 ÷ 自己資本
```

**株主目線の指標**で、自己資本がどれだけ利益を生んだかを表します。目安は8〜10%程度 `〔要確認〕`。ROEは3分解（デュポン分解）できます。

```
ROE ＝ 売上高当期純利益率 × 総資産回転率 × 財務レバレッジ（総資産÷自己資本）
```

> **実務メモ：** ROEが高くても、財務レバレッジ（借入依存）で嵩上げされている場合がある。借入を増やせばROEは上がるが安全性は下がる。ROEは必ず自己資本比率とセットで見る。中小企業の同族会社では、役員報酬の取り方で純利益が動くため、ROEは額面通りに受け取らない。

## 2. 安全性分析（つぶれにくさ）

### 自己資本比率

```
自己資本比率 ＝ 自己資本 ÷ 総資産
```

最重要の安全性指標です。返済不要の元手が総資産に占める割合で、高いほど強い。目安は**中小企業で30%以上あれば良好、15%未満は要注意** `〔要確認〕`。マイナスは債務超過です。

### 流動比率・当座比率

短期の支払能力を見ます。

```
流動比率 ＝ 流動資産 ÷ 流動負債（目安200%、最低100%超）〔要確認〕
当座比率 ＝ 当座資産 ÷ 流動負債（目安100%以上）〔要確認〕
```

当座資産は流動資産から**棚卸資産を除いた**もの（現金預金・売掛金・有価証券等）。在庫は換金に時間がかかるため、より厳しく支払能力を見るのが当座比率です。流動比率が高くても在庫が膨らんでいるだけのことがあり、両方を比べます。

### 固定長期適合率・固定比率

設備など長期資産を、安定した資金でまかなえているかを見ます。

```
固定比率 ＝ 固定資産 ÷ 自己資本（100%以下が理想）
固定長期適合率 ＝ 固定資産 ÷（自己資本 ＋ 固定負債）（100%以下が必須）
```

固定資産を短期借入でまかなっていると、返済期日ごとに資金繰りが逼迫します。**固定長期適合率が100%を超える＝長期資産を短期資金で調達している**危険な状態で、資金繰り悪化の典型要因です。

### インタレスト・カバレッジ・レシオ

```
ICR ＝（営業利益 ＋ 受取利息配当）÷ 支払利息
```

本業の利益で利息を何倍まかなえるか。1倍を切ると利益で利息すら払えず、金融機関が最も警戒する水準です。

## 3. 効率性分析（回転率）

資産をどれだけ効率よく回しているかを見ます。回転率が高い＝少ない資産で多くの売上、回転期間が短い＝資金が早く戻る、と読みます。

| 指標 | 算式 | 意味 |
|------|------|------|
| 総資産回転率 | 売上高 ÷ 総資産 | 資産全体の活用度（回/年） |
| 売上債権回転期間 | 売上債権 ÷（売上高÷365） | 回収までの日数 |
| 棚卸資産回転期間 | 棚卸資産 ÷（売上原価÷365） | 在庫の滞留日数 |
| 仕入債務回転期間 | 仕入債務 ÷（仕入高÷365） | 支払までの日数 |

> **実務メモ：** 回転期間（日数）は「売上100あたり何日分寝ているか」を示すので直感的。売上債権回転期間が業界標準より長ければ、回収サイトの悪化・不良債権・押し込み販売を疑う。棚卸資産回転期間の急伸は、不良在庫・架空在庫のサイン。これらは第3章の運転資金・CCCへ直結する。

## 4. 生産性分析（付加価値）

生産性は「人・設備が生み出す付加価値」を見ます。労働集約型の中小企業では特に重要です。

### 付加価値の算出

付加価値は企業が新たに生み出した価値です。控除法（中小企業庁方式）と加算法があります。加算法の代表例は次の通りです。

```
付加価値 ≒ 営業利益 ＋ 人件費 ＋ 減価償却費 ＋ 賃借料 ＋ 租税公課 ＋ 金融費用
```

### 労働生産性・労働分配率

```
労働生産性 ＝ 付加価値 ÷ 従業員数（1人あたりいくら稼ぐか）
労働分配率 ＝ 人件費 ÷ 付加価値（付加価値の何%を人件費に配分したか）
```

労働分配率の目安は50〜70%程度 `〔要確認〕`。高すぎると人件費負担が重く利益が出にくく、低すぎると賃金競争力・定着に懸念があります。**労働生産性を上げずに賃上げすれば分配率が上がり利益を圧迫する**——賃上げ相談の際の基本フレームです。

## 5. 成長性分析

過去〜現在の伸びを見ます。単年でなく複数期のトレンドで判断します。

```
売上高成長率 ＝（当期売上 − 前期売上）÷ 前期売上
経常利益成長率 ＝（当期経常利益 − 前期経常利益）÷ 前期経常利益
```

> **実務メモ：** 「増収減益」（売上は伸びたが利益は減った）は、値引き拡販・原価高・先行投資のいずれか。「減収増益」はリストラ・不採算撤退の効果であることが多い。成長性は収益性・安全性とセットで解釈し、「無理な成長で財務が痛んでいないか」を確認する。

## 6. 分析の進め方（総合）

1. **時系列比較**：まず自社の2〜3期推移で変化を掴む。
2. **同業他社比較**：業種平均（中小企業実態基本調査等）と比べ、強み・弱みを特定。
3. **相関で読む**：指標は単独でなく組み合わせる（例：ROE↑＋自己資本比率↓＝借入で嵩上げ）。
4. **仮説→ヒアリング**：数字から仮説を立て、第4章の経営者ヒアリングで裏を取る。

## 確認問題

1. ROAを「売上高利益率」と「総資産回転率」に分解する式を書け。
2. 当座比率が流動比率より厳しく支払能力を見られるのはなぜか。
3. 固定長期適合率が100%を超えると、なぜ資金繰りが悪化しやすいのか。
4. ROEが高いのに安全性に懸念があるのはどういう場合か。
5. 労働生産性を上げずに賃上げすると、労働分配率と利益はどうなるか。
6. 「増収減益」から考えられる原因を2つ挙げよ。

### 解答

1. ROA ＝ 売上高利益率 × 総資産回転率。
2. 当座比率は流動資産から**換金に時間がかかる棚卸資産を除く**ため、より即時の支払能力を厳しく評価できるから。
3. 固定資産（長期に寝る資産）を短期資金でまかなっており、**短期の返済期日ごとに資金が流出**するため。
4. **財務レバレッジ（借入依存）でROEが嵩上げ**されている場合。借入を増やすとROEは上がるが自己資本比率は下がる。
5. 労働分配率は**上がり**、利益は**圧迫される**。
6. 値引き・拡販による粗利率低下、原価・仕入高の上昇、先行投資（販管費増）などから2つ。
