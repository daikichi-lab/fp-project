# 第5章　ケーススタディ

> ※本章は**2025年度（令和7年度）時点**の実務・制度に基づく。適用時は最新情報で確認すること。
>
> **注意：本章の企業名・数値はすべて教材用の架空値です。** 実在の企業・決算とは関係ありません。目安値は業種・規模で異なるため `〔要確認〕` を付しています。

第1〜4章の道具を使い、具体的な決算書から「財務分析 → 課題抽出 → 提案」までを通しで演習します。3社を扱います。

## ケース1　金属加工業A社（増収なのに資金繰り悪化）

### 前提

- 業種：金属加工（製造業）、従業員20名、社長65歳、後継者は長男（専務・40歳）。
- 直近2期で売上が15%伸びたが、社長は「売上は伸びたのに金が回らない」と訴える。

### 簡易BS（当期末・単位：百万円）

| 資産 | 金額 | 負債・純資産 | 金額 |
|------|-----:|-------------|-----:|
| 現金預金 | 30 | 買掛金・支払手形 | 60 |
| 売掛金・受取手形 | 120 | 短期借入金 | 90 |
| 棚卸資産 | 100 | 長期借入金 | 150 |
| 有形固定資産 | 180 | （負債合計） | 300 |
| 短期貸付金（役員） | 20 | 純資産（自己資本） | 150 |
| 資産合計 | 450 | 負債・純資産合計 | 450 |

### 簡易PL（当期・単位：百万円）

| 項目 | 金額 |
|------|-----:|
| 売上高 | 600 |
| 売上原価 | 480 |
| 売上総利益 | 120 |
| 販管費 | 96 |
| 営業利益 | 24 |
| 支払利息 | 9 |
| 経常利益 | 15 |
| 当期純利益 | 10 |
| （減価償却費・PL内） | 18 |

### 財務分析

**収益性**：粗利率 120÷600＝**20%**、営業利益率 24÷600＝**4%**、経常利益率 15÷600＝**2.5%**。本業は黒字だが、支払利息9で経常が半減しており、借入負担が重い。

**安全性**：自己資本比率 150÷450＝**33.3%**（良好水準 `〔要確認〕`）。ただし役員貸付金20を控除した実態純資産は130、実態自己資本比率は約**28.9%**に低下。流動比率＝（30+120+100+20）÷（60+90）＝270÷150＝**180%**。当座比率＝（30+120+20）÷150＝170÷150＝**約113%**。

**効率性・運転資金**：
- 売上債権回転期間 ＝ 120÷(600÷365) ≒ **73日**
- 棚卸資産回転期間 ＝ 100÷(480÷365) ≒ **76日**
- 仕入債務回転期間 ＝ 60÷(480÷365) ≒ **46日**（仕入≒原価と近似）
- **CCC ＝ 73＋76−46 ＝ 約103日**
- 所要運転資金 ＝ 売上債権120＋在庫100−仕入債務60 ＝ **160**

**返済力**：簡易キャッシュフロー ＝ 当期純利益10＋減価償却18 ＝ **28**。有利子負債＝短期90＋長期150＝240。債務償還年数 ＝（240−160）÷28 ≒ **約2.9年**（運転資金控除後は健全 `〔要確認〕`）。

### 課題抽出

1. **増加運転資金が資金を食っている**：売上15%増でCCC103日分の運転資金（160）が膨らみ、増収でも現金が残らない。「金が回らない」の正体はこれ。
2. **在庫・売掛が重い**：在庫76日・債権73日は改善余地。CCC短縮で手元資金を厚くできる。
3. **役員貸付金20**：金融機関評価を下げ、社長万一時は会社への貸付＝相続財産化の論点。
4. **社長65歳・後継者あり（長男専務）**：事業承継・自社株対策が数年内の課題。

### 提案の骨子

- **資金対策（最優先）**：回収サイト短縮・在庫圧縮でCCCを改善し、増加運転資金を自己資金でまかなえる体質へ。短期借入への依存を下げる。
- **事業保障**：社長への依存が高く借入240。社長万一時の**返済原資・事業継続資金**として法人保険を検討 → [法人保険](../01-法人保険営業/README.md)。
- **役員貸付金の整理**：報酬設計の見直し等で圧縮。相続時の扱いも整理 → [相続](../03-相続/README.md)。
- **承継準備**：長男へのバトンタッチに向け、自社株評価と対策を早期に着手 → [事業承継](../04-事業承継/README.md)。

> **実務メモ：** A社は「黒字・自己資本比率も悪くない」ため経営者は危機感が薄い。しかし資金繰りの実感は正しい。CCCと増加運転資金という「数字の言葉」で見えない資金流出を可視化すると、経営者の納得と信頼が一気に高まる。

## ケース2　卸売業B社（実質債務超過の疑い）

### 前提

- 業種：食品卸（卸売業）、従業員15名、社長58歳、後継者未定。
- 表面上は資産超過だが、金融機関から追加融資を渋られている。

### 簡易BS（当期末・単位：百万円）

| 資産 | 金額 | 負債・純資産 | 金額 |
|------|-----:|-------------|-----:|
| 現金預金 | 20 | 買掛金 | 110 |
| 売掛金（うち長期滞留30） | 150 | 短期借入金 | 130 |
| 棚卸資産（うち不良在庫25） | 90 | 長期借入金 | 120 |
| 有形固定資産 | 100 | （負債合計） | 360 |
| 役員貸付金・仮払金 | 40 | 純資産（自己資本） | 40 |
| 資産合計 | 400 | 負債・純資産合計 | 400 |

### 簡易PL（当期・単位：百万円）

| 項目 | 金額 |
|------|-----:|
| 売上高 | 800 |
| 売上総利益（粗利率10%） | 80 |
| 販管費 | 74 |
| 営業利益 | 6 |
| 支払利息 | 7 |
| 経常利益 | ▲1 |
| 当期純利益 | ▲1 |
| （減価償却費・PL内） | 8 |

### 財務分析

**収益性**：粗利率**10%**（卸売として一般的水準 `〔要確認〕`）。営業利益率0.75%と薄く、支払利息7で**経常赤字**。ICR ＝ 6÷7 ≒ **0.86倍**（1倍未満＝本業利益で利息を払えない）。

**安全性（表面）**：自己資本比率 40÷400＝**10%**と低い。

**安全性（実態）**：実態純資産 ＝ 表面40 −（役員貸付金40＋長期滞留売掛30＋不良在庫25）＝ **▲55**。**実質債務超過**。金融機関が融資を渋る理由はここ。

**返済力**：簡易キャッシュフロー ＝ ▲1＋8 ＝ **7**。有利子負債＝130＋120＝250。所要運転資金＝売掛150＋在庫90−買掛110＝130。債務償還年数 ＝（250−130）÷7 ≒ **約17年**（過剰債務ゾーン `〔要確認〕`）。

### 課題抽出

1. **実質債務超過（▲55）**：不良資産の存在。格付は要注意先以下の可能性。
2. **薄利・経常赤字**：粗利率が低く、利息すら本業でカバーできない（ICR＜1）。
3. **不良資産の放置**：役員貸付金40・長期滞留売掛30・不良在庫25の処理が未着手。
4. **後継者未定・社長58歳**：このままでは承継も廃業も選べない。まず財務再建が前提。

### 提案の骨子

- **実態BSの改善（最優先）**：不良在庫・回収不能売掛の処理方針を税理士と整理。役員貸付金は報酬・保険活用等で圧縮。実質債務超過の解消計画を作る。
- **収益改善**：低粗利の是正（値上げ・不採算取引の見直し）、販管費の点検。
- **資金繰りの安定**：金融機関へ実態と再建計画を開示し、条件を協議（リスケ含む）。**FPは準備支援に徹し、融資判断は金融機関・専門家へ**。
- **保障の最低限確保**：社長万一時に会社が連鎖破綻しないよう、まず割安な保障を確保 → [法人保険](../01-法人保険営業/README.md)。財務再建前は大型・貯蓄性提案は不適切。

> **実務メモ：** B社に貯蓄性の高い保険や大型の節税提案をするのは逆効果。今必要なのは①不良資産処理②収益改善③最低限の保障。「売る」より「立て直しに寄り添う」局面で、ここで信頼を得ると再建後に本命の提案が生きる。

## ケース3　IT受託開発C社（高収益・自社株評価の上昇）

### 前提

- 業種：ソフトウェア受託開発（サービス業）、従業員30名、社長55歳、後継者は役員の甥。
- 無借金経営で利益・現預金が潤沢。社長は「利益が出て法人税も株価も上がって困る」と話す。

### 簡易BS（当期末・単位：百万円）

| 資産 | 金額 | 負債・純資産 | 金額 |
|------|-----:|-------------|-----:|
| 現金預金 | 220 | 買掛金・未払金 | 40 |
| 売掛金 | 90 | 短期借入金 | 0 |
| 有形固定資産 | 30 | 長期借入金 | 0 |
| 投資有価証券 | 60 | （負債合計） | 40 |
| 資産合計 | 400 | 純資産（自己資本） | 360 |

### 簡易PL（当期・単位：百万円）

| 項目 | 金額 |
|------|-----:|
| 売上高 | 500 |
| 売上総利益（粗利率40%） | 200 |
| 販管費 | 140 |
| 営業利益 | 60 |
| 経常利益 | 62 |
| 当期純利益 | 42 |

### 財務分析

**収益性**：粗利率**40%**、営業利益率**12%**と高収益（サービス業として良好 `〔要確認〕`）。ROA ＝ 62÷400＝**15.5%**、ROE ＝ 42÷360＝**11.7%**、いずれも高水準。無借金のためレバレッジ嵩上げはなく、実力である。

**安全性**：自己資本比率 360÷400＝**90%**。無借金・現預金220で盤石。

**課題は「稼ぎすぎ」の裏側にある**：利益と純資産の蓄積で**自社株評価が上昇**し続けている。社長55歳・甥へ承継意向があるため、株価が上がるほど承継時の贈与・相続税負担が重くなる。

### 課題抽出

1. **自社株評価の上昇**：利益・純資産の蓄積で類似業種比準・純資産価額とも上昇傾向。承継コスト増。
2. **役員退職金の未準備**：高収益だが退職金原資・純資産圧縮策が未着手。退職金は株価引下げにも有効。
3. **余剰現預金の活用**：220の現預金が低利で眠り、資本効率（ROA）を下げている面も。
4. **承継スキーム未定**：甥への承継可否・時期・手法が固まっていない。

### 提案の骨子

- **事業承継設計（最優先）**：甥への承継を前提に、自社株評価の試算と引下げ策（退職金支給・生前贈与・納税猶予の検討）を早期着手 → [事業承継](../04-事業承継/README.md)。
- **役員退職金の準備**：法人保険を活用した退職金原資の準備。支給時の**純資産圧縮＝株価引下げ**効果も期待 → [法人保険](../01-法人保険営業/README.md)。
- **社長個人の相続対策**：高額な役員報酬・個人資産の蓄積が見込まれ、個人の相続税対策・納税資金の検討 → [相続](../03-相続/README.md)。
- **余剰資金の方針整理**：内部留保の使途（投資・退職金・承継原資）を経営者と整理。

> **実務メモ：** C社は「困りごとが黒字ゆえ」の典型。財務は健全なので保障の必要性は低いが、**承継・退職金・相続**という時間軸の長いテーマで大きな提案余地がある。株価は「今が一番低い」ことが多く、承継対策は着手が早いほど有利。ここでは財務分析が「保険」でなく「承継」への入口になる。

## 3社の比較から学ぶこと

| | A社（金属加工） | B社（食品卸） | C社（IT受託） |
|---|---|---|---|
| 表面の印象 | 黒字・自己資本33% | 資産超過 | 高収益・無借金 |
| 実態の核心 | 増加運転資金で資金逼迫 | 実質債務超過 | 自社株評価の上昇 |
| 最優先課題 | CCC改善・資金対策 | 不良資産処理・再建 | 承継・株価対策 |
| 主な接続先 | 保険・承継 | 保険（最低限）・再建支援 | 承継・退職金・相続 |

同じ「決算書分析」でも、**会社の局面によって提案の中心はまったく異なります**。数字を読み、局面を見立て、適切な打ち手（そのうちの一つが保険）へ橋渡しするのがFPの役割です。保険ありきで入らないこと——3社すべてに共通する原則です。

## 確認問題

1. A社で「増収なのに資金が回らない」原因を、指標を挙げて説明せよ。
2. B社の実態純資産を計算し、金融機関が融資を渋る理由を述べよ。
3. B社のICRを求め、その数値の意味を述べよ。
4. C社の課題が「高収益ゆえ」である理由を、自社株評価の観点から説明せよ。
5. 3社に共通する、提案上の原則を述べよ。

### 解答

1. 売上15%増でCCC約103日分の**増加運転資金（所要運転資金160）**が膨らみ、売掛・在庫に資金が寝るため。指標は売上債権回転73日・在庫回転76日・CCC103日。
2. 実態純資産 ＝ 40 −（役員貸付金40＋長期滞留売掛30＋不良在庫25）＝ **▲55**。実質債務超過であり、返済力（債務償還約17年）も乏しいため。
3. ICR ＝ 営業利益6 ÷ 支払利息7 ≒ **0.86倍**。本業の利益で利息すら払えない水準を意味する。
4. 利益・純資産の蓄積で株価（類似業種比準・純資産価額）が上昇し続け、甥への承継時の**贈与・相続税負担が年々重くなる**ため。
5. **保険ありきで入らず、財務・経営の課題を共有し、優先順位をつけたうえで解決手段の一つとして各対策を位置づける**こと。

## 実務チェックリスト

- [ ] BS・PLから主要指標（収益性・安全性・効率性・返済力）を一通り算出したか
- [ ] 表面値だけでなく実態BS（不良資産控除後）で評価したか
- [ ] CCC・所要運転資金・債務償還年数を試算したか
- [ ] 会社の「局面」（成長／再建／承継）を見立てたか
- [ ] 課題を優先順位づけし、上位を提案化したか
- [ ] 各課題を保険・相続・承継の適切なモジュールへ接続したか
- [ ] 局面に不適切な提案（再建局面での大型貯蓄性提案等）を避けたか
- [ ] 数値・税制の前提に `〔要確認〕`、架空値である旨を明示したか
