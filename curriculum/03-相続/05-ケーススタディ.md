# 第5章　ケーススタディ

※本章は2025年度税制に基づく。税制改正で変わるため適用時は国税庁・最新法令で確認。

第1〜4章で学んだ「民法 → 相続税計算 → 財産評価 → 生前対策」を、具体的な家族・財産構成で統合演習します。**本章の家族・財産・金額はすべて教材用の架空値**であり、税率区分・控除額・特例要件・端数処理はいずれも概算です。実際の試算・申告は税理士が最新の速算表と要件で行う前提で読んでください。

> **コンプライアンス注意：** 以下の試算はFPが概算のあたりをつけるための教材であり、確定税額ではありません。税額の断定・保証はせず、必ず税理士の確認を経てください。数値には代表的な箇所に〔要確認〕を付します。

## ケース1：自宅と預貯金中心の標準的な家庭（一次・二次相続）

### 1-1. 家族構成・財産（架空）

- 被相続人：父（78歳・死亡）。相続人：母（75歳）、長男（50歳・同居）、長女（47歳・別居）。
- 財産（相続税評価ベース・架空の概算値）
  - 自宅の土地（特定居住用に該当想定・330㎡以内）：小規模宅地特例適用前 6,000万円
  - 自宅の建物：1,000万円
  - 預貯金：4,000万円
  - 死亡保険金（受取人：母）：2,000万円
- 遺言なし。

### 1-2. Step1：課税価格の把握

- 法定相続人：母・長男・長女の**3人**。
- 生命保険金の非課税枠：500万円×3人＝**1,500万円**〔要確認〕 → 保険金2,000万円のうち課税対象は500万円。
- 小規模宅地等の特例（特定居住用330㎡・80%減）を自宅土地に適用できれば〔要確認〕、6,000万円 → 概算1,200万円まで圧縮（減額4,800万円）。取得者要件（配偶者は無条件、同居長男は継続要件）に注意。

概算の課税価格（特例適用後・架空）：
```
土地 1,200万円 + 建物 1,000万円 + 預貯金 4,000万円 + 保険金の課税分 500万円
≒ 6,700万円（債務・葬式費用は考慮せず概算）
```

### 1-3. Step2：基礎控除

```
基礎控除 ＝ 3,000万円 ＋ 600万円 × 3人 ＝ 4,800万円〔要確認〕
課税遺産総額 ≒ 6,700万円 − 4,800万円 ＝ 1,900万円（概算）
```

### 1-4. Step3〜4：総額と各人税額（概算）

- 課税遺産総額1,900万円を法定相続分（母1/2、長男・長女各1/4）で按分し、速算表で税額を出して合算 → 相続税の総額（本例では比較的小さい）。税率区分・控除額は〔要確認〕。
- **配偶者の税額軽減**（1億6,000万円または法定相続分まで非課税〔要確認〕）を使えば、母の負担は実質ゼロにできる。

### 1-5. 論点：一次で母に寄せすぎない

母に全財産を寄せれば一次相続の税額はほぼゼロにできる。しかし母自身の固有財産（架空：3,000万円）と合算されると、**二次相続**（母の死亡時）では相続人が長男・長女の2人に減り、基礎控除も4,200万円〔要確認〕へ縮小、配偶者軽減も使えない。結果、**一次＋二次の合計税額が増える**おそれがある。

### 1-6. 提案（概算・方向性）

1. **分割**：自宅は同居の長男が取得し小規模宅地特例を確保。母には預貯金＋保険金で生活資金を確保。長女には預貯金・保険金で配分し不公平感を抑える。
2. **二次相続を見据える**：母への配分を「軽減枠いっぱい」にせず、一次で子世代へも一定程度移す配分を検討。
3. **保険**：母受取の保険は非課税枠内で納税・生活資金に。長女受取の保険を追加し、代償・公平調整の原資に。
4. **遺言**：母の遺言（二次相続の分割）を今から準備し、争いと特例喪失を防ぐ。

> **実務メモ：** 「一次で配偶者軽減を最大活用」は目先の税額を下げますが、二次で跳ね返ります。**一次・二次通算のシミュレーション**を示せると提案の説得力が段違いです。試算は税理士と連携を。

## ケース2：自社株が財産の大半を占める経営者（納税資金と分割）

### 2-1. 家族構成・財産（架空）

- 被相続人：父（70歳・製造業オーナー社長）。相続人：妻（68歳）、長男（42歳・後継者・専務）、二男（39歳・会社員・別居）。
- 財産（相続税評価ベース・架空の概算値）
  - 自社株（取引相場のない株式）：2億円
  - 自宅土地建物：4,000万円
  - 預貯金：3,000万円
  - 死亡保険金（受取人：長男）：3,000万円

### 2-2. 課題の構造

- 財産総額（架空・概算）約2億7,000万円のうち、**自社株が2億円**と大半。基礎控除4,800万円〔要確認〕を大きく超え、相続税は高額になる見込み。
- 自社株は換金できず、**納税資金（現金）が決定的に不足**。
- 後継者の長男に株を集中させたいが、そのままでは二男の**遺留分**（架空試算で相応の金額）を侵害しかねない。

### 2-3. 論点と対策（方向性）

1. **株価引下げ・計画的移転**：類似業種比準・純資産価額の水準を踏まえ、退職金支給や配当政策等で株価を調整し、**相続時精算課税や暦年贈与で後継者へ計画移転**。値上がり資産を早めに移す精算課税の利点（第4章）も検討。詳細評価とスキームは [04-事業承継](../04-事業承継/README.md) と税理士へ。
2. **事業承継税制**：一定要件下で自社株の贈与・相続税の納税猶予・免除を受けられる制度の適用可否を検討〔要確認〕（要件・継続要件が厳格。事業承継モジュール参照）。
3. **納税資金**：長男受取の保険金3,000万円を納税原資に。非課税枠500万円×3人＝1,500万円〔要確認〕も活用。不足分は追加の生命保険・会社からの死亡退職金（非課税枠別枠）で手当て。
4. **分割・遺留分**：長男に株を集中する代わり、二男には預貯金・不動産・**二男受取の生命保険（代償・遺留分見合い）**を配分。**公正証書遺言**で「株は長男へ」を明確化し、遺留分侵害額（金銭）に備えた原資を保険で準備。
5. **配偶者軽減**：妻への配分で一次の税負担を抑えつつ、二次相続まで見据えて過度に寄せない。

### 2-4. 提案の骨子（概算）

```
【分割】株 → 長男に集中（公正証書遺言）
【公平】二男 → 預貯金＋不動産＋二男受取保険で遺留分・代償を手当て
【納税】長男受取保険＋死亡退職金で株の相続税を現金手当て
【評価・移転】株価対策＋精算課税/贈与＋事業承継税制の可否を税理士と精査
```

> **実務メモ：** オーナー経営者の相続は「株の評価・移転（節税）」に目が行きがちですが、実際に破綻を招くのは**納税資金と遺留分**です。保険は両方を同時に解決できる中核ツール。事業承継税制は効果が大きい反面、継続要件を外すと猶予税額が一括で発生するため、**適用は税理士と慎重に**。

## ケース3：子のいない夫婦（兄弟姉妹が相続人）

### 3-1. 家族構成・財産（架空）

- 被相続人：夫（72歳・死亡）。相続人：妻（70歳）、夫の弟（65歳）、夫の妹（62歳）。子・親はいない。
- 財産（架空の概算値）：自宅4,000万円、預貯金5,000万円、死亡保険金（受取人：妻）1,000万円。

### 3-2. 論点

- 子も直系尊属もいないため、相続人は**配偶者と兄弟姉妹**。法定相続分は**妻3/4、兄弟姉妹1/4**（弟・妹で各1/8）。
- 妻に全財産を残したくても、遺言がなければ兄弟姉妹に1/4の法定相続分が生じ、分割協議に兄弟姉妹の関与が必要になる。
- ただし**兄弟姉妹に遺留分はない**（第1章）。

### 3-3. 対策（方向性）

1. **公正証書遺言**で「全財産を妻に相続させる」と定める。兄弟姉妹には遺留分がないため、遺言があれば妻に全財産を残せる。
2. **配偶者の税額軽減**（1億6,000万円または法定相続分まで〔要確認〕）で、妻取得分の相続税負担は実質軽微になる見込み。
3. **二次相続の準備**：妻の死亡時は相続人がさらに限られる（甥姪や遺言指定先）。妻自身の遺言・寄付・信託など、次の承継先を今から設計しておく。
4. **保険**：妻受取の保険で当面の生活・葬儀・納税資金を確保。

> **実務メモ：** 「子がいない夫婦」は、遺言がないと配偶者が義理の兄弟姉妹と遺産分割協議をすることになり、精神的負担が大きくなりがちです。**公正証書遺言1枚**で回避できる典型例。子のいない夫婦を見たら、まず遺言の有無を確認してください。

## 確認問題

1. ケース1で、配偶者に財産を寄せすぎると二次相続で不利になるのはなぜか。
2. 小規模宅地等の特例（特定居住用）を確保するうえで、分割・取得者について注意すべき点は何か。
3. ケース2で、経営者の相続を実際に破綻させやすい二大要因は何か。
4. 自社株を後継者に集中させる際、他の相続人への配慮として有効な手段を挙げよ。
5. ケース3で、子のいない夫婦が配偶者に全財産を残すために最も有効な手段は何か。その根拠も述べよ。

### 解答

1. 二次相続では相続人が減って基礎控除が縮小し、配偶者の税額軽減も使えないため、一次で寄せた財産が配偶者の固有財産と合算され課税が膨らむ。一次・二次通算で最適化すべき。
2. これらの特例は原則、申告期限までの分割確定と申告が要件。かつ取得者要件（配偶者は無条件、同居親族は継続要件、別居親族は厳格要件）を満たす取得者を選ぶ必要がある。
3. 納税資金（現金）の不足と、遺留分（後継者への株集中による他の相続人の遺留分侵害）。
4. 他の相続人を受取人とする生命保険での代償・遺留分見合いの準備、預貯金・不動産の配分、公正証書遺言での明確化など。
5. 公正証書遺言で全財産を配偶者に相続させると定めること。兄弟姉妹には遺留分がないため、遺言があれば侵害額請求を受けず全財産を残せる。
