# 第2章　相続税の計算

※本章は2025年度税制に基づく。税制改正で変わるため適用時は国税庁・最新法令で確認。

相続税の計算は、**「課税価格の合計 → 基礎控除 → 相続税の総額 → 各人の税額 → 加算・控除」**という決まった手順を踏みます。この流れを一度体で覚えると、概算試算が一気に速くなります。本章は計算構造を順に追います。

> **コンプライアンス注意：** 相続税額の確定計算・申告書作成・税務署対応は**税理士の独占業務**です。FPが行えるのは「概算試算」と「制度説明」まで。本章の数値も概算・教材用であり、実額は必ず税理士が確認します。

---

## 1. 計算の全体像（4ステップ）

相続税は、各人がバラバラに計算するのではなく、**いったん全体で税額を出してから各人に配分**する独特の構造です。

```
【Step1】各人の課税価格を求め、合計する
        ↓
【Step2】課税価格の合計 − 基礎控除 ＝ 課税遺産総額
        ↓
【Step3】課税遺産総額を法定相続分で按分 → 税率適用 → 合算 ＝ 相続税の総額
        ↓
【Step4】相続税の総額を、実際の取得割合で各人に配分
        → 各人ごとに2割加算・税額控除を反映 ＝ 各人の納付税額
```

この「**総額を先に決める**」方式により、遺産の分け方を変えても相続税の総額は変わりません（各人の負担割合が変わるだけ）。ここが理解の要です。

---

## 2. Step1：課税価格の計算

各相続人・受遺者ごとに、次を加減して課税価格を求めます。

```
本来の相続財産（土地・建物・株式・預貯金 等）
＋ みなし相続財産（生命保険金・死亡退職金 等）
＋ 相続時精算課税による贈与財産
＋ 生前贈与加算（相続開始前一定期間の暦年贈与）
− 非課税財産（保険金・退職金の非課税枠、墓地・仏具 等）
− 債務・葬式費用（債務控除）
＝ 各人の課税価格
```

- **みなし相続財産**：民法上は相続財産でなくても、相続税では課税対象とするもの（生命保険金・死亡退職金など）。非課税枠については第3章参照。
- **生前贈与加算**：相続開始前**一定期間**（暦年課税分）の贈与を相続財産に加算します。2024年改正で加算期間が従来の3年から**段階的に7年へ延長**されました（延長された4年間分については合計100万円まで加算しない措置あり）〔要確認〕。
- **相続時精算課税**：この制度で贈与した財産は、贈与時の価額で相続財産に加算します。2024年からは年110万円の基礎控除が新設されています〔要確認〕（詳細は第4章）。
- **債務控除**：借入金・未払医療費・未払税金などの債務と、葬式費用を差し引けます。ただし墓地購入の未払金など非課税財産に関する債務や、香典返し・法要費用は対象外です〔要確認〕。

> **実務メモ：** 相続放棄をした人でも、生命保険金は受取人固有の財産として受け取れますが、その人には**保険金の非課税枠が適用されません**。また放棄者は債務控除も原則使えません。放棄と保険金の関係は誤解が多いので丁寧に説明を。

---

## 3. Step2：基礎控除

課税価格の合計から基礎控除を差し引き、**課税遺産総額**を求めます。

```
基礎控除額 ＝ 3,000万円 ＋ 600万円 × 法定相続人の数 〔要確認〕
```

課税価格の合計が基礎控除以下なら、**相続税はかからず申告も原則不要**です（特例適用で0円になる場合は申告が必要）。

### 3-1. 「法定相続人の数」の数え方

基礎控除・保険金や退職金の非課税枠・相続税の総額計算で使う「法定相続人の数」には、独自のルールがあります。

- **相続放棄があっても、放棄がなかったものとして数える**（放棄で相続人が減っても基礎控除は減らさない）。
- **養子の数に制限**がある。実子がいる場合は養子は1人まで、実子がいない場合は2人まで算入〔要確認〕。

> **実務メモ：** 「相続人を増やして基礎控除を膨らませる」目的の養子縁組は、上記の人数制限に加え、租税回避と認定されれば否認され得ます。養子縁組は本来の目的（後継者育成・家族関係）を軸に検討し、税効果はあくまで副次的に扱ってください。

---

## 4. Step3：相続税の総額

課税遺産総額を、いったん**法定相続分で分けたと仮定**して各人の税額を計算し、合算します。実際の分け方に関係なく、この仮定計算で総額が決まります。

### 4-1. 手順

1. 課税遺産総額 × 各法定相続人の**法定相続分** ＝ 各人の法定取得金額
2. 各人の法定取得金額に**超過累進税率**を適用して税額を算出
3. 各人の税額を合算 ＝ **相続税の総額**

### 4-2. 相続税の速算表（構造）

相続税は**超過累進税率**で、課税標準が上がるほど段階的に高い税率がかかります。実務では「税率 × 金額 − 控除額」の速算式を使います。

| 法定相続分に応ずる取得金額 | 税率 | 控除額 |
|----------------------------|------|--------|
| 1,000万円以下 | 10% | ― |
| 以降、金額区分ごとに段階的に上昇 | 15%〜 | 各区分の控除額 |
| 最高区分（6億円超） | 55% | 最高区分の控除額 |

上記の具体的な税率区分・控除額は**すべて〔要確認〕**（金額・率とも改正され得るため、国税庁の速算表で確認）。ここで押さえるべきは「**超過累進で最高55%**」「速算表は税率と控除額のセット」という**構造**です。

> **実務メモ：** 総額計算で法定相続分を使うのは「あくまで計算上の仮定」です。顧客に「法定相続分どおりに分けないといけない」と誤解させないよう注意。分け方は自由で、分け方によって各人の負担は変わるが総額は変わりません。

---

## 5. Step4：各人の納付税額

### 5-1. あん分（配分）

相続税の総額を、各人が**実際に取得した課税価格の割合**で按分します。

```
各人の税額 ＝ 相続税の総額 × （その人の課税価格 ÷ 課税価格の合計）
```

### 5-2. 2割加算

被相続人の**配偶者・子・父母以外**の人が財産を取得した場合、その人の税額は**2割加算**されます〔要確認〕。

- 対象例：兄弟姉妹、甥・姪、孫（代襲相続人でない孫養子など）。
- **代襲相続人である孫は2割加算の対象外**。一方、代襲でない孫を養子にした「孫養子」は2割加算の対象になります〔要確認〕。

> **実務メモ：** 「孫に直接相続させて一代飛ばす」対策は、相続の階層を1回減らせる一方で**2割加算**がかかります。加算を織り込んでも有利かは個別試算が必要です。

### 5-3. 税額控除（差し引く順序に注意）

各人の税額から、次の控除を順に差し引きます（適用順序も定められています）。

| 控除 | 内容 |
|------|------|
| 贈与税額控除（暦年） | 生前贈与加算された財産にかかっていた贈与税を控除（二重課税排除） |
| 配偶者の税額軽減 | 下記5-4参照 |
| 未成年者控除 | 未成年の相続人につき、満18歳までの年数 × 一定額〔要確認〕 |
| 障害者控除 | 障害者である相続人につき、85歳までの年数 × 一定額（特別障害者は増額）〔要確認〕 |
| 相次相続控除 | 10年以内に続けて相続があった場合の負担調整 |
| 外国税額控除 | 国外財産に外国の相続税相当を課された場合の調整 |
| 相続時精算課税分の贈与税額控除 | 精算課税で納めた贈与税を控除（控除しきれない分は還付） |

- 未成年者控除・障害者控除は、本人の税額から引ききれない分を**扶養義務者の税額から控除**できます〔要確認〕。

### 5-4. 配偶者の税額軽減

配偶者が取得した財産のうち、次の**いずれか多い方**までは相続税がかかりません〔要確認〕。

- **1億6,000万円**、または
- **配偶者の法定相続分相当額**

適用には原則として**申告期限までの分割確定**と**申告**が必要です（税額が0円でも申告が必要）。

> **実務メモ：** 配偶者の税額軽減は強力ですが、**使いすぎると二次相続で不利**になることがあります。一次相続で配偶者に寄せすぎると、配偶者自身の財産と合算されて二次相続の課税が膨らみ、しかも二次では配偶者軽減が使えません。**一次・二次を通算した最適化**が実務の腕の見せどころです（第5章で演習）。

---

## 6. 申告と納付

- **申告期限・納付期限**：相続の開始があったことを知った日の翌日から**10か月以内**〔要確認〕。
- 提出先は**被相続人の死亡時の住所地**を所轄する税務署。
- 納付は**金銭一括が原則**。困難な場合に**延納**（分割払い）、延納でも困難なら**物納**が認められます（いずれも要件・担保あり）〔要確認〕。

> **実務メモ：** 10か月は思うより短いです。相続人確定（戸籍収集）、財産評価、分割協議、納税資金の準備を並行して進める必要があります。特に**納税資金**（現金の手当て）は生前対策の最重要テーマ。不動産中心の資産構成では「税額は出るが現金がない」という事態が起きやすく、生命保険の活用が効きます（第4章・[01-法人保険営業](../01-法人保険営業/README.md) 参照）。

---

## 7. 計算の流れ（概観・教材用の概算例）

以下は**構造理解のための概算・架空例**です。実額は税理士確認が前提で、税率区分・控除額は〔要確認〕。

1. 課税価格の合計を求める（各人の課税価格を合算）。
2. 基礎控除 ＝ 3,000万円＋600万円×法定相続人数 を差し引く〔要確認〕。
3. 残り（課税遺産総額）を法定相続分で按分し、速算表で各人の税額を出して合算 → 相続税の総額。
4. 総額を実際の取得割合で按分し、各人ごとに2割加算・配偶者軽減などを反映 → 納付税額。

数値を当てはめた試算は第5章のケーススタディで扱います。

## 確認問題

1. 基礎控除額の算式を書け。
2. 相続放棄をした相続人がいる場合、基礎控除の「法定相続人の数」はどう数えるか。
3. 相続税の「総額」は、遺産の分け方によって変わるか。理由も述べよ。
4. 2割加算の対象になる人・ならない人を、それぞれ例を挙げて説明せよ。
5. 配偶者の税額軽減の枠を、2つの基準で答えよ。また使いすぎの注意点を述べよ。
6. 相続税の申告・納付期限はいつか。納付方法の原則と例外は。

### 解答

1. 基礎控除 ＝ 3,000万円 ＋ 600万円 × 法定相続人の数〔要確認〕。
2. 放棄がなかったものとして数える（放棄で相続人が減っても基礎控除は減らさない）。養子の数には別途制限がある。
3. 変わらない。総額は課税遺産総額を法定相続分で按分して計算するため、実際の分け方に左右されない。分け方で変わるのは各人の負担割合。
4. 対象：兄弟姉妹・甥姪・孫養子など（配偶者・子・父母以外）。対象外：配偶者・子・父母、および代襲相続人である孫。
5. 「1億6,000万円」または「配偶者の法定相続分相当額」のいずれか多い方まで非課税〔要確認〕。使いすぎると二次相続で課税が膨らみ、二次では配偶者軽減が使えないため、一次・二次通算で最適化する。
6. 相続開始を知った日の翌日から10か月以内〔要確認〕。金銭一括納付が原則で、困難なら延納、延納でも困難なら物納。

## 実務チェックリスト

- [ ] 課税価格に、みなし相続財産・生前贈与加算・精算課税分を漏れなく含めたか
- [ ] 非課税財産・債務控除・葬式費用を正しく差し引いたか
- [ ] 基礎控除の「法定相続人の数」を放棄・養子制限を踏まえて数えたか
- [ ] 相続税の総額を法定相続分按分＋速算表で求めたか（税率・控除額は最新確認）
- [ ] 2割加算の対象者を判定したか
- [ ] 配偶者軽減・未成年者・障害者・贈与税額控除などを適用順に反映したか
- [ ] 二次相続まで見据えて配偶者への寄せ方を検討したか
- [ ] 申告期限10か月と納税資金（現金確保）を確認したか
- [ ] 確定計算・申告は税理士へ連携したか
