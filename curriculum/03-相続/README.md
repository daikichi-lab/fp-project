# モジュール03：相続

相続を「**民法（誰が・どう分けるか）→ 相続税（いくらかかるか）→ 財産評価（何をいくらで数えるか）→ 生前対策（どう備えるか）**」の順に体系的に理解し、経営者・資産家に対して**相続税の概算試算と生前対策の全体像**を提示できるようになるためのモジュールです。

> 相続は「民法の分割」と「税法の課税」という2つの土俵が重なる領域です。分割でもめれば税の特例（配偶者の税額軽減・小規模宅地等の特例など）も使えなくなります。**法務と税務を分けて考え、最後に統合する**という視点で学習してください。

> **コンプライアンス注意：** 具体的な相続税額の計算・申告・税務判断は**税理士の独占業務**です。FP・保険営業は「概算試算」「制度の全体像の説明」「専門家への橋渡し」までが役割であり、個別具体の税額断定や申告代行は行えません。本モジュールもその前提で記述しています。

---

## 学習目標

このモジュールを修了すると、以下ができるようになります。

1. 法定相続人・順位・法定相続分・遺留分を正しく判定できる
2. 遺言（自筆証書・公正証書・法務局保管制度）と分割手続の実務を説明できる
3. 相続税の計算構造（課税価格 → 基礎控除 → 相続税総額 → 各人の税額）を順に追える
4. 主要な財産（宅地・家屋・株式・生命保険金・退職金）の評価の考え方を説明できる
5. 小規模宅地等の特例・配偶者の税額軽減など主要特例の枠組みを理解している
6. 暦年贈与・相続時精算課税（2024年改正後）を含む生前対策の順序と留意点を提示できる
7. 具体的な家族・財産構成から相続税を概算し、分割と対策を提案できる

## 進め方

1. まず本 README で全体像をつかむ。
2. 第1章で**民法（誰が相続人か・どう分けるか）**を固める。ここがすべての土台です。
3. 第2章で**相続税の計算構造**を、第3章で**財産評価**を学ぶ。計算と評価は表裏一体なので往復して読む。
4. 第4章で**生前対策**を全体像として押さえ、第5章の**ケーススタディ**で統合演習する。
5. 各章末の**確認問題**と**実務チェックリスト**で理解度を自己点検する。

## 重要な前提

- 本モジュールは **2025年度（令和7年度）税制**をベースに記述しています。
- 変わりうる数値・区分・限度額・特例要件には `〔要確認〕` を付しています。**適用時は必ず最新の国税庁・法令で確認**してください。
- 税額の計算・申告・税務判断は**税理士の独占業務**です。FPは概算試算と全体像の提示、専門家連携までが役割です。
