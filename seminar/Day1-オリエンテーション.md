# Day1 オリエンテーション ― スライド目次（登壇用アウトライン）

経営者から選ばれるFP養成講座（3か月集中実践コース）／第1回。3か月・全6回の入口として「なぜ法人マーケットか」「経営者に選ばれるFPとは何か」を腹落ちさせ、受講者の学習スタンスと"追いかける1社"を決めきる回。**本講座は完全オリジナル設計**で、各回が濃密な実践内容として独立して積み上がる。

## このセッションのねらい（到達目標）

- 3か月・全6回で「どこに到達するのか（ゴール像）」を受講者が**自分の言葉で**語れる
- 個人マーケットとの構造的な違いを理解し、法人マーケットの機会と難所を言語化できる
- 経営者が本当に求めているのは「保険説明」ではなく「決算書からの課題可視化と打ち手」だと腹落ちする
- 「商品を売るFP」から「課題を解決する経営パートナー」への転換モデルを理解する
- 3か月の学び方（実案件主義・相談し放題・フォローアップ）を掴み、**追いかける1社**を決める

## 所要時間・形式

- **形式：** オンライン（Zoom）
- **時間：** 60分（12:00–13:00）
- **進め方：** 講義中心＋随所に短い問いかけ。手を動かす本格ワークはDay2以降が本番のため、本回は「考える・決める・宣言する」タイプの軽いワークで巻き込む

## 本編① なぜ今、法人マーケットなのか

### S04 個人マーケットの頭打ちと、法人マーケットの空白

- 個人保険は価格競争・ネット比較・世帯減少で単価と継続性が低下傾向 〔要確認：市場データ・出典〕
- 一方、中小企業は約336万社、その多くが「相談できる相手」を持たない 〔要確認：最新の中小企業白書等〕
- 法人は1社で複数テーマ（事業保障・退職金・福利厚生・相続・事業承継・資金繰り）＝**LTVが大きく関係が長期化**
- 競合FPの多くが「商品提案」に偏り、**課題起点の提案に大きな空きがある**

### S05 中小企業経営者が抱える「お金の不安」の実像

- 事業保障：社長に万一のとき、借入返済・運転資金・従業員の生活は守れるか
- 退職・勇退：自分の引退時にいくら準備できているか（役員退職金）
- 相続：自社株と個人資産をどう遺すか、納税資金は足りるか
- 事業承継：後継者はいるか、自社株をどう渡すか（後継者不在率は依然高水準）〔要確認：最新データ〕
- 資金繰り：黒字でも資金が回らない、金融機関とどう向き合うか
- → これらは**すべて決算書と経営者の頭の中に眠っている**。引き出せる人が選ばれる。

### S06 それでも多くのFPが法人に踏み込めない「3つの壁」

- ①**知識の壁**：決算書・財務・相続・事業承継を体系的に学んでいない
- ②**会話の壁**：経営者と何を話せばいいか分からず、商品説明に逃げてしまう
- ③**提案の壁**：課題は何となく分かっても「打ち手」に落とせない
- → 本講座はこの3つの壁を、3か月で順番に壊す設計

> **ねらい：** 受講者の「できていない理由」を言語化して安心させ、「この講座がそれを埋める」と接続する。

## 本編② 選ばれるFPの本質

### S07 経営者が本当に求めているもの

- 求めているのは「保険という商品の説明」ではない
- 求めているのは「自社の現状・課題・将来リスクを、数字で可視化してくれること」
- 経営者の共通言語は**決算書**。ここで対話できる相手を探している
- 保険・相続・承継は、課題が見えて初めて「解決策」として意味を持つ

### S08 転換モデル：「商品を売るFP」→「課題を解決する経営パートナー」

- Before（商品起点）：面談＝商品説明 → 価格・返戻率の比較 → 相見積り・価格競争 → 単発で終了
- After（課題起点）：面談＝決算書から現状把握 → 課題・リスクの可視化 → 打ち手として保険/相続/承継を提案 → 継続的な伴走
- 同じ「保険を提案する」でも、**入口が違えば立ち位置が変わる**

> **ねらい：** この講座全体の"世界観"を1枚で伝える中核スライド。before/afterを面談シーンで具体的に語る。

### S09 課題起点の提案フロー（本講座の背骨）

- ①決算書を読む（会社の状態・数字を掴む）
- ②課題と将来リスクを可視化する（何が・いつ・いくら足りないか）
- ③打ち手を設計する（保険／相続対策／事業承継／財務改善）
- ④経営者の意思決定を支え、実行を伴走する
- → Day2〜6はこのフローを各パートで深掘りする

### S10 選ばれるFP／選ばれないFPの分かれ道

- 選ばれるFP：課題から会話を始める／数字で対話できる／相続・承継まで見据える／実案件で試し改善し続ける
- 選ばれないFP：いきなり商品説明／決算書を「経理の資料」と避ける／単発提案で関係が続かない
- 本講座は一貫して「選ばれる側」の型を身につける

## 本編③ 3か月の地図

### S11 3か月後のゴール像（成果イメージ）

- 決算書を前に「この会社の課題はここ」と経営者に語れる
- 課題起点で保険・相続・承継の提案につなげられる
- 「保険屋さん」ではなく「相談相手・経営パートナー」としてのポジションを得る
- 講座で扱った実案件（追いかける1社）で、具体的な提案の入口をつくれている

### S12 全6回の全体設計（1本の物語として）

- ①オリエン（本日）→ ②マネジメントゲーム → ③財務分析 → ④相続対策 → ⑤事業承継 → ⑥ブランディング（＋フォローアップ勉強会）
- 学びの流れ：**経営者視点を得る（Day2）→ 数字を読む（Day3）→ 課題別の打ち手（Day4・5）→ 選ばれる自分をつくる（Day6）**
- 各回は独立して濃密。かつ、順番に積み上がって「提案できる自分」に到達する

### S13 Day2 マネジメントゲーム体験で得るもの

- 経営を疑似体験し、**経営者の意思決定と数字のつながり**を体で理解する
- 利益構造・損益分岐点が「暗記」でなく「実感」になる → Day3で決算書が立体的に見える
- 詳細：[`./Day2-マネジメントゲーム体験.md`](./Day2-マネジメントゲーム体験.md)

### S14 Day3 財務分析で得るもの

- 決算書（BS/PL/CF）の構造と読み方、財務分析指標、資金繰りを実務レベルで習得
- 「どこを見て」「何を課題と捉え」「どう提案につなげるか」の一連の型
- 詳細：[`./Day3-財務分析.md`](./Day3-財務分析.md)

### S15 Day4 相続対策で得るもの

- 法人オーナー特有の相続問題（自社株集中・納税資金・分割と遺留分）
- 保険提案の切り口（納税資金・非課税枠・代償分割の原資）
- 詳細：[`./Day4-相続対策.md`](./Day4-相続対策.md)

### S16 Day5 事業承継で得るもの

- 後継者問題の3類型、自社株評価の仕組み、承継スキーム、事業承継税制の全体像
- 事業承継における保険活用（納税・買取資金、代償資金、退職金）
- 詳細：[`./Day5-事業承継.md`](./Day5-事業承継.md)

### S17 Day6 ブランディングで得るもの

- 学んだ専門性を「選ばれる差別化資産」に変える
- ゴールデンサークル／PESTLE・5フォース／STP／クロスSWOTで自分のポジションを設計
- 詳細：[`./Day6-ブランディング.md`](./Day6-ブランディング.md)

### S18 6回が1本につながる「提案ストーリー」

- 経営者視点（Day2）で信頼の入口をつくり、決算書（Day3）で課題を可視化し、相続・承継（Day4・5）で打ち手を提案し、ブランディング（Day6）で"選ばれ続ける自分"になる
- 追いかける1社に当てはめながら進めれば、修了時には**その1社への提案シナリオ**ができている

## 本編④ 学び方・約束

### S19 この講座の学習メソッド

- 各回「体験・理解 → 型の習得 → 実案件への落とし込み」で積み上げる（座学で終わらせない）
- インプットの体系的な裏付けとしてFP育成教材を用意（[`../curriculum/README.md`](../curriculum/README.md)）
- 「学んで終わり」ではなく「現場で使える」を全回のゴールに置く

### S20 実案件主義：追いかける「1社」を決める

- 3か月を通じて、自分の見込み客・案件を1社選び、毎回その会社に学びを当てはめる
- 抽象論を避け、具体で考えることで提案力が定着する

> **ワーク：** 「この会社に提案してみたい」というターゲット企業を1社、いま決める（社名・業種・規模・接点をメモ）。以降すべての回でこの1社を題材に考える。

### S21 サポート体制

- **相談し放題：** 受講期間中、疑問・案件の悩みはLINE・Chatwork・Zoom等でいつでも相談可
- 各回のリアル開催は後日アーカイブ配信あり（復習可能）
- フォローアップ勉強会（第7回）で復習・質疑を行い、3か月をやりきる

### S22 受講にあたっての3つのお願い

- ①できるだけリアルタイム参加（体験・対話が学びの核）
- ②自社の実案件・見込み客を毎回持ち込む
- ③分からないことは溜めずにその場で相談する

## 登壇メモ

- **時間配分：** 60分は短い。地図パート（S11–S18）を厚くしすぎない。各Day紹介（S13–S17）は1枚30秒、"何が得られるか"だけを語りテンポよく。押したらS10かS23を口頭補足に切り替える。
- **山場：** S07–S09「経営者が求めるのは課題可視化／商品を売るFP→課題を解決するパートナー」がこの回の核。before/after面談を具体シーンで語り、世界観を1枚で刻む。
- **完全オリジナルの強調：** 「この講座は市販の型の寄せ集めではなく、現場から作った独自設計」であることを、押しつけず自信を持って伝える。
- **参加型：** オンラインのため、ワークはチャット・自己認識中心。S03（出発点）とS25（ゴール宣言）を対にして、60分で"変化への意思"を作る。S20の「1社決め」は以降の全回の土台なので必ず実行させる。
- **数値の扱い：** 市場データ・後継者不在率等は〔要確認〕。断定せず「傾向」として語り、最新の白書・統計で裏取りしてから登壇する。
- **免責予告：** 税務・法務の個別判断は以降の回で「専門家連携が前提」になる旨を軽く予告しておくと、Day4・5での期待値調整がスムーズ。
