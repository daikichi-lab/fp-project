# Day1 オリエンテーション ― 設計ノート（項目・内容・背景）

このドキュメントは、Day1オリエンテーション（[`./Day1-オリエンテーション.md`](./Day1-オリエンテーション.md)・全24枚）の**構成の意図**を記録するものです。各パートについて「項目名／内容の要約／なぜこのパートを用いたのか（背景）」を整理しています。スライドを作り込む前提の"設計図の解説"として、講師・制作者が共有するために使います。

## 全体の設計方針（なぜこの構成にしたか）

- **前提：参加者は無料セミナー（『3日間チャレンジ』等）を経ており、「なぜ法人か・自分の現在地」を理解済み。** そのため、一般的なオリエンで置きがちな"動機づけ（なぜ法人マーケットか／選ばれるFPとは）"は省略した。既に納得して申し込んだ層に同じ話を繰り返すと、熱が下がるため。
- **本講座は完全オリジナルの高密度プログラム**として設計。入門教材の型（8つの見る場所・4つの資金ギャップ等）の踏襲を前提にしない。
- **Day1の主役は「学び方」。** 3か月・全6回の成果は「何を教わるか」以上に「受講生がどう学ぶか」で決まる。初回に学習姿勢と場の空気を全員で握ることを最重要目的とした。
- 限られた60分（オンライン）で、①宣言 → ②会計の価値の再確認 → ③3か月の地図 → ④学び方（核）→ ⑤自己紹介 → ⑥締め、と積み上げる。

## パート別 ― 項目・内容・背景

### 導入・宣言（S01–S02）

- **項目名：** 表紙／藤山からの宣言「2年の学びを、この3か月に全て注ぎ込む」
- **内容：** 講座名と初回の位置づけを提示。講師・藤山の経歴を最小限に触れ、「約2年かけて会計・財務・相続・事業承継を学び尽くした。その凝縮を出し惜しみなく全て渡す」と宣言する。
- **なぜこのパートを用いたのか（背景）：**
  - 参加者は藤山を既に知っているため、自己紹介は信頼獲得ではなく**"本気度の宣言"**に振り切った方が場が温まる。
  - 「全部渡す」という約束は、受講生側の「全部持ち帰る」という当事者意識を引き出す。冒頭で講座全体の熱量とギブの姿勢を示すことが目的。

### 本編① 会計知識がつくとどうなるか（S03–S05）

- **項目名：** 講座の中心は会計・財務／会計が分かるとFPはこう変わる（Before→After）／会計は一生モノの武器
- **内容：** すべての提案の土台が「会社の数字を読めること」であると再確認。会計知識の有無で経営者との会話・提案・選ばれ方がどう変わるかをBefore/Afterで示し、会計スキルが景気や商品トレンドに左右されない普遍的資産であることを伝える。
- **なぜこのパートを用いたのか（背景）：**
  - 動機づけ（なぜ法人か）は省く一方で、**「なぜ"会計"を軸に3か月学ぶのか」の納得は改めて固めておく必要がある**ため。
  - 無料セミナーで一度触れている層なので、新情報ではなく**"再確認・再燃"**として簡潔に。学びの投資対効果を腹落ちさせ、この後の濃い学習への動機を保つ。

### 本編② 3か月の地図（S06–S12）

- **項目名：** 全6回を1回ずつ（①オリエン〜⑥ブランディング）＋「6回が1本の提案ストーリーにつながる」
- **内容：** 全6回を1枚ずつのスライドで提示し、各回で「何が得られるか」を短く伝える。最後に、6回が経営者視点（Day2）→数字（Day3）→打ち手（Day4・5）→自分づくり（Day6）と1本の提案ストーリーに接続することを示す。
- **なぜこのパートを用いたのか（背景）：**
  - 各回を1枚ずつに分けたのは、**1回ごとの価値を独立して認識してもらう**ため。まとめて1枚にすると「盛りだくさん」で終わり、各回への期待が立たない。
  - 「6回が1本につながる」で締めるのは、**バラバラの知識ではなく一連の提案力**として学ぶという全体像を持たせ、途中回の意味を見失わせないため。

### 本編③（核） 学び方 ― この3か月をどう学ぶか（S13–S20）

- **項目名：** 学び方で成果は変わる／ラーニングピラミッド／マザーテレサの言葉／5つの学びの約束（①拍手で場づくり ②失敗歓迎 ③行動 ④質問 ⑤実践）
- **内容：** 「何を教わるか」より「どう学ぶか」で成果が変わることを提示。ラーニングピラミッドで能動的学習ほど定着することを示し、マザーテレサの言葉で「まず行動を変える」心構えを作る。その上で5つの学びの約束を、**安全な場づくりを先に**という順で握る。
- **なぜこのパートを用いたのか（背景）：**
  - **本講座の成否を分ける中核**。良い教材でも受け身では身につかない。初回に学習姿勢を全員で合意しておくことで、以降5回の学習効率が変わる。
  - **ラーニングピラミッド：** 「なぜ能動的に学ぶ必要があるか」を、感覚論でなく学習モデルで裏づけるため（※定着率の数値は諸説あり、メッセージ重視で使用）。
  - **マザーテレサの言葉（思考→言葉→行動→習慣→性格→運命）：** 「まず"行動"を変えれば結果（運命）が変わる」という流れを、記憶に残る言葉で心構えに落とすため（※帰属に諸説あり、"よく知られた言葉"として引用）。
  - **順番＝「①拍手で場づくり → ②失敗歓迎 → ③行動 → ④質問 → ⑤実践」：** 人は「安心できる」と感じて初めて積極的に動き・質問し・失敗を出せる。だから**心理的安全性（①②）を先に完成させ、その上で個人の能動性（③④⑤）を引き出す**設計にした。最後を「実践（＝ピラミッドの底・定着最大）」で締め、直後の自己紹介・実案件へ接続する。
  - **失敗歓迎に本田宗一郎・スマイルズ・孔子の3つの言葉：** 本田＝経営者の熱量で勇気づけ、スマイルズ＝「失敗から一番学ぶ」の直球（出典明確）、孔子＝「直さないことが本当の過ち」で"間違いを修正する行動"に接続。役割の異なる3つで「失敗は歓迎」を多面的に支える。

### 本編④ 自己紹介（S21）

- **項目名：** 自己紹介タイム ― 名前・参加理由・3か月後の姿
- **内容：** 一人ずつ「①名前 ②なぜ参加したのか ③3か月後どうなりたいか」を共有し、話し終えたら全員で拍手する。
- **なぜこのパートを用いたのか（背景）：**
  - **③学び方の直後に置いたのが最大のポイント。** 拍手・失敗歓迎で立ち上げた"発言しやすい場"を、**いきなり実践する最初の機会**にするため。「話す→拍手」を全員が一度体験すると、以降の発言・質問のハードルが一気に下がる。
  - ③「3か月後どうなりたいか」を言葉にさせるのは、**以降の学びの羅針盤（自分のゴール）**を各自に持たせるため。後半の自己決定型の宿題ともつながる。
  - 仲間の「なぜ・目標」を知ることで、3か月を一緒に走る関係の土台をつくる。

### 締め（S22–S24）

- **項目名：** サポート体制／次回予告（Day2）／締め「今日から行動を変える・宿題は自分で決める」
- **内容：** 相談し放題・アーカイブ・フォローアップのサポートを案内。Day2の予告と、5つの約束をDay2で実践することを伝える。最後に「宿題は自分で決める」―今日の学びから「Day2までに自分がやること」を1つ各自が決めて宣言する。
- **なぜこのパートを用いたのか（背景）：**
  - **宿題を講師が与えず、受講生が自分で決める設計にした最大の理由**は、「実践する（自ら動く）」という学びの約束と一貫させるため。人に決められた課題より、自分で決めた行動のほうが続き、定着する。
  - 締めを「行動を変える」で終えるのは、マザーテレサの言葉（S15）と呼応させ、**この60分を"変化への意思決定"で閉じる**ため。
  - この「自己決定 → 実践 → 次回冒頭で共有（拍手で受け止め）」のサイクルを、全6回＋フォローアップで回す前提。Day2以降の各回クロージングにも同じ設計を反映する。

## この設計で一貫して流れる背骨

1. **省いたもの（動機づけ）と足したもの（宣言・学び方）を明確にした** ― 参加者の現在地に合わせ、時間を"最も効く所"に集中投下した。
2. **心理的安全性を先に、能動性を後に** ― 拍手・失敗歓迎 →（自己紹介で実践）→ 行動・質問・実践、という順で場と姿勢を作る。
3. **主体性を一貫させた** ― ゴール（3か月後の姿）も宿題も"自分で決める"。講師は場と型を渡し、動くのは受講生、という関係を初回で確立する。
