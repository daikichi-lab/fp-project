# 経営者から選ばれるFP養成講座（3か月集中実践コース）― スライド目次集

本フォルダは、講座「経営者から選ばれるFP養成講座」全6回の**スライド目次（登壇用アウトライン）**を管理します。各回のファイルは、そのまま登壇スライド／PowerPoint作成の設計図として使えるよう、スライドを1枚ずつ番号付きで整理しています。

## 講座概要

- **講座名：** 経営者から選ばれるFP養成講座（3か月集中実践コース）
- **コンセプト：** 決算書から会社の状態を読み取り、経営課題・将来リスクを可視化し、法人保険・相続・事業承継まで提案できる「経営者から相談されるFP」を育成する
- **期間：** 3か月・全6回（＋フォローアップ勉強会）
- **対象：** 法人マーケットを開拓したいFP／独立系FP／法人営業に強くなりたい方／経営者との商談力を高めたい方
- **定員：** 10名（少人数制）
- **設計方針：** 本講座は入門的な体験会（『FPのための法人開拓 3日間チャレンジ』）とは別物の、**完全オリジナルの高密度・実践プログラム**。各回が独立して濃密な実務内容を扱いつつ、順番に積み上がって「提案できる自分」に到達する設計とする（既存の入門教材の型の踏襲を前提としない）。

## スライド目次の表記ルール（各Dayファイル共通）

- 冒頭に「このセッションのねらい（到達目標）」「所要時間・形式」「タイムライン（目安）」を置く
- スライドは `### S01 スライドタイトル` の形で番号付け。各スライドの下に、載せる要点を箇条書き
- スライドは **セクション**（`## 導入` `## 本編` `## まとめ` 等）でグループ化
- ワーク・演習・ケースは `> **ワーク：**` の引用ブロックで明示
- 内容は完全オリジナルで構築する（外部の入門教材の型の踏襲を前提としない）。登壇者が独自の事例・データを差し込む箇所は `〔講師が事例・データを差し込む〕` と注記
- 税務・評価等の変わりうる数値は断定せず `〔要確認：2025年度税制／最新法令〕` を付す
- 提案・税務に踏み込む箇所は、FP育成教材（`../curriculum/`）の該当モジュールへ相対リンク
